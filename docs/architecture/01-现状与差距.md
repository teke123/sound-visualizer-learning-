# 架构能力与验收核对

> 依据 [SRS](../srs/README.md)、[后端决策图](../decision-map-backend.md)、[前端决策图](../decision-map-frontend.md) 与 [目标架构](02-目标架构.md) 整理的核心架构能力核对清单。

## 核心能力清单

| 领域 | 架构要求 |
| ---- | ---- |
| 内容与后台（CMS） | 关卡（L01–L30）与原理文章（P04）通过团队自用轻量后台（`/admin`）直接录入与修改，保存后即时生效；支持切换关卡「已开放 / 未开放」状态 |
| 页面与路由 | 大众端共 9 页（P01–P06、P09–P11）；关卡学习与录音检测统一在关卡页 P05 完成 |
| 账号与个人资料 | 用户注册登录即默认同意服务条款；支持选填或修改「方言区 / 母语背景」；学习进度、音域标定与每次录音结果自动保存在本人账号下；支持单删录音、清空档案与验证密码注销账号 |
| 前端实时声学反馈 | 在 P05 录音过程中，前端基于 Web Audio API（`AnalyserNode` / `AudioWorklet`）与 Canvas 零延迟绘制实时波形、音量包络与实时音高（F0）轨迹 |
| 音域标定（支持跳过） | 提供个人音域与元音空间标定引导，同时允许用户跳过标定直接录音提交；跳过时仍正常评分并展示声学对比图 |
| 录音环境质量提示 | 检测音量、环境底噪、截幅与有效时长，在 P09 结果页作为温和的改善提示展示，不阻断评分与声学可视化 |
| 评分与多维声学对比 | 外部评分服务（科大讯飞语音评测）+ 本地 Python 声学提取（`parselmouth` 提取基频 F0、共振峰 F1/F2、送气段波形/VOT 与语谱图）+ 规则引擎四步反馈；短同步窗口 + 超时回落 202 + 30 秒硬截止 |
| 声音档案与对比 | 自动保存每次检测记录至 P10，支持同一关至少两次历史记录并排回放与声学曲线对比 |
| 契约与类型同步 | 后端 OpenAPI 为真源，`openapi-typescript` 自动生成前端 TS 类型；JSON 统一 `{code, message, data, requestId}` 格式 |

## 完成标准

以 [验收与卡点](../srs/08-验收与卡点.md) 为准，覆盖桌面端与移动端浏览器完整主路径：注册登录（含方言/母语背景设置）→ 关卡学习与多视图构形查看 → P05 录音与前端实时声学反馈（标定或跳过标定）→ P09 多维声学可视化对比、四步反馈与录音质量提示 → P10 档案保存、同关并排对比与数据删除/注销 → 后台内容维护与即时同步。
