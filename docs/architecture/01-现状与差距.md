# 架构能力与验收检查

> 依据 [SRS](../srs/README.md)、[后端决策图](../decision-map-backend.md) 和 [目标架构](02-目标架构.md) 定义实现核验项。本文不对代码完成状态作判断。

## 能力核验

| 能力 | 核验要求 |
| ---- | ---- |
| 内容真源 | 关卡与文章由 CMS 提供；身份、可编辑草稿与不可变公开版本分离；搜索与导航只使用公开内容 |
| 页面职责 | 大众端 P01–P06、P08–P11 共 10 页；P04 文章、P03 进度地图、P06 目录、P05/P08 共用录音编排 |
| 评分服务 | 外部 Provider 维度、质量能力、延迟、错误与留存条款经过验证；同步检测受并发和超时约束 |
| 质量检查 | 先检查录音质量与是否按要求朗读；不合格不打分、不生成检测现象，只提供重录指引 |
| 结果与可视化 | 分数、现象、四步反馈、曲线状态及可靠性可解释；后端计算 F0/共振峰/T 值，前端只渲染 |
| 音域 | 专门标定文本与接口；未标定仍可评分，曲线 needs_calibration；无有效 F0 为 not_available |
| 身份与权限 | 上传即登记归属；登录安全绑定 sid；绑定后的私人资源需账号认证；所有文件/特征/结果共享权限判定 |
| 自动转存 | 有效同意后转存本会话全部符合条件的录音；已有同意账号登录触发；并发完成时重校验，不能重复建档 |
| 学习进度 | 访客/未同意仅浏览器本地；同意后新学习事件与存档记录派生进度；不导入本地历史 |
| 留存与删除 | 临时数据首次上传起 72 小时；逻辑拒绝立即生效，本地物理删除最迟 24 小时；撤回/注销清理进度与音域 |
| CMS 治理 | 单管理员认证、三态发布、发布前置、草稿预览与对比、版本回退、应急检测熔断、反馈处理与审计 |
| 契约 | OpenAPI 为类型真源；标准 HTTP/envelope/requestId；两步提交、版本校验、幂等冲突与处理中查询 |
| 媒体 | 正式示范与构形具备授权；公共媒体按发布引用授权，私人媒体不公开；预览绑定管理员会话和草稿 |
| 档案比较 | 本人同关两条存档可比较；跨版本提示范围；历史结果保持快照 |

## 实现前验证

验证 fastapi-users 的用户名认证适配、数据库与密码依赖、Cookie 会话策略；验证管理界面的认证扩展、草稿表单与自定义治理动作。具体依赖版本按兼容性结果选择。

核实评分服务实际维度、超时恢复与第三方删除能力，建立真人录音及人工判断的验证数据。媒体来源和许可须可核查；未经验证的能力不得表述为检测事实。

## 完成标准

以 [验收与卡点](../srs/08-验收与卡点.md) 为准，覆盖手机/桌面主路径、质量失败、未标定、权限越界、临时过期、内容版本冲突、幂等、撤回与在途操作并发、草稿预览、同关比较及外部服务失败。通过业务走查和数据验证后才能确认实现完成。
