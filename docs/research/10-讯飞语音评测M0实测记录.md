## 二、发送参数实测口径（business）

```json
{
  "sub": "ise", "ent": "cn_vip", "category": "read_syllable",
  "cmd": "ssb", "aus": 1,
  "aue": "raw", "auf": "audio/L16;rate=16000",
  "text": "\ufeff<试题文本>", "tte": "utf-8", "ttp_skip": true,
  "rstcd": "utf8", "rst": "entirety", "ise_unite": "1",
  "extra_ability": "multi_dimension;syll_phone_err_msg",
  "group": "adult"
}
```

- 试题文本带 **utf-8 BOM**（`\ufeff`）。
- 多字单字题用「，」分隔：`妈，麻，马，骂`；需要锁定声调时用拼音标注格式：
  `<customizer: interphonic>` + 每字两行（汉字/拼音），本项目声调关卡用后者。
- 音频 1280B/帧 base64 上行（aus 1/2/4，data.status 1/2），帧间隔
  `min(40ms, 12s/帧数)`——60s 音频也能在管线预算内发完。

## 三、返回 schema 实测（文档未写明的细节）

结构：`xml_result → read_syllable → rec_paper → read_syllable(卷面) → sentence → word → syll → phone`

1. **静音/填充节点**：良好朗读也会返回 `rec_node_type="silv"`（字内前后静音）、
   `fil`（引擎插入填充，文档示例里就有）；`sil`（纯静音词）。三者都**不是**增读，
   不计入朗读维检错，只做诊断——否则几乎所有录音都会被质量闸门误杀。
2. **单字题型也有 sentence 层**（文档示例是句篇，实测单字同样有）。
3. **word/syll 的 symbol 调号是「识别出的调型」而非期望声调**：文档示例中「气」
   （qì）返回 `qi9` + `mono_tone="TONE0"`（实际读成轻声且未判错）。声调形状分析
   需要期望声调，适配器用评测文本回填（标注拼音优先，其次 pypinyin），识别值存
   `detail.recognizedTone`。
4. 卷面 `content` 会带句号（发「那」回「那。」）；`perr_level_msg=0` 表示不给出
   置信度（文档：为 0 可不考虑）。
5. 分数取值 0–100；单字题型 `fluency_score / integrity_score` 恒 0。

## 四、XML → ProviderResult 映射

| XML | ProviderResult |
|---|---|
| 卷面 `total_score` | `overall_score` |
| 卷面 `tone_score` | `tone_score` |
| 卷面全部 `*_score`（total/phone/tone/accuracy/fluency/integrity/emotion） | `scores` dict 原样保留 |
| `word[paper]` content/symbol/beg_pos/end_pos | `syllables[]`：text/pinyin、t0/t1（÷100 秒） |
| `phone[is_yun=0]` perr_msg≠0 | `initial_ok=False` |
| `phone[is_yun=1]` perr_msg 1/3（韵错）、2/3（调错） | `final_ok` / `tone_ok` |
| word/syll `dp_message` 16/32/64/128 | `reading.missing/extra/repeated/replaced` |
| 卷面 `is_rejected=true` | `reading.disordered` |
| 全部原始属性 + XML + sid | `raw`（诊断，不下发用户） |

讯飞只有合并的「声韵分」（phone_score），无单独声母/韵母总分，故
`initial_score / final_score` 留空。

## 五、客户端库选型（排障记录）

`websockets` 库（≥12，sync/async 均试）在该网关**握手即被断连**
（`did not receive a valid HTTP response`，服务端 0 字节关闭）。逐字节重放
实验证实：与该库完全相同的 HTTP 头经原生 socket / `websocket-client` 均稳定
101，问题在 websockets 的 TLS/连接行为被网关风控。**结论：使用
`websocket-client`（讯飞官方 Python SDK `websdk-python` 同款）**，依赖已写入
requirements.txt。

## 六、时延与配额

- 单字（0.8s 音频）端到端 5 次：0.61 / 0.62 / 0.67 / 0.96 / 1.08 s
  （握手 53–112ms，发送 ~0.5–0.8s 为主，受帧间隔支配）。
- 免费配额每日 500 次；探针脚本默认单次，`--runs N` 可测分布。

## 七、复现方式

```bash
cd backend
export XFYUN_APP_ID=... XFYUN_API_KEY=... XFYUN_API_SECRET=...
python xfyun_probe.py --selftest                 # 单字用例（真实录音优先）
python xfyun_probe.py --wav x.mp3 --text 那 --pinyin na4
```

产物在 `backend/probe_out/`（已 gitignore）：五层 JSON
（meta/session/raw/parsed/providerResult/verification）+ 解码后 XML。
离线回归：`pytest test_xfyun_parse.py`（文档示例 XML、真实 na4 返回、
检错路径、试题文本格式，共 5 用例）。
