# 研究资产 · #9 CMS 域：轻量级内部维护后台选型

> 数据库采用 SQLite；后续迁移 PostgreSQL 可按需评估。

## 结论

**采用 Python 同进程轻量级管理面板（`starlette-admin` 或 `sqladmin`）作为团队内部自用的简单内容维护后台。**

## 候选评估

| 候选 | 形态 | 判定 | 依据 |
| ---- | ---- | ---- | ---- |
| sqladmin / starlette-admin | FastAPI 同进程管理界面 | ✅ 采用 | Python 生态；与 SQLAlchemy 结合紧密，零额外部署成本，适合团队内部直接录入和修改关卡、文章及媒体文件 |
| Directus | 独立 Node 服务 | ❌ | 需额外部署运行时，对团队内部维护而言过重 |
| Strapi v5 | 独立 Node 服务 | ❌ | 需独立维护一套 Node 服务与数据同步 |
| Payload 3.0 | Next.js 库 | ❌ | 绑定 Next.js 技术栈，与当前 Vue + FastAPI 架构不符 |

## 核心设计原则

后台定位为**团队自用的便捷维护工具**：

- 直接挂载于后端 `/admin` 路径，提供直观的表单界面，方便人类维护者直接增删改查关卡字段（文字、声道关键帧参数、听辨题、练习步骤、四步反馈模板）、原理文章（Markdown）与分类。
- 媒体上传直接存入本地媒体目录并关联到对应记录，修改保存后前端即可读取最新数据。
- 支持查看用户提交的纠错反馈与「希望增加」记录并标记处理状态。
