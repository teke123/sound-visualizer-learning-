# 研究资产 · #8 账号域：自研 vs 开源账号包

> 账号域选型；接口与权限见 [后端决策图](../decision-map-backend.md)。

## 结论

**引入 fastapi-users承担注册/登录/退出与会话；匿名 sid Cookie 保留为访客锚点，
登录成功后安全绑定 sid；有效同意后才自动全部转存本会话未过期录音。** 产品认证适配层统一公开路径、JSON 与标准 HTTP/envelope，不直接照搬库默认路由。

## 候选评估

| 候选 | 判定 | 依据 |
| ---- | ---- | ---- |
| fastapi-users | ✅ 采用 | 注册/登录/退出+会话开箱即用；CookieTransport+DatabaseStrategy 对齐 ADR-5 服务端会话；管理员认证独立配置；所选版本的字段、密码哈希及兼容性实现期核实 |
| authlib | ❌ 排除 | 官方文档：其 FastAPI 集成仅覆盖 OAuth/OIDC，不提供本地用户名密码认证；SRS 06 到 3.0 均无社交登录规划 |
| 托管认证（Auth0/Clerk/Supabase） | ❌ 排除 | 违反 ADR-1「唯一外部强依赖是评分服务」；学生团队无账号运维预算 |
| 自研薄层（~300 行 + pwdlib/itsdangerous） | ⬜ 备选未采用 | 技术上成立；用户选择优先减少自有代码持有量，交由库维护 |

## 定制任务（细则归 #10）

1. **username 登录**：fastapi-users 默认以 email 为登录标识；需定制 UserManager 与登录路由
   逻辑使用 username（FR-107 不收集邮箱）。
2. **传输/策略**：CookieTransport + DatabaseStrategy（HttpOnly；会话 30 天滑动）。
3. **管理员认证**：CMS 管理员走管理界面（starlette-admin/sqladmin）
   认证扩展配置登录（单管理员凭据），不使用学习账号管理员权限；库内部是否保留 is_superuser 等字段按实际模型处理。
4. **sid 绑定与转存**：sid 与认证会话并存；登录成功安全绑定，已有有效同意触发自动转存，否则仍临时。注册不等于登录；授予同意转存本会话全部未过期录音，退出轮换 sid；学习事件不挂 sid，只在同意后写新事件。
5. **契约适配**：`/api/auth/*` 的产品 JSON 路径/字段经适配层实现，标准状态码与统一 envelope/requestId；不能误将 fastapi-users 的 users/me 原生路径写成 auth/me。

## 账号范围

| # | 缺口 | 决定 |
| ---- | ---- | ---- |
| G1 | 密码找回 | 不做：不收集邮箱/手机号，忘密码 = 重新注册，文案写明 |
| G2 | 账号注销 | 1.0 必做：FR-108，按 D-17 清理全部个人数据、匿名化审计并失效会话 |
| G3 | 管理员形态 | 不进 USER 表：管理界面（/admin）通过认证扩展配置单管理员登录承担 NFR-16 |
| G4 | 注册防刷 | 1.0 不做验证码等复杂防刷；基础注册/登录频率限制必做，备份不能替代防刷 |
| G5 | 用户名/密码规则 | 用户名 3–32 字符（字母/数字/下划线/中文）全局唯一，密码 ≥8 位 |
| G6 | 会话有效期 | HttpOnly + SameSite=Lax，30 天滑动过期 |

## 研究结论使用边界

账号库版本须经兼容性验证，中文用户名登录需要完整认证适配。版本、数据库适配、注册/登录请求格式、会话 30 天滑动机制及密码哈希依赖均须在实现前验证；30 天是目标策略，不声称库天然实现滑动续期。注销清理范围按 D-17，不能只清档案行。
