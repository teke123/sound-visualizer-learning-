# 研究资产 · #8 账号域：自研 vs 开源账号包

> 开票 2026-10-15，定案同日。决策图：docs/decision-map.md #8。

## 结论

**引入 fastapi-users（12.x）承担注册/登录/退出与会话；匿名 sid Cookie 保留为访客锚点，
登录/注册时以补丁消费 sid 并认领访客数据。** fastapi-users 挂载路由豁免统一 envelope。

## 候选评估

| 候选 | 判定 | 依据 |
| ---- | ---- | ---- |
| fastapi-users 12.x | ✅ 采用 | 注册/登录/退出+会话开箱即用；CookieTransport+DatabaseStrategy 对齐 ADR-5 服务端会话；自带 is_superuser 可当单管理员；密码哈希内置 pwdlib(argon2) |
| authlib | ❌ 排除 | 官方文档：其 FastAPI 集成仅覆盖 OAuth/OIDC，不提供本地用户名密码认证；SRS 06 到 3.0 均无社交登录规划 |
| 托管认证（Auth0/Clerk/Supabase） | ❌ 排除 | 违反 ADR-1「唯一外部强依赖是评分服务」；学生团队无账号运维预算 |
| 自研薄层（~300 行 + pwdlib/itsdangerous） | ⬜ 备选未采用 | 技术上成立；用户选择优先减少自有代码持有量，交由库维护 |

## 定制任务（细则归 #10）

1. **username 登录**：fastapi-users 默认以 email 为登录标识；需定制 UserManager 与登录路由
   逻辑改用 username（FR-107 不收集邮箱）。
2. **传输/策略**：CookieTransport + DatabaseStrategy（HttpOnly；会话 30 天滑动）。
3. **管理员（#10 G3 修订）**：CMS 管理员走管理界面（starlette-admin/sqladmin）
   自带登录（env 配置单管理员），不进 USER 表、无 is_superuser、无种子脚本。
4. **sid 并存与消费**：sid Cookie 与其会话 Cookie 并存；登录/注册路由外包一层中间件——
   读取请求 sid → 认领 sid 名下录音/学习事件（写 owner_user_id）→ 清除 sid Cookie。
   fastapi-users 本体不改。
5. **envelope 豁免**：`/api/auth/*` 按其原生 401/400 语义与响应模型，OpenAPI 如实登记；
   其余自研路由维持统一 200+code（#3）。
