# 声学图像提取：实现说明

本文说明 `backend/app/acoustics/imagery/` 的实现内容、每段代码对应的声学信息，以及输出内容的结构。设计依据见同目录的《方案.md》（下文简称「方案」，引用其章节号）。

---

## 1. 概述

**做什么**：输入一条录音和它的音节/音素对齐结果，按方案的三个层次生成声学图像和数值表。

| 层次 | 内容 | 生成条件 |
|---|---|---|
| 通用层 | 波形、宽带/窄带/Mel 语谱图、MFCC、F0 与声调、强度、共振峰、元音空间、谐波谱 | 每条录音都生成 |
| 音素层 | 塞音、擦音、塞擦音、/h/、鼻音（含鼻韵尾）、边音、r、零声母的专项分析 | 录音中出现对应声母或韵尾时生成 |
| 发声态层 | 共振峰修正后的谐波振幅、谱倾斜、HNR、CPP/CPPS、SHR、声带周期 | 每条录音都生成（只分析韵母中有 F0 的帧） |

**规模**：图像最多 39 种（一条录音实际生成 23–27 张），数值表 11 种。

**依赖**：numpy、scipy、matplotlib、praat-parselmouth（均在 `backend/requirements.txt` 中），不依赖 librosa。

## 3. 使用方法

### 3.1 命令行（在 `backend` 目录下）

```
py -3 -m app.acoustics.imagery.cli --samples <WAV 根目录> --alignment <对齐 JSON> --out <输出目录>
```

| 参数 | 说明 |
|---|---|
| `--samples` | 递归查找 `*.wav`，按文件名与对齐 JSON 匹配；没有对齐结果的录音会被跳过并提示 |
| `--alignment` | 对齐汇总 JSON，格式见第 4 节 |
| `--out` | 输出目录，每条录音一个子目录 |
| `--only` | 只为文件名包含这些片段的录音出图，例如 `--only ma3_FV1 si1_`；第一遍统计仍覆盖全部录音 |
| `--modules` | 只运行指定模块，例如 `--modules prosody formants` |

示例（本仓库自带的开发集）：

```
py -3 -m app.acoustics.imagery.cli --samples ../docs/声学图像提取/样本 --alignment ../docs/声学图像提取/对齐结果/alignment.json --out <仓库外的输出目录>
```

输出图片较多（每条录音约 3.5 MB），请放在仓库以外。

### 3.2 在代码中调用

```python
from app.acoustics.imagery import generate_all
from app.acoustics.imagery.common import load_alignment, read_mono, DbScales

aln = load_alignment("alignment.json")["ma3_FV1.wav"]
x, sr = read_mono("ma3_FV1.wav")
results = generate_all(x, sr, aln, "out/ma3_FV1", scales=DbScales(...), context={"f0_ref_hz": 282.6})
```

每个模块都提供同一接口 `generate(x, sr, aln, out_dir, scales=None, context=None) -> dict`，返回值结构为：

| 键 | 内容 |
|---|---|
| `images` | {文件名: 路径} |
| `tables` | {文件名: 路径} |
| `params` | 实际使用的参数，包括 Praat 实际采用的时间步长、频率步长等 |
| `warnings` | 中文说明列表（不可测的项目、数据质量提示等） |

单个模块抛出异常时，`generate_all()` 把错误记录在该模块结果的 `error` 字段中，其余模块照常运行。

`scales` 和 `context` 由批处理第一遍计算后传入。单独调用时可以省略，此时语谱图的显示上限按单张图确定（仅供调试），半音参考取本文件 F0 中位数。

## 4. 输入数据

### 4.1 录音

- 格式：16-bit PCM WAV，保留原始采样率（语料为 44.1 kHz），不重采样，也不做归一化。
- 双声道录音只分析第 0 声道（`common.ANALYSIS_CHANNEL`）。语料两个声道之间有 1–3 个采样点的延迟，混成单声道会在高频产生梳状滤波，4–12 kHz 损失 2–4 dB。

### 4.2 对齐 JSON（`common.load_alignment` 读取的格式）

```json
{
  "meta": { ... },
  "samples": [
    {
      "file": "样本/FV1/ma3_FV1.wav",
      "speaker": "FV1",
      "durationSec": 0.889,
      "syllables": [
        {
          "text": "马", "symbol": "ma3", "t0": 0.0, "t1": 0.77,
          "phones": [
            {"label": "m", "part": "initial", "t0": 0.0, "t1": 0.12},
            {"label": "a", "part": "final", "t0": 0.12, "t1": 0.77}
          ]
        }
      ]
    }
  ]
}
```

| 约定 | 说明 |
|---|---|
| 必需字段 | `file`（按文件名匹配录音）、`speaker`、`durationSec`、`syllables[].symbol/t0/t1/phones[].label/part/t0/t1`；其余字段（讯飞分数、原始位置等）程序不读取 |
| 失败样本 | 带 `error` 字段的样本会被跳过 |
| 时间 | 单位为秒，以原始录音起点为零点 |
| `part` | `initial`（声母）或 `final`（韵母） |
| 发音人编号 | 以 M 开头按男声处理，其余按女声处理（决定共振峰上限初始值） |

**音素标签**（讯飞符号，`common.PHONE_IPA` 给出对应的 IPA，图上显示为「符号 [IPA]」）：

| 类别 | 标签 |
|---|---|
| 声母 | b p d t g k / z c zh ch j q / f s sh x h / m n / l / r |
| 零声母伪声母 | `_a` `_o` `_e` `_i` `_u` `_v`，图上显示为 ∅ |
| 韵母 | 拼音韵母。`ii` = [ɿ]（z/c/s 后），`iii` = [ʅ]（zh/ch/sh/r 后），`v` = [y]，`van` = üan |

声母按发音方式分类（`common.initial_class`）：stop / affricate / fricative / nasal / lateral / approximant（r）/ zero（零声母）。韵母按结构分类（`common.final_type`）：monophthong / diphthong / triphthong / nasal_final。

### 4.3 本仓库自带的数据

| 目录 | 内容 |
|---|---|
| `docs/声学图像提取/样本/{FV1,MV1}/` | 开发集：2 位发音人 × 33 个音节的 WAV 与 TextGrid（音节层 + 音素层，可在 Praat 中打开） |
| `docs/声学图像提取/对齐结果/` | 开发集对齐汇总 `alignment.json` 与讯飞原始返回 `raw_xml/*.xml` |
| `docs/声学图像提取/验证集/样本/{FV2,FV3,MV2,MV3}/` | 验证集：4 位发音人 × 24 个音节（不参与参数调整） |
| `docs/声学图像提取/验证集/对齐结果/` | 验证集对齐结果 |

对齐的获取方法：
1. 调用讯飞语音评测接口 open-ise（题型 `read_syllable`，`ent=cn_vip`），用拼音标注（interphonic）格式给出汉字和带调拼音。
2. 送检音频由原始录音经 ffmpeg 转为 16 kHz 单声道，首部补 0.2 s、尾部补 0.3 s 静音。
3. 接口返回的位置以 10 ms 为单位并包含首部补白，换算为秒后减去 0.2 s，截断到 [0, 录音时长]。

接口只给出声母和韵母两段，复合韵母内部没有边界。

## 5. 处理流程与共享约定

### 5.1 两遍处理（`cli.py`）

**第一遍**（统计全部已对齐录音）：
1. 计算每条录音四类频谱图的 dB 最大值（`basic_spectra.db_levels`），取整批最大值作为显示上限（`DbScales`），使所有图使用同一标尺（方案 §9 第四项）。
2. 用 50–600 Hz 宽范围提取 F0，按发音人统计有声帧：
   - F0 下限 = 0.75 × 第 1 百分位，上限 = 1.25 × 第 99 百分位，均取 5 Hz 的整数倍（`common.estimate_profile`，方案 §5.1）；
   - 半音参考值取该发音人全部有声帧的 F0 中位数。

**第二遍**：逐条录音运行全部模块，写出图、数值表和 `manifest.json`；最后合并各录音的同名数值表，写出运行配置和运行摘要。

### 5.2 共享约定（`common.py`）

| 约定 | 内容 | 依据 |
|---|---|---|
| 时间轴 | 所有分析先在完整录音上计算，再按时间范围取用；图一律使用完整原始时间轴，不对单个音素做时间归零、拉伸或增益归一化 | 方案 §1、§2.1 |
| 边界显示 | 讯飞边界画成竖虚线，音素标签放在坐标轴内顶部（带半透明白底）；分析窗伸出录音边界的区域用灰色斜线标出 | 方案 §2.1 |
| 发音人参数 | `SpeakerProfile(f0_floor, f0_ceiling, formant_ceiling)`；共振峰上限初始值女声 5500 Hz、男声 5000 Hz | 方案 §3.1、§5.1 |
| F0 | Praat `To Pitch (filtered ac)`，时间步长 5 ms；候选数、静音阈值、清浊阈值、八度代价等与后端 `f0_pipeline` 主趟一致；无声帧记 NaN，不当作 0 Hz | 方案 §5.1 |
| 元音区间 | `vowel_interval()`，见下表 | 方案 §3.3 |
| 低能量帧 | 25 ms 短时 RMS 电平比所在音节最大电平低 30 dB 以上（`low_level_mask`）。不用 Praat 强度判定：它的分析窗长约 3.2/最低基频，会抹平音节尾部的快速衰减 | — |
| dB 参考 | 语谱图沿用 Praat 绘图参考 4×10⁻¹⁰（`PRAAT_POWER_REF`），其余功率谱用 1.0；不按单个文件的最大值归一化 | 方案 §8.2 |
| 输出 | 图 dpi 150；CSV 为 UTF-8 带 BOM，便于 Excel 直接打开 | — |

**元音区间规则**（各模块共用，保证同一录音的元音区间口径一致）：

| 端点 | 规则 | 原因 |
|---|---|---|
| 起点 | 韵母内第一个「有 F0 且非低能量」的帧；与对齐起点相差不足 10 ms 时沿用对齐起点 | 讯飞有时把送气段划进韵母（验证集 chi1 的讯飞声母只有 50–70 ms），送气噪声不应参与元音分析 |
| 终点 | 从韵母终点前最后一个有效帧起，沿连续有效帧向后延伸：允许 1 帧缺口，且相邻有效帧 F0 相差小于 7 st；上限为下一音节起点或录音结束；延伸不足 10 ms 时沿用对齐终点 | 讯飞常截掉尾部弱衰减段（语料中最多约 110 ms）；F0 不连续的段多为嘎裂处的倍频/半频误检 |
| 区间内部 | 没有 F0 的帧（嘎裂、漏检）仍属于区间，由各模块标为缺失，不做插值 | 方案 §5.3 |

区间来源会写进数值表：`vowel_start_source` 为 `alignment` 或 `first_voiced`；`vowel_end_source` 为 `alignment` 或 `voicing_extended`。

### 6.1 `prosody.py`：波形、F0 与声调、强度

|---|---|---|
| `01_waveform.png` | 振幅随时间的变化、音素边界 | 第 0 声道波形（±1）；标题注明峰值 dBFS 和「文件已做峰值归一化」 |

| `05b_f0_semitone.png` | F0 相对高低（图 B） | 半音曲线 12·log₂(F0/F_ref)；图上注明 F_ref 的数值和来源 |
| `05c_f0_normalized.png` | 时间归一化的声调轮廓（图 C） | 横轴 0–100%，上面板为 Hz，下面板为半音；缺失点处断开连线；标题注明「有效 k/11」 |
| `05d_f0_derivative.png` | 声调升降速率与转折点（图 D） | 上面板为平滑后的半音曲线和转折点（局部极大/极小），下面板为 dF0/dt（st/s） |
| `05e_f0_boundary.png` | 两个音节交界处的 F0（方案 §5.3） | 交界 ±100 ms 的 F0 细节和导数；只在录音包含 ≥2 个音节时生成 |
| `06_intensity.png` | 能量随时间的变化 | Praat 强度（相对 dB，未校准）与 25 ms 短时 RMS（dBFS）；两根纵轴取相同的 60 dB 跨度，斜率可以直接比较 |

**测量方法**：

| 项目 | 方法 |
|---|---|
| 宽范围复测 | 50–600 Hz 再提取一次。两次结果在共同有声帧上的中位数之比超出 [0.6, 1.67]，或逐帧比值接近 2/0.5（相差 12 st 以内 1 st）的帧 ≥3 个且占比 ≥10% 时告警 |
| 局部倍频/半频检测 | 相邻有声帧（跨无声缺口也比较）相差 ≥7 st 处切段。判据有两条：(1) 每个切段边界两侧各取最多 5 帧的局部中位数，相差 ≥7 st 时把帧数较少的一侧判为疑似；(2) 从帧数最多的主段向两侧逐段比较中位数，已判疑似的段不作为后续比较的参照。差值在 9–15 st 记为「疑似倍频/半频」，其余记为「疑似跳变（非整八度）」。疑似帧不做 ×2/÷2 校正，在声调统计和 11 点取样中记为 NaN |
| 半音参考 F_ref | 优先取批处理传入的发音人语料中位数（`context["f0_ref_hz"]`），否则取本文件 F0 中位数并写 warning |
| 11 点取样 | 区间为 [音节内第一个有声帧, 韵母有效终点]（包含 m/n/l 等浊声母），取 0%, 10%, …, 100% 共 11 个位置；只有相邻两帧都有 F0 时才线性插值，否则记为 NaN |
| dF0/dt | 只在连续有声段内计算：先在半音域做 Savitzky-Golay 平滑（9 帧 ≈ 45 ms，2 阶；段长不足时降为不小于 5 的最大奇数，不足 5 帧不求导），再求导 |
| 转折点 | 平滑半音曲线上突出度 ≥0.5 st 的局部极值 |
| 强度 | Praat `To Intensity`（minimum pitch = F0 下限，5 ms，不减均值）；另算 25 ms 窗、5 ms 步长的 RMS（录音边界处截短，不补零） |

**数值表**：`prosody_timeseries.csv`（逐帧）、`tone_stats.csv`（每个音节一行），字段见 7.4 节。

| `04b_mfcc.png` | MFCC 及其一阶、二阶差分（方案 §2.4 中的可选压缩特征） | log-mel（25 ms 窗、10 ms 帧移，固定参考 1.0，下限 10⁻¹⁰，不按单个文件做 top_db 裁剪）→ DCT-II（正交）取 13 个系数；Δ/ΔΔ 用 Savitzky-Golay（宽度 9 帧）；色标按 C1–C12 的对称范围确定（C0 只反映总能量，不参与）；首尾 ±45 ms 的边缘拟合区用斜线标出 |

- Praat 实际采用的时间步长和频率步长（dx/dy）以对象读数为准，写入 `params`（方案 §2.3 要求检查实际值）。

**数值表**：`04b_mfcc.csv`（逐帧 13 个系数及 Δ、ΔΔ）。

### 6.3 `formants.py`：共振峰、元音动态与谐波谱

**测量方法**：

| 项目 | 方法 |
|---|---|
| 共振峰 | Praat `To Formant (burg)`：时间步长 5 ms，最多 5 个共振峰，窗长 25 ms，预加重 50 Hz；提取 F1–F4 与带宽 B1–B4 |
| 共振峰上限的选择 | 每个韵母在发音人初始值 ±500 Hz 内以 250 Hz 为步长取 5 个候选，分别运行 Burg；对每个共振峰的轨迹做时间的三次多项式拟合，取残差均方根除以该共振峰的中位数，F1–F3 求和后分数最低者入选；只考虑满足 F1<F2<F3 且有效帧 ≥5 的候选。只在窄范围内修正换轨：放宽到 ±1000 Hz 时，平滑度无法排除峰合并或伪峰 |
| 有效帧 | 位于元音区间内、非低能量帧、非离群点；**不逐帧要求 F0**（嘎裂和气声段常检测不到 F0，但仍有共振峰结构） |
| 离群点 | F1–F3 中任一条轨迹偏离 5 帧中值滤波结果超过 20% 的帧；派生量（11 点值、中位数）计算时排除 |
| 敏感性检查（方案 §9） | 在所选上限 ±500 Hz 上重跑，比较韵母有效帧上 F1–F3 的中位数；F1 或 F2 变化超过 15% 时告警「该共振峰对 ceiling 敏感，自动值不宜直接采信」 |
| 元音动态 | 元音区间 0%…100% 共 11 个位置的 F1/F2/F3/F0；另记录默认上限下 50% 处的 F1/F2（`F1_default_p50`、`F2_default_p50`），便于跨韵母比较 |
| LPC 包络 | 重采样到 2 × 共振峰上限，阶数 = 2 × 上限/1000 + 2（例如 5500 Hz 时为 13 阶），预加重 50 Hz；返回前扣除预加重滤波器的幅度响应，与原始频谱处于同一谱倾斜；整体平移到谐波峰处的中位偏差，便于叠加对照 |
| H1–H4、A1–A3 | H_k 为 k·F0 ± 0.15·F0 内的谱峰；A_k 为 F_k ± 10% 内最强谐波的 dB；表中的 H1−H2、H1−A1 是**未修正值**（共振峰修正版在发声态模块） |

**对外接口**：`vowel_formants(x, sr, aln, syll_index, profile) -> VowelFormants`，返回某个韵母按上述规则得到的共振峰结果（所选上限、元音区间、帧时间、F1–F4、B1–B4、有效帧标志、F0）。发声态模块导入它，保证两个模块用的是同一份 F1–F3。

**数值表**：`formant_tracks.csv`、`vowel_dynamics.csv`、`harmonic_slices.csv`。

| 浊音起点 | Praat `To PointProcess (periodic, cc)`（F0 范围取发音人参数）的声门脉冲中，第一个满足以下条件的脉冲：从它开始至少连续 4 个脉冲，相邻间隔都小于 1.25/F0 下限，且脉冲序列持续 ≥60 ms（容许缺一个周期）。持续时间条件用来排除送气噪声中孤立的伪脉冲簇 |
| 除阻 | 1–12 kHz 频带能量（1 ms 步长、3 ms 窗）在 [讯飞声母起点, 浊音起点 − 2 ms] 内，第一个「2 ms 内上升量达到区间最大上升量 50%」的帧，即最早的强瞬态；分析窗伸出录音起点的帧不参与。浊音起点距录音起点 ≤3 ms 或搜索区间不足 2 ms 时，标记为 `release_truncated`（爆破可能被裁剪） |

| 送气时长（塞音） | VOT − 爆破时长；爆破为 NaN 时取整个 VOT，记 `aspiration_source = vot_burst_inseparable` |

| 摩擦段（擦音） | 起点为讯飞声母起点；终点取讯飞声母终点与浊音起点中较早者（`frication_end_source = alignment / voicing_onset`），二者相差超过 20 ms 时写 warning |

| 谱矩 M1–M4（方案 §4.2、§8.3） | 去直流 → Hann 窗 → 补零到 4 ×（不小于片段长度的 2 的整数次幂）→ 以功率谱为权重：M1 谱重心、M2 标准差、M3 偏度、M4 峰度。25 ms 窗、5 ms 步长，帧中心落在摩擦段（塞擦音为摩擦本体）的 20%–80% 内。两套频带 500–12000 Hz 与 500–8000 Hz（方案 §9 的频带敏感性检查），每帧另记谱峰频率 |
| 平均谱 | 20%–80% 区间内的 Hann 多帧平均，以及 multitaper 单次估计（DPSS，NW=4，K=7）；按窗能量归一化，不同窗长的估计可以叠加比较 |
| 平均谱参数（近似 Koenig 2013 / Shadle 2023 的频段划分） | FM：3–7 kHz 内的主峰（AmpM 为其幅度）；次峰：与主峰相距 ≥1 kHz 的第二高局部峰；AmpD = FM 幅度 − 0.5–3 kHz 内的最小值；Fh：7–12 kHz 内的最大值；AmpRange = 3–7 kHz 均值 − 0.5–3 kHz 均值；HighLevelD = 8–12 kHz 均值 − 2–4 kHz 均值 |

| 共振峰过渡 | Praat Burg，单独使用 15 ms 窗（方案默认 25 ms，首帧位置更早）；塞音以除阻为参照，塞擦音以浊音起点为参照，取 +10/+20/+40 ms 处的 F1–F3 |

**测量方法**：

| 项目 | 方法 |
|---|---|
| 分析帧 | 元音区间内 5 ms 网格；谐波测量只在有 F0 的帧上进行 |
| 谐波振幅 | 以帧时刻为中心、3 个基音周期长的 Hann 窗（VoiceSauce 的做法），FFT 长度不小于 4 倍窗长。H1、H2、H4：k·F0 ± 0.1·F0 内的最大谱值；A1–A3：F1–F3 ± 10% 内最强谐波；H2k、H5k：2000 Hz、5000 Hz 附近 ±F0/2 内最强谐波 |
| 共振峰修正（Iseli & Alwan，方案 §6.1 中带 * 的量） | 单个共振峰 (F, B) 在频率 f 处的修正量：r = e^(−πB/Fs)，ωₓ = 2πF/Fs，ω = 2πf/Fs，corr = −10·[log₁₀(r²+1−2r·cos(ωₓ+ω)) + log₁₀(r²+1−2r·cos(ωₓ−ω))] + 20·log₁₀(r²+1−2r·cos ωₓ)。H1*、H2*、H4* 扣除 F1、F2 在相应谐波处的修正量；A1*、A2* 扣除 F1–F2 的修正量，A3* 扣除 F1–F3 的修正量；H2k* 用 F1–F3 修正；H5k 不修正 |
| 修正用的共振峰 | 来自 `formants.vowel_formants()`，与 07 号图同一份结果（同一个上限）；带宽用 Burg 实测值，限制在 [30, 600] Hz（与 VoiceSauce 默认的公式带宽不同）。共振峰无效帧上，所有依赖共振峰的量都记为 NaN |
| HNR | Praat Harmonicity (cc)，5 ms，minimum pitch = F0 下限；−200 dB（无声）记为 NaN。分频带：先用 Praat `Filter (pass Hann band)` 得到 0–500/1500/2500/3500 Hz 信号（平滑 100 Hz），分别计算后取韵母有声帧的均值 |
| CPP / CPPS | Praat PowerCepstrogram（pitch floor = F0 下限，5 ms，最高频率 5000 Hz，预加重 50 Hz），用 `To Table (cepstral peak prominences)` 得到逐帧值：峰值搜索范围为发音人 F0 范围，趋势线拟合 0.001 s 到倒频上限，指数衰减，稳健拟合。CPP 用原始倒谱图，CPPS 用 `Smooth`（时间 0.01 s、倒频 0.001 s）之后的倒谱图。另存整段录音的 `Get CPPS` 作参考，平滑参数相同 |
| SHR（简化谱法） | SHR 单独使用 6 个周期的 Hann 窗，补零到 8 倍窗长；SH = Σ 次谐波 (k−0.5)·F0 处的幅度，H = Σ 谐波 k·F0 处的幅度（k·F0 < 4000 Hz），两类位置都在 ±0.05·F0 内取峰；SHR = SH/H。仿照 Sun (2002) 的定义思想，**不是原算法**。正常发声基线约 0.03–0.07，嘎裂处明显升高 |
| 周期 / Jitter / Shimmer | Praat PointProcess 的逐周期长度与峰值振幅；Jitter (local)、Shimmer (local) 使用 Praat 常用参数（周期 0.0001–0.02 s，周期因子 1.3，振幅因子 1.6）。方案 §6.5 不建议作为核心指标：有效周期数少于 20 时写 warning |

**数值表**：`phonation_timeseries.csv`（逐帧）、`phonation_stats.csv`（每个韵母一行）。

## 9. 已知局限

- **对齐粒度**：讯飞只给声母和韵母两段。复合韵母内部、鼻韵尾都没有对齐边界（鼻韵尾用声学方法估计）。零声母的伪声母段是讯飞插入的占位段。
- **语料特点**：录音紧贴语音起点裁剪；每个文件都单独做过峰值归一化，跨录音比较绝对强度没有意义，只能在单个文件内比较。
- **个别测量不可靠，均可识别**：
  - 女声 [i] 的 F2 对共振峰上限敏感，有敏感性告警的样本不宜直接采信（例如 qi2_FV1 的 F2 只有约 1290 Hz）。
  - 少数女声 /m/ 的 N1 带宽很大（数百 Hz），结果不可信。
  - 音节尾部弱能量帧的修正谐波振幅只作参考。
- **处理时间**：每条录音运行全部模块约需 7–13 s，适合离线批量处理或异步执行。
- **后端接入**：后端检测流程目前只使用音节级时间，讯飞返回的音素时间戳在 `provider_xfyun._result_from_parsed` 中被丢弃；接入时需要透传这些时间戳。
