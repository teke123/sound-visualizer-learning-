# 一、研究结论与总体方案

对于已经准确完成音素级强制对齐、且只包含一到两个音节的高质量录音，我建议采用一套以线性频率 STFT 频谱为核心、以音素专用声学分析为补充、以基频和发声态分析为独立模块的处理体系。

关键并不是生成尽可能多种频谱图，而是让每张图保留一类不同的声学信息。因为很多常见表示存在信息重叠，例如 Mel 频谱、MFCC 和线性频谱都来自短时频谱变换，但它们的频率分辨率、压缩程度和保留的信息不同，不能相互替代。

我的建议分为三个层次：

1. 通用层：所有录音都生成。 波形图、宽带频谱、窄带频谱、Mel 频谱、F0 轨迹、共振峰轨迹、强度轨迹。
2. 音素层：依据实际包含的音素生成。 塞音爆破与 VOT、擦音噪声频谱及谱矩、塞擦音分阶段分析、鼻音反共振、近音的共振峰过渡、元音的动态共振峰轨迹。
3. 发声态与声调层：依据实际发音特征生成。 谐波振幅、谱倾斜、HNR、CPP/CPPS、次谐波、声调 F0 轨迹与转折点。

这里有一个重要的实验设计原则：所有分析都保留原始录音时间轴，不能在各音素切片后分别进行独立的时间归零、增益归一化或频谱自动缩放。 每个音素可以单独裁图，但必须保留前后声学过渡和原始边界标记。这样才能观察辅音释放、元音起始、协同发音和声调起点之间的联系。

这个体系的依据主要来自经典声学语音学研究（Lisker & Abramson, 1964；Forrest et al., 1988；Jongman et al., 2000）、声调研究（Xu, 1997, 1999）、发声态研究，以及 Praat 的短时频谱、基频、共振峰和倒谱分析方法。以下给出可以直接落实的参数。

## 二、首先建立统一的切分与分析框架

### 2.1 不能只按音素边界直接裁剪音频

强制对齐给出了音素起止时间，但声学分析的时间窗口与音素的实际时间区间不是同一概念。

例如，分析一个起始塞音时，如果只截取塞音自身的区间，就会失去释放爆破之后进入元音的共振峰过渡信息；分析一个元音时，如果切掉前一个辅音的尾部，也会失去元音开始阶段的过渡信息。

建议保留三种时间尺度：

| 分析对象 | 推荐时间范围                    | 用途                              |
| -------- | ------------------------------- | --------------------------------- |
| 整个录音 | 完整的一至两个音节              | 声调、音节间协同发音、整体节奏    |
| 音节     | 音节起止点前后各延伸约 30–50 ms | 辅音与元音衔接、F0 轨迹、韵母结构 |
| 音素     | 音素起止点前后各延伸约 20–40 ms | 音素内部声学特征、相邻音素过渡    |

这些是建议的初始取窗值，而不是要求音素之间存在实际重叠的重新切分结果。最终边界仍然采用原来的强制对齐标记。尤其是靠近录音首尾的音素，应使用原始波形能够提供的实际上下文，不应通过补零制造虚假的声学信息。

还有一个实现细节：STFT 应直接对完整录音计算，再按时间范围提取图像，而不是先裁切出每个音素再进行 STFT。 因为中心化分析窗需要访问当前时刻两侧的信号，先切音素可能产生边缘效应。

建议在 TextGrid 中保留以下标注层：

- Syllable：音节边界及音节文本。
- Phoneme：音素边界及 IPA 标签。
- Voicing：实际有声区间和无声区间。
- Landmark：塞音闭塞、爆破释放、浊音起始、擦音起始与结束、声调转折点等声学事件。

Praat 的 TextGrid 支持区间层和时间点层，适合存储这些信息。【Cite ref="turn895812search4"】

### 2.2 统一信号处理的基础条件

首先保留原始采样率，不要为了统一参数而盲目降采样。对于辅音中的高频摩擦噪声，这一点尤其重要。若需要观察到 15 kHz，理论上采样率至少要达到 30 kHz；实际可优先保留原始 44.1 kHz 或 48 kHz 录音。16 kHz 录音的奈奎斯特频率只有 8 kHz，无法还原 8 kHz 以上的原始声学信息。Shadle 等人在 2023 年的研究专门指出，高频信息对擦音分析有实际价值。【Cite refs=turn544978search1turn544978search3】

其次，保留原始振幅。不要对每个音素单独做峰值归一化，否则会破坏辅音和元音之间的相对能量差异。对于强度分析，应使用同一套 dBFS 标尺；没有经过声压级校准的麦克风，不能将普通数字音频幅度直接称作 dB SPL。

### 2.3 两张最重要的基础频谱图：宽带和窄带

这是整个处理流程中最值得优先生成的两类图。Praat 对这两种设置有明确的声学依据。

A. 宽带频谱（Broadband Spectrogram）

推荐窗口长度 5 ms，时间步长 1–2 ms，Gaussian 窗，频率显示范围 0–8 kHz（16 kHz 录音）或 0–12 kHz（高采样率录音）。

主要用于观察音素边界、爆破释放、VOT、浊音起始、擦音、鼻音以及共振峰的时间变化。

B. 窄带频谱（Narrowband Spectrogram）

推荐窗口长度 30 ms，时间步长 5 ms，Gaussian 窗，频率显示范围 0–5 kHz，必要时扩展到 8 kHz。

主要用于观察谐波间距、基频、谐波结构、声带振动、低频鼻音共振及发声态。

这两个参数并不是经验上随意指定的。Praat 手册给出了 Gaussian 窗的 −3 dB 带宽计算公式：

\\[ B\_{-3dB}=\frac{1.29828}{T} \\]

其中 \\(T\\) 是窗口长度（秒）。因此，5 ms 对应约 260 Hz 带宽，而 30 ms 对应约 43 Hz 带宽。短窗有较好的时间分辨率，长窗有较好的频率分辨率，两者存在不可消除的权衡。【Cite refs=turn988530view2turn568223search0】

推荐把图像参数固定为：

| 参数                | 宽带     | 窄带     |
| ------------------- | -------- | -------- |
| 窗口长度            | 5 ms     | 30 ms    |
| 时间步长            | 1–2 ms   | 5 ms     |
| 窗形                | Gaussian | Gaussian |
| 频率分辨率设置      | 20–50 Hz | 10 Hz    |
| 显示频率上限        | 8–12 kHz | 5–8 kHz  |
| Dynamic range       | 50 dB    | 50 dB    |
| Dynamic compression | 0        | 0        |

Praat 可能根据窗口长度和计算限制调整实际时间步长及频率步长，因此应检查实际生成的 Spectrogram 对象的 `dx` 和 `dy`，而不仅仅检查界面中输入的数值。【Cite refs=turn568223search0turn568223search1】

另外，建议对宽带频谱再生成一个辅助版本：设置显示预加重为 +6 dB/octave，以增强高频共振峰的可见性。但是，擦音谱矩、爆破谱幅度以及声学能量测量必须使用未预加重的信号或明确补偿后的频谱，不能把这种视觉增强后的图像当作原始频谱。Praat 的预加重本质上是改变高频与低频的相对幅度。【Cite ref="turn568223search1"】

### 2.4 第三种基础图：Log-Mel 频谱

建议也生成，但其作用与前两张不同。

推荐参数：

| 参数           | 设置                                  |
| -------------- | ------------------------------------- |
| 窗口长度       | 25 ms                                 |
| 时间步长       | 5 或 10 ms                            |
| FFT 长度       | 不小于窗口采样点数的最近 2 的整数次幂 |
| Mel 滤波器数量 | 80                                    |
| 低频边界       | 0 Hz                                  |
| 高频边界       | 不超过原始奈奎斯特频率                |
| 频谱类型       | Power Mel Spectrogram                 |
| 数值变换       | 10 log10 转换                         |
| 显示           | 对数功率热力图                        |

例如，16 kHz 录音可以取 `win_length=400`、`n_fft=512`、`hop_length=80`（5 ms），`n_mels=80`、`fmax=8000`。对于 48 kHz 录音，可以采用 25 ms 对应的 1200 个采样点，FFT 长度 2048。

Librosa 官方接口支持以上参数，包括 Mel 滤波器数量、上下限频率、窗口和步长。【Cite ref="turn568223search3"】

Mel 频谱将线性频率轴映射到 Mel 标度，因此低频与高频的分辨率分布不同。它适合观察整体的感知频率能量结构，但不能替代线性频率 STFT，尤其不适合单独分析高频擦音峰值、精细谐波或窄带鼻音反共振。

MFCC 则是在对数 Mel 频谱上进一步进行倒谱变换。建议只将其作为可选的压缩特征图，采用 13 个系数及其一阶、二阶差分，25 ms 窗口、10 ms 步长。它不应成为主要声学证据，因为频谱细节在这一变换中已经被压缩。

## 三、元音分析：需要提取哪些信息

元音不能只使用一张频谱图判断。最重要的声学信息是共振峰（Formants）、共振峰随时间的变化、基频、谐波结构和能量分布。

### 3.1 共振峰分析：F1、F2、F3、F4

建议使用 Praat 的 `Sound: To Formant (burg)...`，即 Burg 算法进行 LPC 共振峰估计。

推荐初始参数：

| 参数                       | 推荐值         |
| -------------------------- | -------------- |
| Algorithm                  | Burg           |
| Time step                  | 0.005 s        |
| Window length              | 0.025 s        |
| Maximum number of formants | 5              |
| Pre-emphasis from          | 50 Hz          |
| Formant ceiling            | 根据说话人调整 |

Praat 官方手册给出的参考上限是：成年男性约 5000 Hz，成年女性约 5500 Hz，儿童约 8000 Hz。这些只是初始值，手册明确指出说话人差异可能较大，不能单纯按照性别固定上限。【Cite refs=turn988530view3turn568223search4】

需要生成三种结果：

图 1：F1、F2、F3 随时间变化的轨迹图。 横轴为时间，纵轴为频率，分别画出 F1、F2、F3，最好叠加在宽带频谱上，但同时保留一张单独的轨迹图，防止频谱背景影响观察。

图 2：F1-F2 元音空间图。 横轴是 F2，纵轴是 F1（通常采用反向纵轴，以符合传统元音空间表示）。标出元音从 0% 到 100% 的轨迹方向。这能够体现舌位高度和前后变化所对应的声学差异。

图 3：元音不同位置的线性频谱与 LPC 包络。 每个元音取多个代表性时刻，显示频谱、LPC 共振峰包络以及 F1-F3 的位置。推荐至少分析 20%、50%、80% 三个时间位置。

为什么需要三种图？因为 F1/F2 的单个数值反映不了动态变化。尤其是双元音，元音的身份可能体现在 F1、F2 随时间的整体轨迹，而非某一个时刻的数值。Elvin、Williams 和 Escudero（2016）对单元音和双元音的研究也表明，动态共振峰轨迹提供了静态测量无法完整表达的区分信息。【Cite ref="turn505171search7"】

因此：

- 单元音：提取稳定部分的 F1、F2、F3，同时保留完整轨迹。
- 双元音：保留从起始到结束的完整 F1、F2、F3 变化，不应只取中点。
- 短元音：至少使用 20%、50%、80% 三个位置，避免将单个中点当成整个元音的代表。
- 卷舌元音、带明显 rhotic 特征的元音：增加 F3 轨迹和频谱包络的观察。
- 鼻化元音：额外进行鼻腔共振与反共振分析，见后文。

需要特别强调：LPC/Burg 只是共振峰估计方法，不能保证每个峰都是正确的声道共振。应当同时检查频谱图和各时刻的 LPC 包络，并对 Formant ceiling 做敏感性检查，例如将初始上限上下调整 300–500 Hz，观察 F1/F2/F3 是否发生不合理跳变。Praat 自己也明确说明，LPC 可能产生用于拟合整体谱倾斜的伪峰。【Cite refs=turn988530view3turn568223search4】

### 3.2 元音谐波结构和频谱包络

元音是有声的周期性信号，除了共振峰之外，还需要观察声源谐波与声道滤波的组合结果。

建议生成：

- 低频谐波细节图：0–2000 Hz。
- 中高频谐波结构图：0–8000 Hz。
- 元音稳态频谱切片：25–40 ms 分析窗。
- 谐波峰值连线图：标记 H1、H2、H3、H4 等谐波幅度。
- LPC 包络叠加图：显示声道共振峰。

这里需要区分两个概念：

一是谐波频率之间的距离，主要与 F0 有关；二是谐波振幅的变化趋势，既与声带振动方式有关，也会受到声道共振峰的影响。不能直接把某条谐波的幅度变化解释成声带发声方式的变化。

### 3.3 元音的时间变化与持续时间

对每一个元音，建议输出一组时间归一化数据：

\\[ t=\\{0\\%,10\\%,20\\%,\ldots,100\\%\\} \\]

在这些位置分别计算 F1、F2、F3 和 F0，形成元音的动态特征表及轨迹图。如果有多个元音，还能直接对比它们的动态频谱特征。

需要注意，时间归一化是为了使不同持续时间的音节可以进行位置对齐，并不意味着要将原始音频时间轴拉伸。原始时长仍然需要独立记录。

## 四、辅音分析：不同发音方式必须采用不同测量策略

辅音的声学结构差异比元音更大，因此不建议给所有辅音使用同一种分析方法。

### 4.1 塞音（Plosives / Stops）

典型塞音包括双唇音、齿龈音、软腭音，以及不同清浊和送气类别。

核心信息包括：

1. 闭塞阶段（closure）。
2. 闭塞期间是否存在声带振动。
3. 爆破释放瞬间（burst）。
4. VOT（Voice Onset Time）。
5. 爆破噪声的频谱形状。
6. 爆破之后到元音开始阶段的共振峰过渡。

C. 爆破到元音的共振峰过渡图

观察释放后约 10–40 ms 内 F1、F2、F3 的动态变化。

需要提取的参数：

| 参数                   | 单位         | 具体意义                         |
| ---------------------- | ------------ | -------------------------------- |
| Closure duration       | ms           | 闭塞持续时间                     |
| Burst onset            | 时间点       | 爆破开始位置                     |
| Burst duration         | ms           | 爆破能量持续时间                 |
| VOT                    | ms           | 爆破释放到有声振动开始的时间差   |
| Prevoicing duration    | ms           | 爆破之前存在的浊音时间           |
| Aspiration duration    | ms           | 爆破之后到规则发声之前的送气时间 |
| Burst peak frequency   | Hz           | 爆破频谱的主要峰值位置           |
| Burst spectral moments | Hz及无量纲值 | 爆破频谱的统计分布               |
| F1/F2/F3 transitions   | Hz           | 爆破后的共振峰轨迹               |

VOT 的基本定义是：

\\[ VOT=t\_{\mathrm{voicing\ onset}}-t\_{\mathrm{release}} \\]

因此，预浊音塞音可以出现负 VOT，送气塞音通常表现为较长的正 VOT。

经典文献 Lisker & Abramson（1964）对多个语言的塞音浊音对立进行了声学测量，是 VOT 研究的基础文献。【Cite refs=turn262580search99turn262580search5】

塞音的发音部位不能仅仅依靠爆破峰值判断。爆破谱形和后续元音的 F2/F3 过渡都很重要。关于塞音部位识别的研究发现，双唇、齿龈、软腭塞音具有不同的爆破谱形特征，而爆破后的共振峰过渡也提供了关键的部位信息。【Cite refs=turn895812search5turn895812search7】

所以，塞音建议采用三组图，而不是只生成一张普通频谱图。

特殊情况：如果包含喉化塞音、内爆音或喷音，应额外保留波形中闭塞期间的振动、释放时的瞬态能量和释放后声带振动的变化。若包含搭嘴音（click），则要把前后爆破事件作为独立时间标记来分析，不能直接套用普通塞音的单一释放模式。

### 4.2 擦音（Fricatives）

这是最需要进行专门频谱处理的辅音类别之一。

擦音的主要声学能量来自湍流噪声，其频谱分布与发音部位、发音方式及声道形状密切相关。

例如，典型的 sibilants（咝音）具有较明显的高频能量峰，而非咝音的频谱通常比较分散或没有明显的高频集中峰。因此，只提取一组简单的 F1、F2 共振峰不能充分描述擦音。

核心参数：四个 Spectral Moments。

设频谱权重归一化后为 \\(w_i\\)，对应频率为 \\(f_i\\)，建议保留以下四项：

\\[ M_1=\sum_i w_i f_i \\]

\\[ M_2=\sqrt{\sum_i w_i(f_i-M_1)^2} \\]

\\[ M_3=\frac{\sum_i w_i(f_i-M_1)^3}{M_2^3} \\]

\\[ M_4=\frac{\sum_i w_i(f_i-M_1)^4}{M_2^4} \\]

这里的 \\(M_1\\) 为谱重心（Center of Gravity），\\(M_2\\) 为标准差，\\(M_3\\) 为偏度，\\(M_4\\) 为峰度。上面的定义采用频谱功率作为权重，实际实施时需要固定频谱权重定义、频率上下限和平均方法，不要在不同音素之间混用幅度谱与功率谱。

这些指标有经典研究基础：Forrest、Weismer、Milenkovic 和 Dougall（1988）将频谱作为概率分布并利用谱矩描述塞音和擦音；Jongman、Wayland 和 Wong（2000）进一步研究了擦音的谱峰、谱矩、持续时间、相对振幅和 F2 起始频率。【Cite refs=turn262580search1turn988530view1】

但这里有一个非常值得纳入方案的更新：不要把四个谱矩当作擦音的完整描述。

Shadle（2023）指出，传统谱矩会受到分析频带、谱的归一化及平滑程度的影响，而且对于不符合近似高斯分布的非咝音，四个谱矩可能不能充分刻画频谱形状。Shadle、Chen、Koenig 和 Preston（2023）进一步研究了高频擦音频谱的分析方法。【Cite refs=turn544978search8turn544978search1】

因此，在四个谱矩之外，建议同时提取：

| 参数                         | 含义                           | 需要生成的图或数值 |
| ---------------------------- | ------------------------------ | ------------------ |
| Spectral peak frequency (FM) | 主频谱峰所在位置               | 频谱曲线及主峰标记 |
| Spectral peak amplitude      | 主峰强度                       | 频谱峰值           |
| Secondary peak               | 次峰位置及强度                 | 频谱曲线           |
| AmpD                         | 主峰与低频局部谷值之间的幅度差 | 幅度差             |
| High-frequency maximum (Fh)  | 高频区最大振幅                 | 高频频谱曲线       |
| AmpRange                     | 低频和高频区域之间的幅度差     | 频带能量差         |
| HighLevelD                   | 高频与参考频率区域的幅度级差   | 高频动态变化图     |

尤其是非咝音，如 /f/、/θ/ 一类，不应只依赖 COG 来判断。Shadle 等人（2023）对最高 15 kHz 的擦音频谱进行分析，显示高频能量和随时间变化的频谱指标能够补充传统谱矩的信息。【Cite ref="turn544978search3"】

对于浊擦音，还要增加有声成分与噪声成分的区分，提取 F0、HNR、谱倾斜和浊音占比。单纯的频谱重心无法表达浊擦音内部的周期性结构。

### 4.3 塞擦音（Affricates）

塞擦音具有明显的阶段性，建议分成三个子阶段处理：

\\[ \text{闭塞}\rightarrow\text{爆破释放}\rightarrow\text{摩擦噪声} \\]

需要提取：

- 闭塞持续时间。
- 释放爆破的瞬态频谱。
- 摩擦噪声的总持续时间。
- 总音段时长。
- 摩擦阶段的四个谱矩。
- 摩擦阶段的主峰频率及高频能量。
- 向后续元音过渡时的 F1、F2、F3。

额外计算：

\\[ R\_{\mathrm{fric}}= \frac{T\_{\mathrm{frication}}} {T\_{\mathrm{affricate}}} \\]

这个比值可以描述一个塞擦音中摩擦阶段占整个音段的比例，但它应与总时长、爆破和频谱信息一起看，而不能单独决定音类。

塞擦音与塞音最重要的区别之一，是释放后持续的摩擦噪声，因此要将摩擦阶段专门作为擦音频谱分析对象，而不是只测量 VOT。【Cite ref="turn465158search14"】

### 4.4 鼻音（Nasals）

鼻音是一个容易被一般频谱分析遗漏的类别，因为鼻音的频谱不仅包含共振峰，还包含反共振（Antiresonance）。

鼻腔与口腔之间的耦合会产生额外的声学共振和反共振，尤其会改变低频部分的谱形以及某些共振峰的强度和带宽。

建议生成三张图：

1. 低频细节图：0–2000 Hz，显示鼻音低频共振及鼻音谐波结构。
2. 0–8000 Hz 宽带频谱图：观察鼻音段内部的谱形和与元音的过渡。
3. 高频分辨率频谱图：观察频谱峰、谱谷以及反共振造成的能量衰减。

需要测量：

| 参数                      | 意义                       |
| ------------------------- | -------------------------- |
| Nasal resonance frequency | 鼻腔共振峰位置             |
| Antiresonance frequency   | 反共振频率                 |
| Resonance bandwidth       | 共振峰带宽                 |
| Spectral zero depth       | 反共振位置的能量衰减       |
| F1/F2 transition          | 相邻元音共振峰过渡         |
| Nasal murmur duration     | 鼻音低频共振阶段的持续时间 |

鼻腔的第一个共振在成年说话人中经常位于约 250 Hz 附近，但具体位置与个体鼻腔结构和开口状态有关，不适合把 250 Hz 作为固定检测频率。声道反射也可以造成多个频谱零点。【Cite ref="turn465158search0"】

Macquarie University 的鼻音分析资料还指出，鼻音及鼻化元音常出现低频鼻腔共振、反共振和共振峰带宽增加等现象。【Cite ref="turn465158search2"】

实现时有一个特别重要的技术细节：普通 Burg/LPC 默认采用全极点模型，而鼻音的声学传递函数包含零点。因此不能仅使用 LPC 拟合鼻音谱形。建议以高分辨率线性频谱为基础，必要时采用 pole-zero 或 ARMA 模型分析频谱零点。

### 4.5 近音、滑音、边音和颤音

这类音素具有周期性声源，但声学变化主要体现在共振峰的结构和过渡上。

滑音 /j/、/w/：建议提取 F1、F2 的完整动态轨迹，并观察与邻接元音的连续变化。不要只保存滑音中间某一瞬间的频谱。

边音 /l/：建议重点保留 F1、F2、F3，以及是否出现反共振或明显的谱能量衰减。尤其要把辅音与前后元音组成一个连续时间序列分析。近期 IPA 研究也采用了 LV/VL 整体过渡方式分析边音，而不仅仅是边音中点。【Cite ref="turn465158search3"】

近音 /r/ 和卷舌音：建议额外观察 F3，特别是具有 F3 降低特征的 rhotic 类型。但是，不能把英语近音 /ɹ/ 的典型 F3 现象直接套用到所有语言的 /r/、闪音、颤音或其他 rhotic 类型。

闪音与颤音：除共振峰之外，增加 0–10 kHz 的高时间分辨率波形图，提取周期性闭塞、振幅下降、释放脉冲和各次接触之间的间隔。若有多个接触事件，记录各事件的时间点及持续时间。

对这些音素，建议统一生成以下图像：宽带频谱、F1-F3 轨迹、局部线性频谱，以及必要时的波形放大图。

### 4.6 喉音、声门擦音和其他特殊辅音

还有两类容易被忽略的情况：

- /h/：通常具有非周期性噪声，但频谱能量分布可能受到相邻元音共振峰的显著影响。因此需要观察与相邻元音的共振峰连续性，而不只是计算噪声频谱。
- /ʔ/：可能表现为短时闭塞、明显的振幅下降、脉冲不规则、F0 丢失和声门化。应生成精细波形、宽带频谱、窄带频谱和发声态参数图。
- 喷音、内爆音等：增加释放瞬态、闭塞阶段的周期性与释放后的声门振动分析。

这些类别不需要在每一段录音上都生成，只有音素清单中出现时才启动对应模块。

## 五、声调分析：不能只依靠一张普通频谱图

如果录音包含声调语言，声调应该拥有独立的分析模块。最关键的声学变量是基频 F0 随时间的变化，而不是某个时间点上的 F0 值。

### 5.1 F0 提取

推荐使用 Praat 的 `Sound: To Pitch (filtered autocorrelation)`，用于基频和声调轨迹分析。

建议：

| 参数          | 推荐设置                       |
| ------------- | ------------------------------ |
| Algorithm     | Filtered autocorrelation       |
| Time step     | 5–10 ms                        |
| Pitch floor   | 根据说话人实际最低 F0 设定     |
| Pitch ceiling | 根据说话人实际最高 F0 设定     |
| 输出          | F0、时间、voicing/候选置信信息 |

对于普通成年说话人，可以先采用较宽的 50–600 Hz 范围做初步检查，再根据实际录音缩小范围。不能直接把这个范围作为所有说话人的最终配置。

Praat 有一个值得注意的技术细节：F0 的有效分析窗长度由 Pitch floor 决定，约为：

\\[ T\_{\mathrm{F0}}=\frac{3}{F0\_{\mathrm{floor}}} \\]

例如，Pitch floor 为 75 Hz 时，分析窗约为 40 ms。即便输出间隔设为 5 ms，也不意味着相邻两个 F0 测量拥有独立的 5 ms 声学信息。它们实际上使用高度重叠的分析窗。【Cite refs=turn988530view4turn262580search10】

对于持续时间特别短的音节，这一点尤其重要。不要把密集输出的 F0 数据点误认为同等数量的独立观测。

### 5.2 建议生成的声调图片

图 A：F0 原始轨迹图。 横轴为真实时间，纵轴为 Hz。每个音节分别标记起点和终点，有声段之外显示为无声或缺失，不应将其当作零 Hz。

图 B：F0 半音轨迹图。 将 F0 转换成半音标度：

\\[ F0\_{\mathrm{st}}=12\log_2 \left(\frac{F0}{F\_{\mathrm{ref}}}\right) \\]

其中 \\(F\_{\mathrm{ref}}\\) 使用同一说话人的参考基频，通常以说话人语料的中位数作为参考。原始 Hz 曲线必须保留，因为半音转换用于表达相对高低，不能丢失绝对 F0。

图 C：时间归一化 F0 轨迹图。 对每个音节的有效有声区间提取 11 个位置：

| ---- | -------- |
| P0   | 0%       |
| P1   | 10%      |
| P2   | 20%      |

每个点保存 Hz，同时保存半音值和时间戳。对于只有一个音节的录音，这样得到一个完整的时间归一化声调轮廓；对于两个音节，则分别提取两组轨迹，并额外绘制完整连续轨迹。

这种 11 点抽样方式在声调声学研究中有实际先例。例如，有研究使用 0%–100% 的 11 个等间隔 F0 点进行普通话声调比较；另有研究使用 10 个等间隔点分析普通话声调的动态变化。【Cite refs=turn505171search4turn505171search10turn505171search11】

\\[ \frac{dF0}{dt} \\]

记录声调上升、下降、平坦阶段的斜率，并标记局部最大值、局部最小值及其出现时间。这张图有助于描述曲线变化发生在哪个阶段。

建议输出的声调参数：

| 参数               | 具体定义                  |
| ------------------ | ------------------------- |
| F0 onset           | 有声区间起始 F0           |
| F0 offset          | 有声区间结束 F0           |
| F0 mean            | 平均 F0                   |
| F0 median          | 中位 F0                   |
| F0 minimum         | 最低 F0                   |
| F0 maximum         | 最高 F0                   |
| F0 range           | 最高值减最低值            |
| F0 slope           | 整体斜率或分段斜率        |
| Turning point      | 转折点位置                |
| Turning point F0   | 转折点 F0                 |
| Turning point time | 转折点发生时间            |
| F0 trajectory      | 11 个归一化位置的完整数值 |

这里要特别注意：如果语言采用的是音高高度和音高走向共同构成声调对立，那么 F0 原始高度和动态曲线都必须保留。不要仅仅对单个音节进行 min-max 归一化，这样会消除声调高度方面的信息。

### 5.3 两个音节的声调需要联合分析

虽然录音只有一到两个音节，但前后音节的声调关系依然重要。

Yi Xu 的两项经典普通话声调研究非常值得参考：

- Xu（1997），Contextual tonal variations in Mandarin，分析相邻声调之间的协同影响。
- Xu（1999），Effects of tone and focus on the formation and alignment of f0 contours，分析声调曲线的形成、对齐及语境影响。

这两项研究说明，局部 F0 轨迹不仅受当前音节声调影响，也会受到前后音节的制约。【Cite refs=turn850468search2turn850468search0】

因此，建议对两个音节的录音生成：

1. 两个音节拼接的完整 F0 轨迹。
2. 第一个音节独立归一化的 F0 轨迹。
3. 第二个音节独立归一化的 F0 轨迹。
4. 两个音节交界区域的 F0 细节图。
5. 跨越音节边界的 F0 导数图。

这样既能研究当前音节的声调，也能观察前后音节的过渡和影响。

对于普通话，尤其应当避免把第三声简单处理成固定的下降—上升曲线。第三声在实际语境中可以有不同的实现；相邻声调、语境位置和焦点都可能改变实际 F0 轮廓。

此外，声调并不一定全程都有可靠的周期性。如果发生 creaky voice（嘎裂音）或不规则振动，F0 算法可能出现漏检或者错误倍频。这类位置应当标记为缺失或者单独的非周期性区域，不能用插值假装存在连续且准确的 F0 数据。相关普通话声调研究已经采用人工检查并处理因嘎裂发声而无法测得 F0 的点。【Cite refs=turn505171search4turn850468search0】

## 六、发声态（Phonation）与谐波—噪声分析

这是一个非常值得增加的模块，特别是录音中出现气声、紧喉、嘎裂音、送气与不送气对立，或者声调与发声态存在关联的情况。

单独的 F0 无法描述声带振动的完整特征。

### 6.1 谐波振幅与谱倾斜

建议使用 VoiceSauce 或 Praat 配合专门的声学分析程序。

核心参数如下：

| 参数       | 意义                           |
| ---------- | ------------------------------ |
| H1\*       | 经过共振峰修正的第一谐波振幅   |
| H2\*       | 经过修正的第二谐波振幅         |
| H4\*       | 经过修正的第四谐波振幅         |
| A1\*       | F1 附近的谐波振幅              |
| A2\*       | F2 附近的谐波振幅              |
| A3\*       | F3 附近的谐波振幅              |
| H1\*–H2\*  | 低次谐波间的相对幅度           |
| H1\*–A1\*  | 第一谐波与 F1 附近谐波的幅度差 |
| H1\*–A2\*  | 第一谐波与 F2 附近谐波的幅度差 |
| H1\*–A3\*  | 第一谐波与 F3 附近谐波的幅度差 |
| H2\*–H4\*  | 中低次谐波的幅度差             |
| H4\*–H2k\* | 中频区域的谱倾斜               |
| H2k\*–H5k  | 高频区域的谱倾斜               |

其中 `*` 表示需要进行声道共振峰和带宽修正的测量值。

尤其推荐 H1\*–H2\*，常用于研究气声、紧喉等发声态差异。但它并非声门开放程度的直接测量，不能脱离其他指标独立下结论。

Peter Ladefoged、Pat Keating 等研究传统，以及后续 Garellek 的综述工作，都将谐波幅度差、谱倾斜和噪声结构作为声学发声态研究的重要指标。【Cite refs=turn505171search2turn505171search3】

VoiceSauce 的优势在于能够自动提取多个谐波幅度和对应的修正值，而且能够进行基于 F0 的同步分析。其手册介绍了使用多个基音周期作为分析窗口的谐波幅度提取方式。【Cite refs=turn465158search8turn465158search9】

建议生成两张图：

- 谐波幅度随时间变化图：显示 H1\*、H2\*、H4\*、A1\*、A2\*、A3\*。
- 谱倾斜轨迹图：显示 H1\*–H2\*、H1\*–A1\*、H1\*–A2\*、H1\*–A3\*。

这些参数要尽量在同一元音的多个时刻测量，而不是仅取一个平均数。

### 6.2 HNR（Harmonics-to-Noise Ratio）

HNR 是谐波能量与非谐波噪声能量的相对关系，通常以 dB 表示：

\\[ HNR=10\log\_{10} \left(\frac{E\_{\mathrm{harmonic}}} {E\_{\mathrm{noise}}}\right) \\]

Praat 的 Harmonicity 对象就是用来表达这种周期性能量和非周期性能量的关系。【Cite ref="turn262580search4"】

建议生成：

- HNR 随时间变化图。
- HNR 全段平均数。
- 不同频带 HNR 参数。

可以优先考察：

| 参数              | 频带      |
| ----------------- | --------- |
| HNR below 500 Hz  | 0–500 Hz  |
| HNR below 1500 Hz | 0–1500 Hz |
| HNR below 2500 Hz | 0–2500 Hz |
| HNR below 3500 Hz | 0–3500 Hz |

这样既能观察低频周期性能量，也能观察中高频非周期噪声的变化。

对正常清晰元音、气声元音及嘎裂元音，HNR 有助于补充仅靠频谱形状无法得到的信息。不过要注意，HNR 会受到元音频谱分布和分析算法的影响，不能机械地套用统一阈值。

### 6.3 CPP 和 CPPS

CPP（Cepstral Peak Prominence）是另一个非常值得提取的参数。它通过倒谱分析来描述语音中周期性结构的突出程度。

CPPS 是进行时间及倒谱方向平滑后的 CPP。

建议：

| 参数              | 推荐设置                |
| ----------------- | ----------------------- |
| 工具              | Praat PowerCepstrogram  |
| Pitch floor       | 按说话人的 F0 范围设定  |
| Maximum frequency | 5000 Hz，必要时 8000 Hz |
| Time step         | 5–10 ms                 |
| Pre-emphasis      | 50 Hz 起始设置          |
| 输出              | CPP/CPPS 轨迹           |

Praat 的 PowerCepstrogram 根据 Pitch floor 确定有效分析窗长度，例如 60 Hz 对应三个周期、约 50 ms 的有效窗长。CPP 测量还涉及倒谱背景趋势拟合及峰值搜索范围，因此应将设置完整保存，而不能只记录 CPP 的最终数值。【Cite refs=turn988530view5turn465158search7turn262580search8】

建议生成：

1. Power Cepstrogram 热力图。
2. CPP/CPPS 时间轨迹。
3. CPP 全段统计。

CPP/CPPS、HNR 和谐波谱倾斜是互补指标，不建议互相替代。

### 6.4 Subharmonics-to-Harmonics Ratio（SHR）

如果声音出现明显嘎裂、次谐波或周期性不规则，还应提取 SHR。

建议生成：

- 窄带频谱图。
- 波形的局部放大图。
- 次谐波结构图。
- SHR 随时间变化曲线。

这里尤其要保留原始波形，而不是只看频谱热力图。因为次谐波结构与波形周期是否规则、周期长度是否出现倍增有关。

### 6.5 Jitter 和 Shimmer 是否值得做？

Jitter 反映相邻声带振动周期的时间变化，Shimmer 反映相邻周期振幅变化。

Praat 的使用手册明确建议，Jitter 和 Shimmer 通常用于较长的持续元音。【Cite refs=turn895812search1turn895812search2】

对于只有一到两个音节的录音，我不建议把这两个数值作为核心测量指标。特别是当元音很短、包含音高变化或嘎裂振动时，少量周期不适合支撑稳定的总体统计。

可以保留：

- 声带周期的逐周期时间间隔。
- 每个周期的振幅。
- 周期变化的局部图。
- 能够稳定测得时的 Jitter 和 Shimmer。

但应明确报告有效周期数量及测量区间，不宜将短样本的统计值与长时间持续元音的参考数据直接比较。

### 8.3 擦音谱矩的计算代码

为了保证谱矩计算可以独立验证，建议自己实现，而不是把不同软件输出的 COG 当成完全一致的数值。

以下使用功率谱作为权重：

```
import numpy as npdef spectral_moments(    x,    sr,    fmin=500,    fmax=12000):    x = np.asarray(x, dtype=float)    if len(x) < 16:        raise ValueError("Analysis window is too short")    if fmax > sr / 2:        raise ValueError("fmax exceeds Nyquist frequency")    # 去除直流分量    x = x - np.mean(x)    # Hann 窗    x = x * np.hanning(len(x))    # Zero padding，仅改善频谱曲线插值显示    n_fft = 4 * 2 ** int(        np.ceil(np.log2(len(x)))    )    # 功率谱    P = np.abs(        np.fft.rfft(x, n=n_fft)    ) ** 2    freqs = np.fft.rfftfreq(        n_fft,        d=1 / sr    )    mask = (        (freqs >= fmin) &        (freqs <= fmax)    )    f = freqs[mask]    p = P[mask]    if len(p) == 0 or np.sum(p) <= 0:        raise ValueError("No valid spectral energy")    # 归一化频谱权重    w = p / np.sum(p)    # 第一阶矩    m1 = np.sum(w * f)    # 第二阶中心矩的平方根    m2 = np.sqrt(        np.sum(w * (f - m1) ** 2)    )    if m2 == 0:        raise ValueError("Zero spectral variance")    # 偏度    m3 = (        np.sum(w * (f - m1) ** 3)        / m2 ** 3    )    # 峰度    m4 = (        np.sum(w * (f - m1) ** 4)        / m2 ** 4    )    return {        "COG_Hz": m1,        "SD_Hz": m2,        "Skewness": m3,        "Kurtosis": m4    }
```

实际处理擦音时，不是把整个擦音一次性送入函数，而是按照前述 20–80% 区间，逐帧提取 20–30 ms 信号，计算各帧谱矩，再输出时间序列及均值、标准差。

这里使用了 4 倍 zero-padding，但这只改善频谱曲线的插值显示，不会真正提高短时窗的频率分辨率。对于频谱非平稳的擦音，可以使用 4–8 个 DPSS multitaper 估计并对多个谱进行平均。Shadle 等人的近期研究也特别强调了分析窗位置、频谱平均和频谱估计方法对测量结果的影响。【Cite refs=turn544978search3turn544978search45】

## 九、如何验证生成的声学图像和参数可靠

这部分非常重要。你的录音质量好、强制对齐准确，并不代表自动提取出来的 F0、共振峰和频谱指标就一定准确。每一种测量都应该有对应的验证办法。

| 分析项目         | 验证方法                | 需要检查的问题               |
| ---------------- | ----------------------- | ---------------------------- |
| 宽带 STFT        | 对照原始波形            | 爆破、闭塞、浊音起点是否对齐 |
| 窄带 STFT        | 对照周期波形            | 谐波间距是否与 F0 一致       |
| F0               | 对比不同算法及局部周期  | 是否出现倍频、半频和错误跳变 |
| Formants         | 对照线性频谱及 LPC 包络 | 是否有伪峰、缺失峰和异常跳变 |
| 擦音谱矩         | 改变频带和分析窗        | 测量结果是否过度依赖设置     |
| 鼻音反共振       | 对照原始频谱及谱包络    | 是否误把噪声谷值当作反共振   |
| HNR / CPP        | 对照谐波结构            | 是否与周期性、噪声结构相符   |
| Jitter / Shimmer | 检查周期数量和脉冲      | 是否具备足够有效周期         |
| 声调             | 对照窄带频谱与周期波形  | 是否正确处理嘎裂和无声段     |

我建议至少执行以下五项质量控制：

第一，F0 人工抽查。 在波形上放大若干周期，直接量取周期长度：

\\[ F0=\frac{1}{T\_{\mathrm{period}}} \\]

然后与自动 F0 轨迹比较，重点检查 F0 轨迹是否发生倍频错误。尤其是两个音节的交界处，以及声调低谷附近。

第二，共振峰参数敏感性检查。 至少使用两种相邻的 Formant ceiling 设置生成结果，比较 F1、F2、F3。如果某一个共振峰的位置在不同设置下出现较大变化，或者无法与原始频谱峰对应，就不应该将自动测量值直接视作可靠结果。

第三，擦音频带敏感性检查。 同一擦音分别使用 500–8000 Hz 和 500–12000 Hz 两种频率范围计算谱矩。如果结果差异明显，说明结果高度依赖分析频带。此时两个版本都要保存，不应该只保留其中一个数值。

第四，固定图像的频谱显示标尺。 尤其是宽带、窄带频谱，不要让每个音素都分别自动缩放颜色强度。否则，同一个绝对频谱幅度可能在不同图片中显示为完全不同的颜色。

第五，保留全部数值中间结果。 图片不是原始声学测量数据。对于每一个分析时间点，至少保存时间戳、F0、F1–F4、强度、HNR、CPP、谱矩等。这样以后可以重新绘图，不需要重新分析录音。

- 11 个归一化时间点的 F0。

## 十二、我的最终建议：采用分层而不是单纯增加图片数量

综合以上研究，我会把实际处理方案确定为以下优先级：

第一优先级 · 全部录音

基础声学表示

宽带 STFT（5 ms）、窄带 STFT（30 ms）、波形图、F0 轨迹、F1–F3 轨迹、Log-Mel 频谱、强度轨迹。

第二优先级 · 对应音素

辅音与元音专用分析

塞音：VOT + 爆破谱 + 共振峰过渡。

擦音：高频频谱 + 四个谱矩 + 高频能量参数。

塞擦音：闭塞、爆破、摩擦分阶段分析。

鼻音：鼻腔共振 + 反共振。

近音：F1–F3 动态轨迹。

元音：Formants + 动态元音轨迹。

第三优先级 · 有声段及特殊发声态

声源及发声态表示

H1\*–H2\*、H1\*–A1\*、H1\*–A2\*、H1\*–A3\*、HNR、CPP/CPPS、SHR。

第四优先级 · 声调

时间动态分析

原始 Hz 曲线、半音曲线、11 点归一化 F0 曲线、F0 导数、转折点、两个音节的连续过渡。

我认为最值得投入处理精度的五项是：高时间分辨率的宽带频谱、准确的 F0 轨迹、F1–F3 的动态变化、擦音高频谱形以及声源发声态参数。这五组信息覆盖了大量语音区别所依赖的核心声学线索。其他图像用于补充和交叉验证。

有一个实施建议：不要一次性把所有声学参数都放进同一张大图。每张图片只承担一个明确的测量任务，图上统一保留时间轴、频率单位、音素边界及分析窗参数；所有图片对应的数值另外保存为 CSV。这样既能确保处理结果具有可验证性，也能避免某一张图的显示设置掩盖其他声学信息。
