# LLM 发音建议图像：审查结论与重构建议

本文审查《LLM发音建议图像.md》列出的 9 类图像，包括描述是否正确、`backend/app/acoustics/imagery/` 中对应的实现是否合适、有哪些欠缺和冗余，并给出重构方案。文中不含具体代码。

---

## 0. 审查范围与依据

**阅读的材料**

- 《LLM发音建议图像.md》全文，以及《方案.md》《实现说明.md》中与这 9 类图像有关的章节。
- 实现代码：`imagery/common.py`、`prosody.py`（05c、05e、06）、`basic_spectra.py`（02）、`formants.py`（07c）、`obstruents.py`（09a、10b、11a）、`sonorants.py`（12b、13a）、`cli.py`、`__init__.py`。
- 产品侧的相关代码：`acoustics/f0_pipeline.py`（评分和结果页用的 F0 管线）、`acoustics/analysis.py`（共振峰、VOT、音域估计）、`acoustics/transcode.py`（用户录音转码）、`scoring/rules.py`、`content/usecases.py`、`seed.py`（参考发音人的音域与元音空间）。

在开发集上运行了现有批处理（`pa2_FV1 ba4_MV1 ma3_FV1 ca1_FV1 shi1_MV1 an1_FV1 la1_FV1 ri4_MV1 xiao1_FV1` 共 9 条），没有报错，并逐张查看了 02、05c、06、07c、09a、10b、11a、12b、13a。下文引用的数值都来自这次运行。

## 1. 总体结论

按影响从大到小排列。

### 1.1 图像只描述一条录音，没有参考对照，LLM 无法「定位差异」

文档的目的写的是「定位差异和组织练习建议」，但所有图像只分析一条录音。LLM 看到「VOT 181 ms」「F2 在 1500 Hz」时，没有依据判断这是对还是错：

- 声调、元音、送气、擦音部位都有很大的说话人差异，固定阈值（例如「送气要大于 70 ms」）只能判断很粗的错误。
- 产品需求 FR-1005 本来就要求「与标准参考示范对比展示」，Tone Perfect 语料为每个音节提供 6 位发音人的标准录音，`content` 模块已经为参考发音人存了音域（`f_lo`、`f_hi`）和元音空间统计（`vowel_space`）。

**结论**：每张图都应同时画学习者和参考，数值也应成对给出，并给出差值。这是本次审查最重要的一条。

### 1.2 实现按 44.1 kHz 研究语料设计，产品录音是 16 kHz

`transcode.SAMPLE_RATE = 16000`，用户录音统一转成 16 kHz，奈奎斯特频率为 8 kHz。现有实现的多处设计以 44.1 kHz 为前提：

| 位置 | 设计 | 16 kHz 下的情况 |
|---|---|---|
| 02 宽带语谱图 | 显示 0–12 kHz | 上面三分之一是空白，元音共振峰被压在下面三分之一 |
| 10b 擦音参数 | Fh 取 7–12 kHz，HighLevelD 用 8–12 kHz | 无法测量 |
| 10d、除阻检测 | 频带上限 12 kHz | 8 kHz 以上没有信号 |
| 10a | 0–15 kHz 面板 | 无意义 |

参考录音（44.1 kHz）和学习者录音（16 kHz）也必须先统一到同一采样率才能对比，否则频谱形状、谱重心不可比。

### 1.3 LLM 读不准图上的数值，需要配套的结构化数值

多模态模型能看出曲线是升还是降、两条线是否重合，但读不准坐标值，也容易误读图例。现状的问题：

- 关键数值散落在 11 张 CSV 里，字段名是研究用的（`AmpD_dB`、`HighLevelD_dB`、`M3_mean_500_12000`），而且图像模块只写 CSV，没有一份「每个音节一组数值」的汇总。
- 图的标题写满了分析参数（「Gaussian 窗 5 ms，步长 2.0 ms，频率步长 43.1 Hz」「To Intensity：minimum pitch 100 Hz」），对写发音建议没有用处，反而占用模型的注意力。
- 图例放在坐标轴外，色标占据大块面积（09a、11a 右侧近一半是空白）。

**结论**：LLM 应以一份结构化数值文件为主要依据，图像用来核对和补充定性信息。图上直接标出关键数值，标题用朴素的中文说明「这张图看什么」。

### 1.4 F0 有两套实现，与学习者在结果页看到的曲线不同源

`imagery/prosody.py` 自己提取 F0（参数、清洗规则、半音参考都与产品不同），而评分和结果页用的是 `f0_pipeline`（主趟 + 救援趟、四步清洗、按个人音域换算五度值、Chao 调值、21 点比较序列）。LLM 依据的曲线如果和学习者在结果页看到的曲线不一致，话术就会自相矛盾。

**结论**：LLM 用的声调数据应直接取自 `f0_pipeline`，与结果页同源、同口径（五度值和调值）。

### 1.5 计算太慢，不适合在线反馈

单条 15–43 s。主要原因是重复计算：

- `common.vowel_interval()` 每次调用都重新提取一遍 F0，而它在 prosody、formants、sonorants、phonation 中被反复调用。
- `formants.vowel_formants()` 内部又重算 F0、Burg 和元音区间；`generate()` 对每个韵母调用它之后，又把打分重算一遍。
- 共振峰上限自动选择对每个候选（5 个）和敏感性对照（±500 Hz）都完整运行 Burg。
- 逐帧通过 Python 调用 Praat 取共振峰值和带宽。

只服务这 9 类图像时，每条录音只需一次 F0、一次 Burg、一次声门脉冲提取和一次短时电平计算，预计 1–3 s 可完成一对录音。

### 1.6 学习者录音的典型情况没有覆盖

开发集是专业发音人的单音节，紧贴语音起点裁剪。实现中有不少规则依赖这一点，而学习者录音恰恰相反：

| 学习者录音的情况 | 现有实现 |
|---|---|
| 有前导静音和塞音闭塞段 | 「闭塞时长一律记 NaN」，除阻搜索区间按「录音起点附近」设计 |
| 外语母语者把 b/d/g 发成真浊音（闭塞期就有声带振动，VOT 为负） | 浊音起点先找、除阻在其之前搜索，预发声时搜索区间为空，**测不出来**（详见 2.6） |
| 韵尾脱落或只鼻化元音 | 鼻韵尾检测找不到时退回「韵母最后 30%」，把不存在的鼻音段画出来（详见 2.9） |
| 录音音量、噪声差异大 | 语谱图用跨样本统一的绝对 dB 上限（DbScales），对不同麦克风的学习者和参考没有意义 |
| 多音节词（变调、轻声） | 05e 从未在真实多音节录音上运行过（《实现说明》§8 已注明） |

## 2. 逐项审查

每项按「文档描述」「实现」「问题」「建议」组织。

### 2.1 `02_broadband.png` 宽带语谱图

**文档描述**：基本正确。宽带语谱图确实是观察爆破、送气、摩擦、浊音起点和共振峰过渡的基础图。

**实现**：Praat Spectrogram，5 ms Gaussian 窗、2 ms 步长，0–12 kHz，动态范围 50 dB，跨样本统一 dB 上限；画讯飞音素边界虚线和音素标签。

**问题**

1. 文档说「标出音节、声母和韵母边界」，实现只有一层音素标签。单音节时音节边界与音素边界重合，看不出问题；多音节时没有音节层。
2. 文档说图中可以看到「起声时刻」，但图上没有标出任何检测到的事件（除阻、浊音起点、鼻音段），LLM 只能自己从灰度图里找。
3. 0–12 kHz 在 16 kHz 录音上一半无信息（见 1.2）。
4. 统一的绝对 dB 上限对学习者和参考的对比没有意义：两者麦克风、增益不同，同一个上限会让一张图整体发白、另一张发黑。
5. 标题是分析参数。

**建议**

- 上下两行：学习者、参考。频率 0–8 kHz。
- 横轴用相对时间（从各自语音起点算起，前后各留约 50 ms），两行用同一横轴长度，便于比较时长。
- 两层标注：音节（拼音 + 汉字）、声母 / 韵母（拼音 + IPA），并在每段下方标出时长（ms）。
- 叠加检测到的事件：除阻（竖线）、浊音起点（竖线）、鼻音段（阴影）。
- 每行按本条录音的峰值确定显示上限（相对 50 dB）。图注说明「深浅只在同一行内比较」。
- 波形不必单列，事件线已足够。

### 2.2 `05c_f0_normalized.png` 时间归一化基频轮廓

**文档描述**：「下面板为相对于该说话人参考基频的半音值」在产品场景下不成立。批处理里参考基频是「发音人在整批语料中的 F0 中位数」，而产品中一个学习者通常只有当前这一条录音，实现会退回「本文件 F0 中位数」。这样单音节阴平永远落在 0 半音附近，阳平、去声都围绕本条录音的中位数上下摆动，**音高绝对高低完全不可判断**，只能判断调形。文档应写明这一限制。

**实现**：11 点取样（P0–P10），上面板 Hz，下面板半音；区间为「音节内第一个有声帧」到「韵母有效终点」；有效终点沿连续有声帧延伸，弥补讯飞截掉的尾部；疑似倍频帧记为缺失。

**做得对的地方**

- 有声终点延伸很重要：开发集中讯飞对齐常截掉尾部弱衰减段（最多约 110 ms），上声的升尾可能就在其中（`ma3_FV1` 的升尾在对齐终点之后）。
- 缺失点不插值、不连线，符合方案 §5.3。

**问题**

1. 与产品 F0 不同源（见 1.4）。产品结果页用五度值和 Chao 调值，LLM 话术说「你的第二声起点偏高」时应和结果页同口径。
2. Hz 与半音两个面板表达同一条曲线，冗余。
3. 11 点与产品的 21 点比较序列（`comparisonPoints`）不一致。
4. 归一化区间的 0% 在不同音节含义不同：`ma` 从 m 开始，`pa` 从元音开始。学习者与参考读同一音节时仍然可比，但文档需要说明，否则 LLM 会误以为 0% 都是元音起点。
5. 没有参考曲线。

**建议**

- 纵轴改为五度值（1–5），由 `f0_pipeline.process_syllables` 按各自音域换算；图上标出学习者和参考的 Chao 调值（如「学习者 213 / 参考 214」）。
- 学习者实线、参考虚线叠加，每个音节一个子图；横轴为该音节分析区间的 0–100%（21 点），区间终点用延伸后的有声终点。
- 音域来源分三种并写进图注和数值文件：
  1. 学习者已完成个人标定：用标定快照（与评分一致）。
  2. 参考发音人：用 `seed.py` 已经算好的 `f_lo`、`f_hi`。
  3. 都没有：按产品「跳过标定」路径由本条录音估计（`analysis.adaptive_f0_range` 的逻辑），并注明「只可比较调形，音高绝对高低不可靠」。
- 疑似倍频、有效帧不足时，在图上和数值文件里写明「调形仅供参考」，并要求 LLM 不据此给建议。

### 2.3 `05e_f0_boundary.png` 相邻音节的音高衔接

**文档描述**：描述与实现一致，但这张图对写建议的价值不高。

**问题**

1. 语料全是单音节，这张图从未在真实多音节录音上运行过。
2. 交界 ±100 ms 的放大视图和导数曲线噪声很大；交界处常常是清辅音造成的 F0 缺口，导数在不足 5 帧的段上不计算，恰好在交界处断开。
3. 普通话双音节中对学习者最重要的是：上上相连的变调（前字变成阳平类的升调）、轻声（短、弱、音高依赖前字）、「一」「不」变调。这些主要从**整词连续轨迹和各音节的调值、时长、强度**判断，而不是交界 100 ms 的导数。

**建议**：取消独立的 05e，并入下面的「整词韵律图」（见 2.4）。交界信息用数值给出：前一音节末端五度值、后一音节起点五度值及其差值。

### 2.4 `06_intensity.png` 短时能量轨迹

**文档描述**：「可用于分析重音、弱化及音节间的力度安排」只对多音节材料成立。普通话单音节没有词重音；单音节的强度曲线只能看出尾部是否突然截断、上声中段的能量下降（常伴随嘎裂）这类次要信息。

**问题**

1. Praat Intensity 与 25 ms 短时 RMS 两条曲线在图上几乎完全重合（`ma3_FV1`），冗余。
2. 每个文件都做过峰值归一化，强度只能在单个文件内比较，文档没有写明。
3. 外语学习者真正的强度问题（把英语重音习惯带进双音节词、轻声不弱）需要多音节材料，而现在没有。

**建议**：与 05e 合并为「整词韵律图」：

- 横轴按音节归一化拼接（每个音节占一个单位宽度，学习者与参考在音节边界处对齐），上面板为五度值 F0，下面板为相对本录音峰值的强度（一条曲线）。
- 学习者实线、参考虚线；每个音节下方标出时长和占整词的比例。
- 数值文件给出每个音节的时长、时长占比、峰值强度、元音段平均强度。
- 单音节时这张图价值有限，可以只在多音节时生成，或只保留强度面板。

### 2.5 `07c_formant_normalized.png` 韵母共振峰动态

**文档描述**：基本正确。F1、F2 描述舌位高低和前后，F3 补充卷舌（er）以及 ü 与 i 的区分。

**实现**：元音区间起点后移到首个有声帧（排除送气），终点沿有声帧延伸；共振峰上限在发音人初始值 ±500 Hz 内按轨迹平滑度自动选择；离群点（偏离 5 帧中值 >20%）和低能量帧标为空心点。

**做得对的地方**：元音起点后移排除送气段、低能量帧和离群点排除，都是必要的。

**问题**

1. 只有「共振峰随时间」，没有 F1–F2 平面。判断「舌位偏高 / 偏前」最直观的是 F1–F2 平面上的位置和走向；现有的 07b 不在 LLM 清单中。
2. 鼻韵母的元音区间把鼻音段也包含进去。`an1_FV1` 在 0.6 s 之后 F2 降到约 900 Hz，那是鼻音段上的 Burg 结果，没有元音意义，却被画成元音轨迹的一部分。
3. 共振峰上限自动选择与敏感性检查是研究用途，计算量大；产品已有更简单的规则（`analysis.extract_formants`：F0 中位数低于 165 Hz 用 5000 Hz，否则 5500 Hz），参考发音人的元音空间统计也是按这个规则算的。两套规则会让学习者的数值与产品参考区不同口径。
4. 男女声的共振峰 Hz 不能直接比较。学习者是男声、参考是女声时，F2 差几百 Hz 主要是声道长度差异，LLM 很容易据此给出错误的「舌位偏后」建议。
5. `xiao1_FV1` 的 F3 有明显跳动、末点缺失，图上只是空着，LLM 不知道原因。
6. 没有参考轨迹。

**建议**

- 一张图两个面板：左边 F1–F2 平面（两轴反向，传统元音图方向），轨迹起点画圆点、终点画箭头；右边 F1/F2/F3 随归一化时间（11 点）。学习者实线、参考虚线。
- 元音区间终点：鼻韵母取鼻音段起点（检测方法见 2.9），其他取有声终点。
- 共振峰上限统一用产品规则；不做自动搜索。
- 性别不同时：有元音空间统计（参考发音人的 `vowel_space.overall`，学习者完成元音标定时的个人统计）就给出 z 分数（按各自均值、标准差归一化）；没有就在图注和数值文件里明确写「Hz 差值主要反映声道长度差异，只比较轨迹方向和相对位置」。
- 某个取样点无效时，数值文件写明原因（低能量、离群、无数据）。

### 2.6 `09a_stop_vot.png` 塞音释放与起声

**文档描述**：有两处需要改。

1. 「标出除阻、送气段、规则声带振动起点和声带振动起始时间」：「规则声带振动起点」和「声带振动起始时间」重复，而且 VOT 是一个时间差，不是时刻。应写成「标出除阻和浊音起点，以及二者之差 VOT」。
2. 「适用于分析塞音的送气、不送气及清浊对立」：普通话 b/p、d/t、g/k 是**送气对立**，两组都是清音，没有清浊对立。对外语学习者真正要检查的是：(a) 送气音送气是否足够；(b) 不送气音是否被发成了真浊音（法语、西班牙语、俄语、日语等母语者常见，表现为负 VOT，即预发声）；(c) 英语母语者有时把不送气音发得略带送气。文档应改成「送气与不送气对立，以及是否带有预发声」。

**实现**：浊音起点 = 从录音起点开始第一个「至少连续 4 个声门脉冲、持续 ≥60 ms」的脉冲；除阻 = [讯飞声母起点, 浊音起点 − 2 ms] 内 1–12 kHz 电平上升最快的帧；爆破时长 = 除阻后 3–20 ms 平滑包络峰值之后的第一个局部极小；闭塞时长恒为 NaN。

**问题**

1. **预发声测不出来。** 浊音起点从录音起点开始找。学习者发成真浊音时，闭塞期就有声门脉冲，于是浊音起点落在除阻之前，「[声母起点, 浊音起点 − 2 ms]」这个除阻搜索区间为空或错位，VOT 变成无效值或很小的正值。`_prevoicing()` 只在除阻有效时才计算。也就是说，对外语学习者最需要检测的一类偏误，现有实现恰好无法处理。
2. 语料没有闭塞段，学习者录音有前导静音和闭塞段。前导静音中的呼吸声、键盘声等可能被当成瞬态。
3. 爆破时长在大多数送气音上找不到局部极小（`pa2_FV1` 图上写着「爆破：与送气不可分」「送气（与爆破不可分，含爆破）181 ms」），图上和表里留下一串说明文字。区分爆破和送气对教学建议没有帮助。
4. 版面：图例在外侧，色标占右侧一大块空白，「除阻」「浊音起点」标签挤在左上角；横轴从录音起点开始，学习者和参考无法对齐。

**建议**

- 除阻和浊音分开独立检测，再判断先后：
  - 除阻：高频（约 2–7.6 kHz）短窗电平的最早强瞬态，要求上升后电平接近该区间最大值（排除「静音 → 浊音杠」这种低频为主的上升）。搜索区间从声母起点前约 20 ms 开始，到覆盖韵母的那段浊音起点前 2 ms 为止；若那段浊音在声母起点之前就已开始（预发声），则搜索到声母终点。
  - 浊音：声门脉冲的连续段（相邻脉冲间隔小于 1.25 倍下限周期，持续 ≥40 ms），取覆盖韵母的那一段。
  - 若这段浊音在除阻之前至少 10 ms 就已开始：判为预发声，VOT = 浊音起点 − 除阻（负值）。否则 VOT = 浊音起点 − 除阻。
- 删去爆破时长。只保留 VOT 和「是否预发声」。
- 图：学习者、参考左右两列，每列上为波形、下为 0–8 kHz 语谱图；横轴以除阻为 0 ms（例如 −30 ms 到 VOT + 60 ms），两列横轴范围相同；送气段用橙色阴影，预发声用绿色阴影；在图上直接写「VOT 181 ms」。
- 参考数值：普通话不送气塞音大致在 10–30 ms，送气塞音通常在 70 ms 以上，单音节朗读更长（`pa2_FV1` 实测 181 ms）。这类固定范围只适合判断很明显的错误，主要依据应是同音节参考录音。

### 2.7 `10b_fricative_mean_spectrum.png` 擦音稳定段频谱

**文档描述**：「频谱形状反映摩擦噪声主要集中在哪些频率，可用于分析擦音之间的发音部位差异」是对的。但「标出主要频谱峰、次峰及频带间能量差」所依据的频段划分不适合普通话和 16 kHz 录音。

**实现**：擦音 20%–80% 段的 Hann 多帧平均谱和 multitaper 谱；FM 取 3–7 kHz 内的主峰，次峰为与主峰相距 ≥1 kHz 的第二高峰，AmpD = FM 幅度 − 0.5–3 kHz 最小值，Fh 取 7–12 kHz，AmpRange、HighLevelD 为频带均值差；绝对 dB（参考值 1）。

**问题**

1. 频段划分（Koenig 2013、Shadle 2023 的近似）针对英语 /s/、/ʃ/，不针对普通话 s [s]、sh [ʂ]、x [ɕ] 三类咝音。普通话三类的谱峰大致是 sh 最低、x 居中、s 最高（女声 s 可高于 7 kHz）。FM 固定在 3–7 kHz 会把高于 7 kHz 的 s 峰截在频带边缘。
2. `shi1_MV1` 的平均谱在 3171 Hz 和 6148 Hz 各有一个峰，实现按 3–7 kHz 内最高者定 6148 Hz 为主峰、3171 Hz 为次峰。对于 sh，低频那个峰往往才是区分 sh 与 s、x 的关键。哪一个峰更能区分这三类，需要用语料统计验证，但「按固定频带决定主次」本身不合理。
3. Fh（7–12 kHz）、HighLevelD（8–12 kHz）在 16 kHz 录音上不可测。
4. 两条未平滑的锯齿状曲线叠在一起，很难读；AmpD 的低频谷取 0.5–3 kHz 内的最小值，落在锯齿的谷底，数值（`shi1_MV1` 为 34.3 dB）受随机起伏影响很大。
5. f [f]、h [x] 不是咝音，谈「主峰、次峰」没有意义：f 的谱平而弱；h 的谱主要由后接元音的共振峰决定（这正是 `14_h_continuity` 的用途，但不在清单中）。
6. 绝对 dB 在学习者与参考之间不可比。
7. 文档中的这张图只用于擦音；塞擦音 z [ts]、zh [tʂ]、j [tɕ] 的发音部位区分与 s、sh、x 完全平行，却没有对应的频谱对比（11b 不在清单中）。

**建议**

- 同时用于擦音和塞擦音（改名为「噪声频谱」）。
- 取值区间：擦音为噪声段的 20%–80%；塞擦音为除阻后 3 ms 开始、长度取 VOT 的 60%（不超过 60 ms），避开后段向元音过渡的送气噪声。
- 只画一条平滑后的平均谱（20 ms Hann 帧平均，约 300 Hz 平滑），学习者与参考叠加，各自归一化到本条谱的最大值，只比较形状。
- 只标两个数值：谱峰（在 0.5–7.6 kHz 全频带内找，不分主次）和谱重心。
- 另给两项数值：噪声段相对后接元音的电平（Jongman 2000 的相对振幅，区分强咝音与弱的 f、h），噪声段时长。
- 删除次峰、AmpD、AmpRange、HighLevelD、Fh、multitaper 曲线和 M3、M4。
- f、h 只给相对振幅和时长；h 若要看与元音的连续性，可以单独保留 14 号图，但不必放进 LLM 清单。

### 2.8 `11a_affricate_stages.png` 塞擦音阶段结构

**文档描述**：「标出释放、持续摩擦、送气和元音起声各阶段」「塞擦音内部的送气对立」。前半句要求的「摩擦」与「送气」的分界在声学上没有可靠依据：普通话送气塞擦音（c、ch、q）的摩擦噪声逐渐减弱并过渡为送气噪声，中间没有稳定可检测的边界。

**实现**：[除阻, 浊音起点] 分为爆破、摩擦本体、送气；摩擦本体终点 = 2.5–12 kHz 能量从段内峰值回落 10 dB 以上且不再回升的位置；R_fric = 摩擦本体 / (浊音起点 − 讯飞声母起点)；下面板为浊音起点前后的 F1–F3。

**问题**

1. **会直接误导 LLM。** `ca1_FV1`（c 是送气音）的图标题写「送气=0 ms」，图例写「摩擦+送气 133 ms」。LLM 读到「送气 0 ms」很可能给出「送气不足」的建议，而实际 VOT 是 146 ms，送气充分。
2. 10 dB 回落规则是启发式，阈值改变时阶段划分会大幅变化。
3. R_fric 的分母依赖讯飞声母起点。学习者录音有闭塞段时，这个分母的含义会改变。
4. 下面板的共振峰过渡在 `ca1_FV1` 上 F1、F2 交叉（a 的 F1、F2 很接近，Burg 把两峰合并），说明自动共振峰在过渡段不稳定；对塞擦音的建议价值很低。
5. 三个面板加色标加外置图例，信息分散。

**建议**

- 不拆分摩擦与送气。送气对立用整个噪声段时长（= VOT，除阻到浊音起点）表示：z、zh、j 短，c、ch、q 长。
- 「塞擦音与擦音」的区分用噪声上升时间：噪声起点到电平接近最大值（例如差 3 dB 以内）的时长。塞擦音由除阻开始，上升快；擦音逐渐增强，上升慢。这是区分 c/s、zh/sh、q/x 混淆的经典指标。另一个依据是是否检测到除阻瞬态。阈值需要用语料验证（见 5.8）。
- 发音部位用 2.7 的噪声频谱。
- 删去 R_fric 和共振峰过渡面板。
- 图：学习者、参考两列，横轴以除阻为 0 ms；每列为波形、语谱图，波形上叠加一条高频噪声包络，标出 VOT 和上升时间。

### 2.9 `12b_nasal_broadband.png` 鼻音与相邻元音的过渡

**文档描述**：「适用于分析鼻声母和鼻韵尾的实现与衔接」方向正确，但实现的鼻韵尾区间不可靠，鼻音段上的共振峰也没有意义。

**实现**：0–8 kHz 宽带语谱图，叠加整段 F1、F2；鼻声母取讯飞区间；鼻韵尾 = 韵母后半段中 500–3000 Hz 能量回落到最大值 −8 dB 以下且不再回升的位置，找不到时取韵母最后 30%。

**问题**

1. **鼻韵尾区间估计偏早。** `an1_FV1` 估计的韵尾从 0.41 s 开始，长约 300 ms；而 F2 在 0.6 s 才明显下降，真正的鼻音段更可能在约 0.6–0.71 s。原因是元音向鼻音过渡时 F1 逐渐降低，500–3000 Hz 能量是逐渐下降的，不是阶跃，8 dB 门限被提前触发。LLM 会据此得出「鼻韵尾 300 ms」这类错误结论。
2. 找不到下降点时退回「最后 30%」，会把一个可能根本不存在的鼻音段画出来。学习者的韵尾脱落（只有元音、或只鼻化元音）恰恰是要检查的偏误。
3. F1、F2 一直画到鼻音段内部。全极点 Burg 模型不能表示鼻音的反共振，鼻音段上的共振峰值没有意义。
4. 0–8 kHz 范围对鼻音没有必要，0–5 kHz 更清楚。

**建议**

- 鼻韵尾检测改用「中高频与低频的电平差」：鼻音段能量集中在低频（约 500 Hz 以下），中高频很弱。计算（1–4 kHz 电平 − 50–500 Hz 电平），以本韵母前半段元音的中位数为基准，从某一点起比基准低约 10 dB 并一直保持到有声终点，即判为鼻音段；至少 30 ms。阈值需要在 an/ang/en/eng/in/ing（开发集 an1、ang2，验证集 tang1–4、xin1）上验证，尤其 i、u 这类低 F1 或低 F2 元音。
- 检测不到时不要退回固定比例，而是明确写出「未检测到明显的鼻音段（可能韵尾脱落或只有元音鼻化）」。
- F1、F2 只画在元音部分；鼻音段只用阴影和时长表示。
- 前后鼻音（an/ang、en/eng、in/ing）是外语学习者和南方方言区学习者的共同难点。主要线索有两个：元音音质（ang 中的 a 更靠后，F2 更低），以及韵尾前 F2 的走向（-ng 前通常下降并靠近 F3，-n 前通常保持或上升）。这些需要语料验证。数值文件给出：元音中点 F2、鼻音段起点前约 15 ms 的 F2、二者之差、鼻音段时长、是否检测到鼻音段。
- 鼻声母 m、n：讯飞区间通常可信；m 与 n 的区别主要在元音起始处的 F2，可给出元音起点后约 15 ms 的 F2。n 与 l 的混淆主要见于部分方言区学习者，若产品面向这类用户，需要在 13a 中与 l 一起处理。
- 学习者、参考上下两行，0–5 kHz。

### 2.10 `13a_approximant_formants.png` 边音与卷舌声母的共振峰过渡

**文档描述**：基本正确。

**实现**：宽带语谱图（0–5 kHz）叠加声母起点到韵母 50% 的 F1–F3；r 的 F3 用粗线，下方加一个 r 区间平均功率谱面板（注明未分离谐波和噪声）。

**问题**

1. 噪声谱面板（`ri4_MV1` 谱倾斜 0.1 dB、谱重心 3820 Hz）对写建议几乎没有信息，区间平均谱同时含谐波和噪声，读不出「擦化程度」。
2. 讯飞给出的 r 区间可能很短：`ri4_MV1` 只有约 30 ms（0.01–0.04 s），声母「中点」的数值基本落在边界或过渡上。图上没有任何提示。
3. 没有参考对照。

**建议**

- 删去噪声谱面板，改为数值：声母段浊音占比、HNR（反映擦化程度）、声母中点与元音中点的 F1–F3、过渡段内 F3 最小值。
- 对齐区间短于约 40 ms 时，在图注和数值文件里写明「边界可能偏短，声母中点数值仅供参考」。
- 外语学习者的常见替代：把 r 发成英语 [ɹ]（F3 很低，常伴随圆唇）、法语小舌音、[l] 或 [ʒ]；把 l 发成英语的「暗 l」（F2 低）。方案已指出不能把英语 /ɹ/ 的 F3 规律直接套到普通话 r 上，这是对的；但有了参考对照，「学习者 F3 明显低于参考」本身就是英语 r 迁移的证据。
- 学习者、参考上下两行，F1–F3 叠加，r 的 F3 加粗。

## 5. 重构方案

### 5.1 结构：新建独立模块，不在现有 imagery 上改

现有 `imagery` 是研究用途的完整方案（39 种图、11 种表），模块之间相互依赖（phonation 依赖 formants 的 `vowel_formants()`，几乎所有模块依赖 `vowel_interval()`）。在原地修改这 9 类图会牵动清单外的图，而这些图不在本次范围内。

建议新建一个只服务 LLM 发音建议的模块（例如 `backend/app/acoustics/pronunciation_figures/`），`imagery` 保留不动，供研究和参数验证使用。新模块分三层：

1. **测量层**：每条录音只分析一遍，逐音节得到全部数值和画图需要的数组。
2. **对比层**：学习者与参考逐音节配对，给出差值和可靠性说明。
3. **图像层**：只读测量结果出图，不做任何计算。

输出两类文件：图像，以及一份 `measurements.json`。

可以复用的现有代码：对齐数据模型与读取（`imagery.common` 的 `Alignment`、`load_alignment`、`read_mono`、`initial_class`、`nasal_coda`、`PHONE_IPA`），中文字体设置与保存，`f0_pipeline` 全套，`analysis` 的音域估计和共振峰上限规则。

### 5.2 输入

| 输入 | 来源 |
|---|---|
| 学习者录音与对齐 | 产品录音（16 kHz）+ 讯飞返回的音节、声母、韵母时间戳 |
| 参考录音与对齐 | Tone Perfect 同音节录音 + 对齐（可预先离线处理并缓存测量结果） |
| 学习者音域（可选） | 个人标定快照（`pitch_range_snapshot`），与评分一致 |
| 参考音域 | 参考发音人的 `f_lo`、`f_hi`（`seed.py` 已计算） |
| 元音空间统计（可选） | 参考发音人 `vowel_space.overall`；学习者完成元音标定时的个人统计 |
| 母语 / 方言背景、本关目标、评分服务检错结果 | 产品已有，交给 LLM 提示词层，不进入测量层 |

### 5.3 统一约定

- 采样率：一律先降到 16 kHz，频谱测量止于约 7.6 kHz（降采样滤波在 8 kHz 附近衰减）。
- 时间：图上用相对时间（语音起点为 0，或以除阻为 0），学习者与参考横轴范围相同。
- 配色和线型全局一致：学习者红色实线，参考蓝色虚线。不论哪张图，LLM 都能用同一条规则读图。
- 显示归一化：语谱图、噪声频谱各自按本条录音的最大值归一化，图注说明「只比较形状 / 只在同一行内比较深浅」。
- 字号：正文不小于 11 号；图例放在坐标轴内；不画色标（或只画很窄的色标）。
- 标题：一句朴素的中文说明这张图看什么，例如「声调曲线：纵轴为五度值，红色实线为学习者，蓝色虚线为参考」。
- 关键数值直接写在图上（VOT、调值、谱峰、鼻音段时长）。
- 数值不可靠时，在图上写明原因，而不是只把那一段留空。

### 5.5 各项测量方法

以下阈值是建议的初始值，都必须先用 5.8 的方法在语料上验证。

**有声终点**：韵母起点到下一音节起点（或录音结束）之间，最后一个「有 F0 且电平高于录音峰值 −35 dB」的帧。用来补上讯飞截掉的尾部。

**声调**：对 [音节起点, 有声终点] 调用 `f0_pipeline.process_syllables`，按各自音域得到 21 点五度值、Chao 调值、起点 / 终点 / 转折点、`canDiagnose`。音域来源见 2.2。

**强度**：25 ms 窗、5 ms 步长的短时 RMS，相对本录音峰值（dB）。

**元音区间**：

- 起点：声母为塞音、塞擦音、擦音时取浊音起点（排除送气和摩擦）；其他取韵母起点。
- 终点：有鼻音段时取鼻音段起点，否则取有声终点。
- 11 个位置上各取 ±10 ms 内有效帧（非低能量、非离群）的中位数。
- 共振峰：一次 Burg（5 ms 步长、25 ms 窗、最多 5 个峰），上限按产品规则（F0 中位数低于 165 Hz 用 5000 Hz，否则 5500 Hz）。

**塞音、塞擦音的 VOT**：见 2.6 的建议。除阻用高频（约 2–7.6 kHz）、3 ms 窗、1 ms 步长的电平，取「2 ms 上升量达到区间最大上升量 50%，且上升后电平不低于区间最大值 25 dB」的最早帧。浊音用声门脉冲连续段。预发声判定和 VOT 符号见 2.6。

**擦音**：

- 噪声起点：1–7.6 kHz、10 ms 窗的电平，升到段内最大值 −25 dB 的最早帧。
- 噪声终点：覆盖韵母的浊音段起点。
- 上升时间：噪声起点到电平达到最大值 −3 dB 的时长。
- 频谱区间：噪声段 20%–80%。

**塞擦音**：噪声起点即除阻；频谱区间为除阻后 3 ms 起、长度 min(0.6 × VOT, 60 ms)；上升时间同擦音。

**噪声频谱**：20 ms Hann 帧、5 ms 步长的平均功率谱，约 300 Hz 平滑后在 0.5–7.6 kHz 内找谱峰；谱重心按未平滑功率在同一频带内计算；相对振幅 = 噪声段平均电平 − 后接元音段峰值电平。

**鼻韵尾**：见 2.9 的建议（1–4 kHz 与 50–500 Hz 的电平差，比韵母前半段中位数低约 10 dB 并保持到有声终点，至少 30 ms）。

**边音与 r**：声母中点、元音中点的 F1–F3（各取 ±10 ms 中位数），声母起点到元音中点内的 F3 最小值，声母段浊音占比（有 F0 的帧比例），声母段平均 HNR（Praat Harmonicity）。

### 5.6 `measurements.json` 的内容

每条录音（学习者、参考各一份）：

| 层级 | 字段 |
|---|---|
| 录音 | 时长；估计性别（由 F0 中位数）；五度音域及来源；共振峰上限；录音质量（来自 `check_signal`）；整条录音的说明列表 |
| 音节 | 拼音、汉字、目标调类；声母（标签、IPA、起止、时长、是否送气音）；韵母（标签、IPA、起止、时长、结构类型）；时长、时长占比；有声终点 |
| 声调 | Chao 调值、调形类别、起点 / 终点五度值、转折点、21 点五度值、是否可诊断 |
| 强度 | 音节峰值、元音段平均（相对本录音峰值） |
| 元音 | 区间与时长、终点来源（有声终点 / 鼻音段起点）、11 点 F1/F2/F3、中点 F1/F2/F3、中点 z 分数（有统计时） |
| 声母（按类别） | 塞音：除阻时刻、浊音起点、VOT、是否预发声。塞擦音：同上 + 上升时间 + 噪声频谱（谱峰、谱重心、相对振幅）。擦音：噪声起点、噪声时长、上升时间 + 噪声频谱。鼻音：鼻音段时长、元音起点 F2。边音 / r：声母中点与元音中点 F1–F3、F3 最小值、浊音占比、HNR |
| 鼻韵尾 | 是否检出、鼻音段起止和时长、元音中点 F2、鼻音段前 F2、F2 变化量 |
| 说明 | 该音节的可靠性说明（中文） |

对比部分（学习者 − 参考，逐音节）：调值对照、21 点平均五度差、起点 / 终点五度差；时长对照、时长占比差；元音中点 Hz 差（以及 z 分数差）；VOT、噪声时长、上升时间、谱峰、谱重心、相对振幅、鼻音段时长、F2 变化量的成对数值；是否同性别及相应说明；音节数不一致时不做对比并说明原因。

元数据：分析参数（窗长、步长、频带、阈值）、软件版本。这些只写在这里，不上图。

### 5.7 交给 LLM 的组织方式

这部分属于提示词层，但它决定了图像和数值的设计，一并给出建议：

- 输入：本关目标音、用户母语 / 方言背景、评分服务的检错结果、`measurements.json` 的对比部分、相关的 2–4 张图。
- 规则写进提示词：以数值为准、图像为辅；标为不可靠的项不给建议；音域为估计时不评价音高高低，只评价调形；性别不同时不比较共振峰 Hz。
- 常见偏误与母语背景的对应关系（例如「法语、西班牙语母语者常把 b/d/g 发成真浊音」「英语母语者常把 r 发成 [ɹ]」「日语母语者常混淆 u 与 ü」）作为提示词中的背景知识，不在测量代码里做判断。代码只负责给出可靠的数值和差值。
- 产品已有分数和现象标签（FR-1601：分数与现象标签由评分与声学模块稳定给出），LLM 只负责组织话术，不应推翻评分服务的检错结论。

### 5.8 验证计划

阈值和检测方法在接入前必须验证。开发集 66 条（2 位发音人 × 33 个音节）、验证集 96 条（4 位发音人 × 24 个音节）可用于以下检查：

| 检查 | 期望 |
|---|---|
| VOT：送气（p t k c ch q）与不送气（b d g z zh j） | 两组分布明显分开；没有误判的预发声 |
| 噪声谱峰、谱重心：s、sh、x（以及 z、zh、j 和 c、ch、q） | 在每位发音人内 sh < x < s 的排序稳定（需按性别分别看） |
| 上升时间：塞擦音与擦音 | 两组分开；若重叠严重，放弃这一指标 |
| 鼻韵尾：an1、ang2、tang1–4、xin1 | 鼻音段时长在合理范围（大约数十到一百多毫秒），没有 an1 那种 300 ms 的结果；非鼻韵母上不误检 |
| 有声终点 | 上声音节的升尾被包含在内 |
| 声调 | 产品 Chao 调值与目标调类一致的比例 |
| 对比层 | 用不同发音人的同音节做「学习者 / 参考」，差值应小；用故意错配的音节对（ba4 对 pa2、si1 对 shi1、an1 对 ang2、ma1 对 ma3）做对比，差值应明显并指向正确方向 |
| 多音节代码路径 | 拼接两条单音节录音并平移对齐时间，确认流程可运行 |
| 学习者录音 | 采集少量真实学习者录音（含前导静音、预发声、送气不足、韵尾脱落），这是现有语料无法替代的 |
| 性能 | 一对录音 1–3 s |

## 7. 范围外的发现（产品侧，建议单独核实）

1. **结果页声调曲线可能截掉上声升尾。** `scoring/rules.py` 用讯飞音节边界 `(t0, t1)` 作为 F0 分析区间。开发集上讯飞对齐常截掉尾部弱衰减段（最多约 110 ms），上声的升尾可能被截去，导致产品把 214 判成 21 一类。需要用语料核实。
2. **产品的 VOT 检测较粗。** `analysis.detect_onset_span` 用 10 ms F0 帧确定浊音起点，VOT 下限钳制为 5 ms，不支持负 VOT（预发声）。与 2.6 的问题相同。
3. **讯飞音素时间戳被丢弃**（见 5.2）。
4. **F0 有两套实现**（见 1.4）。如果 `imagery` 只作研究用途，可以保留；但任何面向用户或 LLM 的输出都应统一用 `f0_pipeline`。
