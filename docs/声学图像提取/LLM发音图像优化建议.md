### 一、 总体评估

该方案的整体架构具有明确的设计逻辑：采用“全局总览 + 针对特定音素类别的局部特征图”的动态路由策略（按 `tone`、`vowel`、`initial`、`nasal` 等优先级挑选），并配合结构化的 `measurements` 数值输出。这种图文互补的思路符合多模态大模型（VLM/LLM）的分析需求。

然而，结合测量参数与实际生成的样图来看，当前方案在**底层声学事件检测的鲁棒性**、**跨图数据一致性**以及**面向机器视觉的图形编码设计**上存在多处明显缺陷，部分算法参数设置导致提取出的声学特征与语音事实不符，若直接输入给 LLM，容易引发错误的语音学推论。

### 二、 准确性审查：算法逻辑缺陷与样图实测偏差

通过核对参数表与 8 张样图，可以发现当前测量管线存在以下 6 个核心准确性问题：

#### 1. “有声终点”强依赖有效 F0，导致元音与韵尾被大面积截断
* **问题机制**：参数表定义有声终点为“同时具有有效 F0、相对电平高于 −35 dB 的最后一帧”。在汉语单字发音或词末音节中，发音人常在元音中后段或鼻韵尾出现**声门化（creaky voice / 嘎裂音）**或周期不规则振动。此时语谱图能量依然很强，但 Praat 自相关法（Autocorrelation）会因周期倍增或抖动而丢失 F0。
* **样图实证**：
  * 在 `12b_nasal_broadband.png`（`an1`）中，语谱图清晰显示语音持续到 `0.60 s` 左右，但红色的 F1/F2 轨迹在 `0.35 s` 处突然终止。
  * 在 `13a_approximant_formants.png`（`la1`）中，语谱图持续到 `0.68 s`，但 F1/F2/F3 轨迹在 `0.42 s` 处突然中断（0.40 s 后脉冲条纹变疏，出现声门化），导致后半段约 260 ms 的稳态元音完全脱离分析区间。
* **修正建议**：有声终点的判定应以短时能量（Intensity）和低频段（如 100–1000 Hz）能量占比为主，F0 仅作为辅助参考，不应要求最后一帧必须具备有效 F0。

#### 2. 声门脉冲（PointProcess）在强送气段误触发，导致 VOT 与浊音起点失准
* **问题机制**：浊音起点依赖 Praat 周期声门脉冲连续 40 ms 的片段，且频率下限设为 `max(50 Hz, 0.7 × F0_p5)`。在送气塞音和送气塞擦音的末段，较强的低频随机气音湍流会在波形上产生间隔小于 20 ms（对应 50 Hz 以上）的局部峰值。若不结合谐噪比（HNR）或自相关峰值强度（Voicing threshold）进行过滤，PointProcess 会将纯送气噪声误判为声门脉冲。
* **样图实证**：
  * 在 `02_broadband.png` 和 `11a_affricate_stages.png`（`ca1`）中，绿色实线（浊音起点）标在了 `130.8 ms` 处。但观察 `11a` 顶部的波形图和中间的语谱图，130.8 ms 至 152 ms 之间完全是低振幅的无周期送气噪声，真正的周期性声带振动（元音起点）位于 `152 ms` 附近，VOT 测量值偏小约 21 ms。
  * 在 `09a_stop_vot.png`（`pa2`）中，波形在 `174 ms` 处已经出现第一个显著的周期性大振幅声门脉冲，但绿色实线滞后到了 `179.6 ms`（第二个周期处）。

#### 3. 摩擦噪声频段下限过低（0.5 kHz），导致谱峰、谱重心与上升时间测量失效
* **问题机制**：
  * 方案规定计算摩擦噪声谱重心使用 `0.5 kHz 至分析带宽`，且塞擦音从除阻后 3 ms 起最多取 60 ms；计算噪声包络与上升时间使用 `1 kHz 至分析带宽`。
  * 语音学上，舌尖前音（`z, c, s`）、舌尖后音（`zh, ch, sh`）和舌面音（`j, q, x`）属于咝音（sibilants），其主摩擦湍流集中在 2.5 kHz 以上。而在 0.5–2 kHz 频段内，往往存在极强的声道低频湍流、环境底噪或后接元音 F1/F2 的腔体耦合共振（尤其是送气阶段）。
* **样图实证**：
  * 在 `10b_fricative_mean_spectrum.png`（`ca1`）中，舌尖前音 `c` [tsʰ] 的主摩擦能量本应在 5–9 kHz，但由于未高通滤除低频腔体共振，测出的**谱峰仅为 861 Hz，谱重心仅为 1730 Hz**。这一数值完全失去了区分发音部位（齿龈 vs. 卷舌 vs. 龈腭）的语音学效力。
  * 在 `11a_affricate_stages.png`（`ca1`）底部的噪声电平包络图中，由于统计了 1 kHz 以上的全部能量，而后接元音 `a` 的 F2 恰好在 1.2–1.5 kHz，送气末段激发的 F2 共振能量高于前段的舌尖高频摩擦能量，导致噪声包络从 0 ms 到 120 ms 一路爬升，测出 `上升时间 71.5 ms`。这测量的是送气向元音过渡的腔体共振增长，而非塞擦音成阻释放后的摩擦包络上升时间。
* **修正建议**：计算咝音（sibilants）的谱峰和摩擦上升时间时，下限截止频率应提高至 1.5 kHz 或 2 kHz；对于送气塞擦音，必须先将**成阻摩擦段（Frication）**与**声门送气段（Aspiration）**切分开，仅在纯摩擦段内计算摩擦频谱和上升时间。

#### 4. 鼻韵尾候选的硬性时长与比例上限导致正常发音漏检
* **问题机制**：方案规定鼻韵尾候选“时长上限为 200 ms，占元音起点至有声终点区间的比例上限为 45%”。在单字朗读或慢速清晰发音中，鼻韵尾时长超过 200 ms、占比达到 50% 以上非常普遍（尤其是前响或短元音配鼻尾，如 `in, ing, en, eng, an`）。
* **样图实证**：在 `12b_nasal_broadband.png`（`an1`）中，语谱图上 `0.30 s–0.60 s` 是非常典型的鼻音段（时长约 300 ms，占比约 53%，低频鼻音杠清晰，中高频反共振明显）。但由于触发了 200 ms 和 45% 的硬性上限（或前述有声终点截断在 0.35 s 的问题），图中完全没有标出鼻音段的位置和时长，与方案表中承诺的“图中信息包含鼻音段位置和时长”不符。

#### 5. 共振峰追踪缺乏稳态约束，且元音轨迹包含了过渡段与静音尾段
* **样图实证**：
  * 在 `07c_formant_normalized.png`（`ca1`）左图中，单韵母 `a` 的 F1–F2 轨迹呈现从 `(1235, 630)` 到 `(1540, 1145)` 再原路折返至 `(1235, 695)` 的剧烈折返形态。结合右图可见，0%–20% 和 70%–90% 包含了刚脱离辅音的过渡段以及末尾能量衰减段。将整段（含头尾过渡）不加区分地画在 F1–F2 平面上，会使单韵母呈现出类似复韵母的轨迹特征。
  * 在 `12b_nasal_broadband.png`（`an1`）中，`0.13–0.18 s` 处 F2 突然垂直跌落并与 F1 重合，属于明显的 Burg 算法极点合并（Pole merging）失误，当前“5 帧邻域偏离中位数 20%”的清洗规则未能修正此类连续数帧的追踪跳变。

#### 6. 跨图表的时长数据与采样点数量不一致
* **样图实证**：
  * **时长冲突**：同一条录音 `ca1`，在 `02_broadband.png` 标题中总时长为 `780.4 ms`，声母标注 `160.0 ms`，韵母标注 `550.0 ms`（两者相加为 `710.0 ms`，缺失 70.4 ms）；而在 `07c_formant_normalized.png` 中，标题却标注 `ca1 · 元音 620.4 ms`（即 780.4 − 160.0）。同一音素在不同图中给出 `550.0 ms` 和 `620.4 ms` 两个数值，会直接干扰 LLM 的数值核对。
  * **采样点缺失**：方案规定 `07c` 右图展示元音区间 11 个位置（0%–100%），但实测图横轴仅绘制到 `90%`（共 10 个点），缺失了 100% 位置的数据点。
  * **标记缺失**：方案规定 `07c` 左图“圆点标起点、箭头标终点”，实测图中仅有起点圆点，无终点箭头。

### 三、 有效性审查：面向 LLM 视觉感知的图像设计问题

多模态大模型通过视觉编码器（ViT）将图像切分为 Patch 进行识别，其视觉特性与人类眼睛存在差异。当前图像设计存在以下不利于 LLM 读取的因素：

1. **多条曲线使用相同颜色，LLM 极难区分**
   * 在 `07c`（右图）、`12b`、`13a` 中，F1、F2、F3 全部采用同一种深红色绘制。`12b` 和 `13a` 完全没有线型或数据点形状的区别；`07c` 虽有极小的圆点、方块、三角标记，但在图像经过视觉编码器缩放后，几十像素内的微小几何形状差异很容易丢失。当两条共振峰轨迹靠近或相交（如 `13a` 的 0.03 s 处、`12b` 的 0.15 s 处）时，LLM 无法可靠区分哪条是 F1、F2 或 F3。
   * **改进**：F1、F2、F3 必须采用高对比度的不同颜色（例如蓝、红、绿或深橙），并直接在曲线起始/结束侧旁注文字标签 `F1`、`F2`、`F3`。
2. **F1–F2 元音图采用自适应动态坐标轴，缺乏绝对空间锚点**
   * `07c` 左图的横纵坐标范围是根据当前单条轨迹的极值自动缩放的（如横轴仅显示 1550–1150 Hz，纵轴 600–1150 Hz）。LLM 在看图时对视觉空间位置（左上、右下、居中）非常敏感，但对坐标轴刻度的细微变化不够敏感。动态缩放会导致无论是高元音 `[i]` 还是低元音 `[a]`，其轨迹都填满整个画布，容易诱导 LLM 对舌位高低前后做出错误判断。
   * **改进**：F1–F2 图应当固定坐标轴范围（或根据发音人性别固定标准范围，如 F1: 200–1200 Hz，F2: 500–3000 Hz），并在背景中用浅灰色虚线绘出该发音人（或标准普通话）的极端元音 `[i]`, `[u]`, `[a]` 构成的元音三角形作为视觉参考系。
3. **图中存在未在图例中说明的视觉元素**
   * `02_broadband.png` 中在 `0.16 s` 处有一条粉红色点状竖线（代表强制对齐的声韵边界），但右下角图例仅列出了“除阻”和“浊音起点”，未说明粉红色虚线的含义，也未画出韵母结束边界线。

### 四、 完备性审查：实验语音学分析的信息缺漏

为了支撑严谨的实验语音学分析，当前方案在以下模块缺少关键声学信息：

1. **声调分析（`05c_f0_normalized.png`）缺少绝对频率（Hz）与音域基准**
   * 图中仅展示了归一化后的五度值（1–5）。五度值完全取决于个人音域上下限（`f0_min`, `f0_max`）的设定。例如样图中 `ca1`（阴平，标准调值 55）被测为 `调值 43`（曲线在 3.5–3.8 之间）。如果不在图中标出对应的绝对基频（Hz，可在右侧增加双 Y 轴）以及本次换算所使用的音域上下限数值，分析者（及 LLM）无法判断“调值偏低”是因为发音人实际基频偏低，还是因为系统预设的个人音域上限过高导致的归一化压缩。
2. **摩擦音分析（`10b_fricative_mean_spectrum.png`）缺少高阶频谱矩**
   * 在实验语音学中，仅靠谱峰和谱重心（M1，一阶矩）不足以稳健区分不同发音部位的擦音/塞擦音（尤其是当发音人个体声道差异导致 `sh` 与 `x` 重心接近时）。通常需要完整提供**频谱四阶矩**：重心（Center of Gravity, M1）、标准差/离散度（Standard Deviation, M2，区分频谱集中与弥散）、偏度（Skewness, M3，反映频谱不对称性）和峰度（Kurtosis, M4），并在图例或标注中列出。
3. **塞擦音分析（`11a_affricate_stages.png`）缺少闭塞段、摩擦段与送气段的独立切分**
   * 塞擦音的核心声学特征是“除阻脉冲 + 强摩擦段 +（送气段）”。当前方案将除阻到浊音起点笼统合称为 VOT，未能在送气塞擦音（`c, ch, q`）中区分舌尖/舌面摩擦时长与声门送气时长；而在多音节词中，还缺少词中塞音/塞擦音的**成阻闭塞段时长（Closure duration）**测量。
4. **鼻音分析（`12b_nasal_broadband.png`）缺少前鼻音与后鼻音的鉴别特征**
   * 汉语实验语音学分析鼻韵母的核心需求之一是区分前鼻音（`-n`）与后鼻音（`-ng`）。仅展示鼻音段时长是不够的，真正决定感知与发音部位的是**元音向鼻音过渡段的 F2 移动方向**（例如在 `an` 中 F2 上升或持平，在 `ang` 中 F2 下降；在 `in/ing`、`en/eng` 中表现为 F1/F2 间距及鼻化度 A1–P0 的差异）。需要在图中及测量值中明确标出元音中点到元音末尾（鼻音起点）的 $\Delta\text{F1}$、$\Delta\text{F2}$ 斜率或差值。

### 五、 冗余性审查与精简建议

向 LLM 输入过多图像不仅会显著增加视觉 Token 消耗和推理延迟，还可能因多图细节不一致而分散模型注意力。当前方案存在以下冗余与低效环节：

1. **`02_broadband.png` 与局部语谱图（`09a`、`11a`、`12b`、`13a`）高度重叠**
   * 对于单音节录音（如样图所示），`02_broadband.png` 中的除阻、浊音起点、语谱图在 `09a`/`11a` 中被放大重画了一遍，在 `12b`/`13a` 中又以 0–5 kHz 的频率上限重画了一遍。
   * **优化建议**：
     * 在 `02_broadband.png` 上直接叠加绘制共振峰轨迹（F1–F3）和基频曲线（F0），使总览图真正具备综合判读能力。
     * 如果是单音节且已生成专门的声母/鼻音局部语谱图（如 `11a`、`12b`、`13a`），或者针对特定子任务（如仅评估 `tone` 或 `vowel`），无需每次都重复输入空白信息较多的 0–12 kHz 全景图 `02_broadband.png`（元音和鼻音在 5–12 kHz 区域基本为空白，占用大量无效像素）。
2. **`07c_formant_normalized.png` 左右两图的信息承载效率偏低**
   * 右图是 F1/F2/F3 对归一化时间（0%–100%）的折线图，而 `12b`/`13a`（或改进后的 `02`）中已经有了叠加在语谱图上的真实时间轴 F1/F2/F3 轨迹。
   * 相比于脱离语谱背景的纯折线图（右图），**直接将共振峰轨迹画在 0–5 kHz 的宽带语谱图上**对实验语音学分析更有价值——因为 LLM 和研究人员可以直观地看到红线是否准确贴合在语谱图的深色能量条带（共振峰暗带）中心，从而一眼识别出 Burg 算法的追踪错误（如 `12b` 中 0.15 s 处的跳变）。在单独的折线图（`07c` 右图）上，无法判断曲线波动是发音人真实的舌位移动还是算法追踪失误。
3. **图像纵横比（Aspect Ratio）过于扁长，有效像素占比低**
   * 当前所有样图的宽高比接近 `11:4`（约 1600×580），画布中存在大面积空白。许多多模态模型在处理超宽图像时，会将其缩放到固定正方形网格或切分为多个子块，导致文字标注和细线变得模糊。建议调整子图排版（如将单张过宽的图改为紧凑的上下双栏或标准 `4:3` / `16:9` 比例），加粗线条与字号，提升视觉编码器的识别精度。

### 模块一：发音人基线建档与克隆参考生成（前置校准）

在正式分析一至两个音节的目标语音前，通过采集少量校准语音建立发音人的声道与声带生理基线，并生成同声线的标准参考音。

#### 1.1 边缘元音采集与个体元音空间建档
* **采集内容**：要求发音人以自然、平稳的阴平调发四个边缘单韵母：`衣 [i]`、`乌 [u]`、`啊 [a]`、`迂 [y]`，每个持续约 0.5–1.0 秒。
* **提取参数与用途**：
  1. **稳态段截取**：取每个元音有声区间中部的 30%–70% 区间。
  2. **个体最优共振峰上限（Optimal Max Formant）标定**：由于不同个体的声道长度差异较大，固定 5000 Hz 或 5500 Hz 容易产生极点合并或伪共振峰。系统在 4500 Hz 至 6300 Hz 之间以 100 Hz 为步长遍历 Praat Burg 算法的上限参数（参考 FastTrack 算法逻辑），选择使四个边缘元音内部共振峰轨迹最平滑（一阶差分方差最小）且满足 $[i], [u], [a]$ 拓扑分离度最大的频率值，作为该发音人的专属 `speaker_max_formant`。
  3. **个人元音空间锚点**：记录该发音人 $[i], [u], [a], [y]$ 的 $F1, F2, F3$ 均值与标准差，用于后续在元音图背景中绘制“个人生理元音四边形”，并计算 Lobanov 归一化 Z 分数。

#### 1.2 连续语流采集与个体音域建档
* **采集内容**：要求发音人朗读一段包含四声及轻声的均衡短文或长句（时长 15–30 秒，约 40–80 字）。
* **提取参数与用途**：
  1. **双引擎基频提取**：同时运行 Praat 滤波自相关法（Filtered Autocorrelation，抑制倍频与半频跳变）与神经网络基频提取器（如 RMVPE 或 CREPE），仅保留两者偏差小于 5% 的高置信度有声帧。
  2. **稳健音域上下限计算**：剔除离群值，取连续语流基频分布的 **第 5 百分位数（$F0_{p5}$）作为音域下限 $F0_{\min}$**，**第 95 百分位数（$F0_{p95}$）作为音域上限 $F0_{\max}$**，并记录中位数 $F0_{\text{med}}$。
  3. **五度值映射公式**：采用对数半音（Semitone）或 T 值公式将目标语音的 $F0$ 映射为连续五度值：
     $$T = 4 \times \frac{\log_{10}(F0) - \log_{10}(F0_{\min})}{\log_{10}(F0_{\max}) - \log_{10}(F0_{\min})} + 1$$
     （允许结果在 $0.5$–$5.5$ 之间浮动，避免硬截断掩盖超调或低调现象）。

#### 1.3 个人声线标准参考音生成（Voice Cloning Reference）
* **实现路径建议**：相比于直接用零样本 TTS（文本转语音）生成参考音，实验语音学分析更推荐采用**“标准发音人录音模板 + 零样本音色转换（Voice Conversion，如 Seed-VC / FreeVC）”**的混合方案：
  1. 预先录制好专业播音员或语音学专家的 1–2 音节标准词库作为“声学黄金模板”。
  2. 利用音色转换技术，将黄金模板的音色（声道共振峰分布）转换为当前发音人的声线，同时将黄金模板的五度值基频曲线按当前发音人的 $[F0_{\min}, F0_{\max}]$ 逆映射为绝对 Hz。
* **应用边界**：转换后的标准参考音同步运行相同的声学提取管线。其**基频曲线、元音共振峰轨迹、音节时长占比**可作为同图表内的“浅色参考基线”；但塞音除阻瞬态（Burst）与摩擦音高频谱矩仍以真实语音学统计常模为准（因为声码器会对瞬态噪声产生平滑效应）。

### 模块二：多源融合边界精修与核心声学参数提取

强制对齐（如 MFA）基于 10 ms 帧移的声学模型，其边界精度通常存在 10–30 ms 的误差。系统需以强制对齐结果作为粗略搜索窗，结合时频信号特征生成**全局统一的时间戳对象（Master Timeline）**，所有图表共享同一套时间锚点。

#### 2.1 全局时间锚点与边界精修参数

| 边界/事件名称 | 搜索范围（基于强制对齐 FA） | 信号处理方法与判定准则 | 解决的核心问题 |
| :--- | :--- | :--- | :--- |
| **除阻时间 ($t_{\text{burst}}$)** | FA 声母起点前 20 ms 至声母后 60% 处 | 3 ms 窗长、1 ms 帧移，计算 2 kHz–12 kHz 高频能量包络。取一阶差分（1 ms 步长能量上升率）达到局部峰值 50%、且此前至少有 15 ms 低能量闭塞段的时刻。 | 消除呼吸音误判，精确锚定塞音与塞擦音释放瞬态。 |
| **摩擦段与送气段交界 ($t_{\text{fric\_end}}$)** | 仅针对送气塞擦音（`c, ch, q`）：$t_{\text{burst}}$ 后 10 ms 至浊音起点 | 5 ms 窗长、1 ms 帧移，计算高频摩擦带（3–10 kHz）与中频声道共振带（0.8–2.5 kHz）的能量比值（dB）。取该比值从高位下降并跌破 0 dB（中频气音共振开始占优）的时刻。 | 将塞擦音切分为“纯摩擦段”与“送气段”，避免送气腔体共振污染摩擦频谱。 |
| **浊音起点 ($t_{\text{voicing}}$)** | FA 声韵交界前后 $\pm 40\text{ ms}$ | 联合判定准则（需同时满足且持续 $\ge 25\text{ ms}$）：<br>1. Praat 周期声门脉冲（PointProcess）存在；<br>2. 局部谐噪比 $\text{HNR} > 3.0\text{ dB}$；<br>3. 0.1–1 kHz 低频能量大于 2–8 kHz 高频能量至少 6 dB。 | 阻止强送气末段的低频湍流被误判为声门脉冲，修正 VOT 偏小问题。 |
| **鼻韵尾起点 ($t_{\text{nasal\_on}}$)** | 含 `-n/-ng` 韵母：FA 韵母中点至有声终点 | 若 FA 模型支持子音素切分（将韵母拆为元音核+鼻尾），在 FA 鼻尾边界 $\pm 30\text{ ms}$ 内精修；否则计算 800–2500 Hz 能量相对 100–400 Hz（鼻音杠）的能量差，取一阶负导数最大（中频能量陡降而低频维持）的时刻。取消 200 ms 和 45% 的硬性上限。 | 准确分离元音段与鼻音闭塞段，支持慢速朗读中长鼻尾的完整提取。 |
| **有声终点 ($t_{\text{offset}}$)** | FA 韵母终点前 100 ms 至后 80 ms | 20 ms 窗长、5 ms 帧移。满足以下任一条件即视为有声：<br>1. 具有有效 $F0$ 且相对峰值强度 $> -35\text{ dB}$；<br>2. 虽无常规 $F0$（处于嘎裂音/声门化状态），但 100–1000 Hz 频段能量相对环境底噪高出 $12\text{ dB}$ 以上，且存在非周期性声门脉冲峰值。 | 防止单字尾或上声（第三声）常见的嘎裂音段因丢失 $F0$ 而被提前截断。 |

#### 2.2 细分声学特征提取参数

| 分析模块 | 方法与具体参数设置 | 提取的核心指标 |
| :--- | :--- | :--- |
| **基频与发声态** | 1. 帧移 5 ms，融合 Praat 滤波自相关法（搜索范围：$0.7 \times F0_{\min}$ 至 $1.3 \times F0_{\max}$）与 RMVPE。<br>2. 在 $[t_{\text{voicing}}, t_{\text{offset}}]$ 区间内剔除声母扰动段（前 15 ms），按时间归一化均匀取 21 个点。<br>3. 识别嘎裂音段（Creaky intervals）：有声但自相关峰值 $< 0.6$ 或相邻脉冲周期抖动（Jitter）$> 3\%$ 的连续区间。 | 1. 21 点绝对频率（Hz）与个人五度值（1–5）；<br>2. 起调值、折点值、收调值及斜率；<br>3. 嘎裂音起止位置与时长占比。 |
| **元音共振峰** | 1. | **塞音与塞擦音** | 1. **闭塞段（Closure）**：双音节第二音节的声母，测量前一音节 $t_{\text{offset}}$ 至本音节 $t_{\text{burst}}$ 的时长及是否存在浊音杠（Voicing bar）。<br>2. **VOT 与分段时长**：塞音测量 $\text{VOT} = t_{\text{voicing}} - t_{\text{burst}}$；塞擦音分别测量**纯摩擦时长**（$t_{\text{fric\_end}} - t_{\text{burst}}$）、**送气时长**（$t_{\text{voicing}} - t_{\text{fric\_end}}$）及总 VOT。 | 1. 闭塞段时长（ms）、预发声时长（ms）；<br>2. 塞音 VOT（ms）；<br>3. 塞擦音摩擦段时长、送气段时长、总 VOT 及摩擦包络上升时间（仅在纯摩擦段 2–10 kHz 内计算）。 |
| **擦音与塞擦音谱矩** | 1. **取样区间**：擦音取摩擦段中部的 20%–80%；塞擦音严格在**纯摩擦段** $[t_{\text{burst}} + 5\text{ ms}, t_{\text{fric\_end}}]$ 内取样。<br>2. **频带限制**：经 **1.5 kHz 高通滤波**（消除声道低频腔体共振），上限 12 kHz（采样率 44.1 kHz），使用多窗口谱估计（Multitaper Spectrum）或 20 ms Hann 窗平均功率谱。 | 1. **频谱四阶矩**：重心（COG/M1，区分前后部位）、标准差（SD/M2，区分频谱集中度）、偏度（Skewness/M3）、峰度（Kurtosis/M4）；<br>2. 主谱峰频率（Hz）及高频摩擦相对后接元音的电平差（dB）。 |
| **鼻音与鼻化度** | 1. **过渡段征**：提取纯元音中点（50%）至元音末点（即 $t_{\text{nasal\_on}}$ 前 10 ms）的 $F1, F2, F3$ 变化量。<br>2. **声学鼻化度**：在元音后半段提取第一共振峰谐波振幅 $A1$ 与低频鼻音极点振幅 $P0$（约 250–350 Hz 处最强谐波）之差 $A1 - P0$（dB）。 | 1. 鼻音段绝对时长（ms）与韵母占比（%）；<br>2. 过渡段 $\Delta F2$（Hz）与斜率（Hz/ms，核心区分 `-n` 上升/持平 vs. `-ng` 下降）；<br>3. 鼻音共振峰 $FN1$ 频率及元音鼻化度指标 $A1 - P0$。 |
| **边音 `l` 与近音 `r`** | 1. 在声母稳定段与过渡段追踪 $F1, F2, F3$。<br>2. 计算声母区间内的谐噪比（HNR，10 ms 步长）与高频摩擦噪声占比（防止将 `r` 发成强擦音 `[ʐ]` 或清化）。 | 1. 声母段 $F3$ 最小值（区分卷舌程度，`r` 通常 $< 2200\text{ Hz}$）；<br>2. 声母至元音交界处的 $\Delta F1$ 跃升速率（检验边音 `l` 舌尖除阻的干脆度）；<br>3. 声母段 HNR（dB）与浊音帧占比（%）。 |

### 模块三：面向多模态 LLM 的图像生成方案

#### 3.1 面向机器视觉的全局绘图规范
为确保多模态大模型能够准确读取视觉特征，消除视觉混淆，所有图像遵循以下四项规范：
1. **固定画幅与高密度排版**：统一采用 **`16:10` 或 `4:3` 比例**（例如 `1200 × 800` 像素），避免超宽扁平长条图被模型缩放后丢失细节。字号不小于 12 pt，核心轨迹线宽不小于 2.0 pt。
2. **严格色彩编码与端头直标**：
   * 在任何叠加共振峰的图中，固定使用高对比度色彩：**$F1$ 为亮蓝色（`#0066CC`）**，**$F2$ 为鲜红色（`#CC0000`）**，**$F3$ 为深绿色（`#008844`）**，并在每条曲线的右侧末端直接打印文字标签 `F1`、`F2`、`F3`，不依赖单独的颜色图例。
   * 若叠加展示克隆标准参考音，**被试实测曲线用实线**，**同声线克隆参考曲线用同色半透明虚线**。
3. **语义化背景色块（Shaded Regions）**：所有垂直切分边界（除阻、摩擦结束、浊音起点、鼻音起点、有声终点）不仅画竖线，还在顶部时间轴下方用带有文字标签的微透明色块标出阶段名称（如 `[闭塞]`、`[摩擦]`、`[送气]`、`[元音]`、`[鼻尾]`、`[嘎裂音]`）。
4. **物理坐标系锁定**：元音空间图（$F1\text{–}F2$）与声调图（五度值）必须锁定坐标轴范围，禁止随单条数据的极值动态缩放。

### 模块四：结构化数值输出与图像动态路由策略

#### 4.1 结构化数值输出（`measurements` JSON 规范）
为防止 LLM 出现视觉读数偏差，所有图表中展示的特征均同步以结构化 JSON 文本注入 Prompt。每个指标包含四个字段：
1. `measured_value`：被试实测值（含单位）。
2. `reference_value`：个人声线克隆标准音的对应测量值（或语音学常模区间）。
3. `delta_or_zscore`：实测值与参考值的差值（如 $\Delta\text{VOT}$、五度值曲线 RMSE、共振峰 Bark 距离或个人空间 Z-score）。
4. `confidence_flag`：测量可靠性标记（例如：`normal`、`creaky_voice_detected`、`low_snr_warning`、`formant_ceiling_adjusted`）。

#### 4.2 图像动态挑选与路由规则
为控制单次输入给 LLM 的图像数量（建议每次请求控制在 **2 至 4 张图** 以内，保证视觉注意力集中），系统根据任务目标与音节音素构成按以下规则自动挑选图像：

| 分析模式 / 音素构成 | 必选基础图 | 条件追加图（按音素触发） | 单次总图数 |
| :--- | :--- | :--- | :--- |
| **综合诊断模式（General）** | `P01_overview_prosody.png`<br>`P02_tone_vowel_norm.png` | 按音节中包含的声母/韵尾属性，自动追加对应的 `P03`、`P04`、`P05` 或 `P06`（若双音节含同类声母，合并在同一张图的左右子图中展示）。 | 2–4 张 |
| **声调与韵律专项（Tone & Prosody）** | `P01_overview_prosody.png`<br>`P02_tone_vowel_norm.png` | 无（`P01` 提供真实时长、连读变调、轻声强度比与嘎裂音位置；`P02` 提供归一化调型与克隆基准对比）。 | 2 张 |
| **元音与韵母专项（Vowel & Final）** | `P01_overview_prosody.png`<br>`P02_tone_vowel_norm.png` | 若韵母含 `-n` 或 `-ng`，追加 `P05_nasal_dynamics.png`；若为儿化音或舌尖元音，追加 `P06`。 | 2–3 张 |

通过这一方案，前端信号处理管线解决了嘎裂音截断、送气脉冲误判、低频共振污染谱矩以及共振峰极点跳变等底层测量问题；同时通过个体校准建立的元音多边形、音域基准以及同声线克隆参考轨迹，为多模态 LLM 提供了具备明确物理参照系的视觉与数值输入。
