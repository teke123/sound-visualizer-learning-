# 音频分析图像功能说明

## 调用流程

用户提交关卡录音后，评分任务 `run_pipeline` 读取 44.1 kHz、单声道、16-bit PCM WAV，计算录音质量并提取一次基频轨迹。评分服务的音节与音素时间戳转换为秒，构成分析对齐。测量层复用基频轨迹，生成共振峰、声门脉冲、宽带与窄带语谱、强度、声学事件和逐音节特征。任务在 `finalizing` 阶段按关卡类别选择图像，并把 `pronunciationEvidence` 写入评测结果。

结果页可查看图像，下载测量数据与 AI 发音建议材料。命令行入口通过 `--goal` 选择关注方向，通过 `--all-figures` 生成全部适用图像。

## 共用测量

| 项目 | 方法与参数 |
| --- | --- |
| 采样与带宽 | 分析采样率为 44.1 kHz。宽带语谱和噪声频谱上限为 12 kHz；源录音带宽取 `min(12000 Hz, 源采样率 × 0.475)`。 |
| 宽带语谱 | Praat/Parselmouth 使用 5 ms 窗长参数、2 ms 时间步长、40 Hz 频率步长；每条录音按本条语谱峰值换算为相对 dB。 |
| 窄带语谱 | Praat/Parselmouth 使用 12.5 ms 窗长参数、5 ms 时间步长、20 Hz 频率步长；与宽带语谱共用同一相对 dB 基准。 |
| 图像时间窗口 | 取评分服务返回的首个音节起点前 100 ms 到最后音节终点后 100 ms，并限制在录音范围内。P01 显示该窗口；局部图根据声学事件取窗口内对应时段。 |
| 基频 | 产品 `f0_pipeline` 使用 Praat 自动相关法，10 ms 帧移，50–800 Hz 搜索范围，最多 15 个候选，经过产品四步清洗。每音节输出 21 个位置的 Hz 和五度值，并计算 Chao 调值。 |
| 音域 | 产品使用受理录音时保存的个人音域快照；独立命令行可传入音域上下限。五度值由该音域对数映射得到。 |
| 相对强度 | 25 ms 均方根窗、5 ms 帧移，以本条录音峰值为 0 dB。 |
| 有声终点 | 在韵母末端附近，以有效基频及相对强度，或低频能量与声门脉冲定位。低频分析使用 100–1000 Hz、20 ms 窗、5 ms 帧移，候选电平高于环境底噪 12 dB。 |
| 共振峰 | Praat Burg 方法：25 ms 窗、5 ms 帧移、50 Hz 起预加重。个人 `speaker_max_formant` 可指定上限；其余录音按基频中位数选择 5000 或 5500 Hz。连续有效轨迹经五帧中值与三次样条平滑；往返跳轨、共振峰合并及离群帧记入逐点测量状态。 |
| 元音取样 | 韵母的元音区间取 0%–100% 共 11 点；单韵母图聚焦 30%–70% 稳态段。每个取样点使用前后 10 ms 内有效帧的中位数，并输出稳态 F1/F2/F3、轨迹长度与方向。 |

## 声母、鼻尾与元音空间

| 项目 | 方法与参数 |
| --- | --- |
| 除阻 | 在声母起点前 20 ms 至声母末段，按 3 ms 窗、1 ms 帧移计算 2 kHz 以上高频电平；选取 2 ms 上升量达到局部最大上升量 50% 的候选。 |
| 浊音起点与 VOT | 声门脉冲、局部谐噪比大于 3 dB、100–1000 Hz 相对 2–8 kHz 电平高于 6 dB 的状态持续至少 25 ms 时确定起振。`VOT = 浊音起点 − 除阻时间`；负值表示预发声。 |
| 塞擦音分段 | 送气塞擦音在除阻后用 3–10 kHz 与 0.8–2.5 kHz 电平比定位摩擦末端；与初始摩擦段相比下降 10 dB 且持续 5 ms 的时间点作为交界。由交界计算纯摩擦和送气时长。 |
| 摩擦频谱 | 咝音从 2 kHz 至分析带宽取频谱，f/h 从 1.5 kHz 起。20 ms Hann 窗、5 ms 帧移、1024 点 FFT；平滑带宽约 300 Hz。输出谱峰与功率加权的一至四阶矩，以及摩擦段相对后接元音的电平差。 |
| 鼻韵尾 | 用 800–2500 Hz 与 100–400 Hz 的电平差定位持续至有声终点的低频优势区间；25 ms 窗、5 ms 帧移，阈值为相对元音前半段下降 10 dB，最短时长 30 ms。输出鼻尾时长、占比、元音中点至鼻尾起点的 ΔF1/ΔF2/ΔF3，以及 ΔF2 斜率。 |
| 鼻化度 | 在元音和鼻尾区间计算 F1 附近能量与 250–350 Hz 低频鼻音极点能量之差 `A1−P0`，并输出中低频能量差曲线。 |
| l/r 过渡 | 输出声母中点与元音中点 F1–F3、F3 谷值、声韵交界 ΔF1、声母有效基频帧占比、10 ms 步长谐噪比及高频电平曲线。 |
| 个人元音空间 | 由同一发音人的 `i/u/a/ü` 录音建立。每个元音取有声区间中部 30%–70%，在 4500–6300 Hz 间以 100 Hz 步长选择 Burg 上限；输出四个锚点的 F1/F2/F3 均值、标准差及整体 F1/F2 z 分数参数。 |

`P02` 从四元音标定结果中读取 `i/u/a` 三个锚点，按 `13 × atan(0.00076 × f) + 3.5 × atan((f / 7500)^2)` 将 F1、F2 从 Hz 转为 Bark，再绘制个人元音三角形和当前元音轨迹。`measurements` 包含当前元音的原始 Hz 测量与 Bark 绘图坐标。

已有 FV1 发音人的 `yi1_FV1.wav`、`wu1_FV1.wav`、`a1_FV1.wav` 和 `yu2_FV1.wav` 用于个人元音空间测试。分析结果通过 `vowel_norm` 传入录音对象；产品从已有标定快照读取元音空间。标准参考由独立输入提供，产品当前使用学习者录音数据。

## 输出与命令行

`measurements.json` 含分析参数、软件版本、音域来源、个人元音空间、每音节测量值与 `reliability`。图像与测量数据共享时间锚点；存在参考录音时，`comparison` 包含逐项差值及 `can_use`。`llm_input.json` 保存提示词、上下文、测量值和所选图像名称。

```sh
python -m app.acoustics.pronunciation_figures --audio learner.wav --alignment alignment.json --output output --goal initial
```

`--goal` 支持 `general`、`tone`、`vowel`、`initial`、`nasal`；`--all-figures` 输出该录音适用的全部图像；`--vowel-space` 读取个人元音空间 JSON；`--pitch-range LOW HIGH` 提供音域。显式参考录音使用 `--reference`、`--reference-alignment` 和 `--reference-pitch-range`。
