# 基频（F0）提取、异常清洗、五度标音与双轨可视化升级方案

## 一、 核心设计原则：同源同轨（Same-Pipeline Overlay）

目标：优化当前的基频提取和展示效果，使静音、清音、嘎裂/气泡音、音高跳跃得到合理处理，并根据用户本人音域进行五度标音。

**用户录音**与**标准示范录音（默认发音人）**必须走**相同的声学提取、异常清洗、分段修剪、平滑、等距重采样与个人音域归一化管线**。

- 标准发音人有其自身的参考音域 $[f_{\text{lo}}^{\text{ref}}, f_{\text{hi}}^{\text{ref}}]$；
- 用户有其自身的个人音域 $[f_{\text{lo}}^{\text{user}}, f_{\text{hi}}^{\text{user}}]$；
- **用户已经通过前置音域标定得到个人音域。每次练习直接读取并冻结该音域，不根据当前录音重建或滚动更新音域。**
- 双方各自完成声学清洗与归一化后，在统一的音节相对时间轴与五度坐标系中对齐叠加。
- 前端 MPM 实时轨用于即时反馈；后端 Praat 轨用于录音结果、调值和现象诊断。两者统一音域、坐标映射和时间单位。
- 结果页保留静音和清音断口，按音节展示可用曲线；低周期性片段通过置信度样式呈现。

实现主线：**完整录音提取 → 帧级质量判断与候选纠偏 → 音节有声核心定位 → 短毛刺缺口修补 → 分段平滑 → 五度映射 → 绘图序列与比较序列分别输出**。

## 二、 后端基频提取与多候选解算管线

### 1. 信号预处理与双特征同步提取

1. **统一重采样与直流偏置处理**：
   - 输入音频统一转为 `16000 Hz` 单声道 PCM，转浮点后减去均值去除直流偏置。
   - 保留原始幅度，计算 RMS、背景噪声和相对音节峰值的能量差。
2. **Praat `To Pitch (filtered ac)` 宽域提取**：
   - 使用 **`To Pitch (filtered ac)`**，在自相关前对信号做高斯低通滤波，抑制高次谐波与声道第一共振峰 F1 对音高提取的干扰。
   - 首版采用单趟提取，参数集中配置，正文与第八节调用示例使用同一套配置：
     - `time_step = 0.010`（10 ms 帧移）
     - `pitch_floor = 50.0` Hz
     - `pitch_top = 800.0` Hz（filtered AC 的顶部参数，配合 `attenuation_at_top` 定义高斯低通滤波）
     - `max_number_of_candidates = 15`
     - `very_accurate = False`
     - `attenuation_at_top = 0.03`
     - `silence_threshold = 0.09`
     - `voicing_threshold = 0.50`
     - `octave_cost = 0.055`、`octave_jump_cost = 0.35`、`voiced_unvoiced_cost = 0.14`
   - 提取搜索范围与个人五度音域分别配置。低音域使用更低的 `pitch_floor` 时，实时窗口长度和后端配置同步适配；恢复阶段使用相同搜索范围中的候选。
3. **同步提取每帧候选集与短时强度（Intensity）**：
   - 保存 Praat 选定的频率，以及每帧完整的有声候选集合 `candidates[i] = [(frequency, strength), ...]`，供异常区间重选使用。
   - `selected_array["frequency"]` 是 Praat 路径优化后的结果；保留该结果作为原始轨，后处理生成独立的处理轨。
   - 调用 Praat `To Intensity (50.0, 0.010, "yes")`，用线性插值对齐到 `Pitch` 的时间网格 `t`，得到逐帧能量 `intensity_db[i]`。
   - 背景能量优先取录音前置静音段的中位数；无前置静音时取整段能量低分位数。各音节单独计算峰值能量。
   - ZCR、HNR、SHR 作为后续增强特征；首版使用候选强度、相对能量与时间连续性完成弱周期片段处理。

### 2. 运行环境与复用方式

- 使用已通过 GitHub Actions 构建并支持 filtered AC 的 Parselmouth 开发版，固定构建产物或提交号，并记录 `parselmouth.VERSION`、`PRAAT_VERSION` 和 `PRAAT_VERSION_DATE`。
- `tone_py.inspect` 复用 `_detect_token_artefacts()` 的 numpy 检测逻辑，在项目内包装稳定接口。
- `tone_py.resample` 复用 near/far 重采样规则，对逐帧置信度和来源字段显式实现传播。
- 单音节五度数字使用项目内新函数，复用 `tone_py.chao` 的取点逻辑和 `classify_contour()`。
- `tone_py.sonify` 按第五节接入实际时间和静音掩码。
- 两趟提取及其他引擎列为后续算法对比项，首版围绕 filtered AC 完成整条管线。

## 三、 静音段、嘎裂（气泡音）与音高跳跃的四步清洗流水线

完整原始帧、候选与音节粗边界在处理期间保留。恢复和纠偏完成后，再确定最终有声核心区间。

### Step 1：帧网格保留与孤立伪有声点处理（Silence & Unvoiced Handling）

1. **孤立伪有声点剔除**：
   - 扫描原始有声掩码 `voiced = np.isfinite(f0) & (f0 > 0)`，连续有声游程长度 `< 2` 帧的孤立点置为 `NaN`，记录删除原因并保留候选。
2. **静音断口保留原则**：
   - 音节内部的无有效 F0 帧在原始时间网格上保留，输出为 `null`；前端使用 `connectNulls: false`。
   - 缺口描述“此处无有效音高值”；声音是否持续由候选和能量辅助判定。
   - 原始清音、静音和持续缺测段保持断开。Step 4 仅对经过异常检测删除的短毛刺片段进行修补。
3. **音节粗边界**：
   - 沿用现有音节时间戳，把后续检测、恢复和纠偏限制在各自音节内。
   - 单字录音在缺少有效音节时间戳时使用整段录音作为粗区间。

### Step 2：嘎裂 / 气泡音附近的弱周期片段处理

普通话第三声谷底与第四声句尾常出现生理性嘎裂（不规则脉冲或双周期振动 Diplophonia）。保留其中有效的低频走势，以候选强度、相对能量和连续性接纳弱周期片段。

1. **已有低频值**：
   - 对持续下滑或稳定处于低频的有效轨迹，保留实测频率。
2. **弱周期候选恢复（Creaky Rescue Pass）**：
   - 对紧邻稳定浊音段的内部缺口（最长 120ms）和音节尾部（最长 100ms），检查各帧有声候选。
   - 初始接纳参数集中配置：候选强度 `>= 0.30`；帧能量 `>= max(floor_db + 6dB, peak_db - 22dB)`。
   - 使用第三步的区间路径方法选择连续候选，并与已有稳定帧连接；内部片段使用两侧锚点，尾部片段使用前侧锚点。
   - 恢复帧记录 `source = "corrected"`，并按选中候选强度保留较低置信度。其余帧保持 `null`。
3. **低频与八度纠偏分开处理**：
   - 嘎裂附近的低频值按实测轨迹保留，八度纠偏统一在 Step 3 使用候选路径执行。
   - 五度音域下界用于坐标映射；声学处理保留低于该下界的有效频率。

### Step 3：音高跳跃检测与候选重选（复用并强化 `tone_py/inspect.py`）

1. **Sundberg 速率阈值与八度比检测**：
   - 将有声帧序列转换为半音：$ST[i] = 12 \log_2(f_0[i] / 55)$。
   - 在同一音节的连续有效段内，计算相邻帧（时间差 $\Delta t$ 秒）的每 10ms 归一化半音变化率：
     $$\Delta ST_{10\text{ms}} = \frac{ST[i] - ST[i-1]}{\Delta t / 0.010}$$
   - 触发跳变标记的初始条件（满足其一）：
     - 上升速率 $> +1.263\text{ ST}/10\text{ms}$；
     - 下降速率 $< -1.714\text{ ST}/10\text{ms}$；
     - 频率比 $f_0[i] / f_0[i-1] > 1.95$ 或 $< 0.51$。
   - 以上阈值用于定位待检查片段，统一配置并结合回归录音调参。
   - **异常侧判定与 Carryover 双向扩展**：比较相邻两帧距音节中位数半音的距离，将旗标打在较远的一帧；沿用 `carryover_mult = 1.5` 向两侧扩展，得到连续待检查区间。
2. **区间候选路径纠偏**：
   - 对每个待检查区间，从原始候选集合中选择一条整体连续的路径，保留原路径作为比较项。
   - 使用动态规划，以候选强度的负对数作为观测代价，以相邻候选半音差作为连接代价，并加入与区间外锚点的连接代价；代价权重集中配置。
   - 区间内部使用两侧可靠锚点；起音与收尾使用可用的一侧。锚点取邻近未被标记、候选强度 `>= 0.50` 的有效帧。
   - 选中候选路径后更新处理轨，记录原频率、处理后频率和修正原因；倍频/半频错误通过选择对应候选修正。
   - 内部区间以两侧锚点的半音线性连线为初始参考，候选偏离参考超过 `2.5 ST` 时增加惩罚；只有新路径总代价低于原路径时才替换。单侧区间以邻近稳定帧的短时趋势外推作为参考。
   - 候选缺失或路径连接不合适的异常帧置为 `NaN`，交由 Step 4 处理。
3. **按音节报告可用程度**：
   - 每个音节统计有效帧数、覆盖率和剩余跳变密度。覆盖率分母为最终分析区间内的原生网格帧数。
   - 有效曲线按音节返回，个别异常片段保留断口；整段录音有任一可绘制音节即可显示结果。
   - 现象诊断的初始条件为有效帧 `>= 8`、覆盖率 `>= 0.60`、剩余跳变密度 `<= 0.20`，再按具体规则检查其需要的端点或转折区数据。
   - 绘图与现象诊断分别判定：有效连续段达到 2 帧即可绘制；诊断条件不足时只显示曲线。

### Step 4：有声核心定位、半音域修补、Savitzky-Golay 平滑与重采样

1. **音节内浊音核心区修剪（`trim_to_voiced`）**：
   - 在各音节粗边界 $[t_0, t_1]$ 内，起点锚定首个连续 `>= 3` 帧有效的游程起点；终点锚定末个连续 `>= 2` 帧有效的游程终点。
   - 对短音节，若仅有一个 2 帧有效游程，则用该游程作为显示区间。
   - 使用恢复与纠偏后的帧定位核心区；分析区间只裁剪一次，并保存原始秒数。归一化时间由该区间统一计算。
   - 调值端点使用第四节的局部窗口代表值。
2. **短毛刺缺口修补**：
   - 仅对由 Step 3 删除、长度 `<= 2` 帧（20ms）的内部异常片段进行修补。
   - 两侧锚点候选强度均 `>= 0.50` 且半音差 `< 2.0 ST` 时，在半音域做线性插值，记录 `source = "interpolated"`，置信度取两侧较小值的 0.5 倍。
   - 其他缺口原样保留。
3. **分段 Savitzky-Golay 滤波**：
   - 在原生 10ms 时间网格上，对每段连续有效游程独立处理。
   - 长度 `>= 5` 帧时，在半音域使用 `scipy.signal.savgol_filter(window_length=5, polyorder=2)`；不足 5 帧保持原值。
   - 平滑后的半音转回 Hz，保留原始轨供检查。
4. **绘图序列与等距比较序列分别输出**：
   - **绘图序列**：保留原生时间网格、有效值和全部 `null`，用于结果曲线和音高试听。
   - **比较序列**：将分析区间时间归一化到 $t_{\text{norm}} \in [0,1]$，重采样为 `N = 21` 个等距点（步长 0.05），用于调型比较。
   - 复用 `tone_py/resample.py` 的 near/far 规则：near 无效则输出 `null`；near 有效、far 无效则取 near；两侧有效则在半音域线性插值。
   - 重采样点的 `confidence` 取实际参与插值帧的较小值，`intensityDb` 按时间插值；新增数值插值点的 `source` 记为 `interpolated`，恰好落在原生帧上时沿用该帧来源。
   - 调值和现象诊断结合绘图序列及原始有效段掩码计算，保留短缺口的位置。

## 四、 说话人个人音域与五度标音实现

### 1. 个人音域模型 $[f_{\text{lo}}, f_{\text{hi}}]$

定义个人五度音域下界 $f_{\text{lo}}$（对应 1 度线）和上界 $f_{\text{hi}}$（对应 5 度线）：

- 从已有前置标定记录读取 `fLo/fHi`，录音开始时传给实时画布；提交分析时保存同一份音域快照。
- 同一次录音的实时图、结果曲线、调值和音高映射共用该快照。
- 标准发音人使用自己的固定参考音域，随标准曲线保存。
- 前置标定使用与结果曲线相同的 `extract_track → process_syllables` 管线：filtered AC 提取、弱周期恢复、跳变纠偏和连续有效段内平滑。音节边界优先使用评测返回的时间戳，缺省按累计有声时长等分。
- 音域统计只使用原生帧中 `source = measured/corrected` 且 `confidence >= 0.50` 的有效 Hz，排除插值帧；音节共享端点按原始时间去重。至少需要 20 帧，以 P3 × 0.94 和 P97 × 1.06 得到下、上界，分别限制为不低于 55 Hz、不高于 520 Hz，保存为固定的 `fLo/fHi`。
- 用户标定、后台新参考发音人登记和种子发音人音域计算共用上述频率清洗与统计。个人音域只在主动标定成功时更新；新增或删除练习录音不改变音域，历史结果继续使用受理时保存的快照。

### 2. 连续五度值与赵元任离散五度数字（Chao Tone Numerals）计算

1. **三种纵轴坐标**：
   - **连续五度值 `degree`**：
     $$D(t) = 1.0 + 4.0 \times \frac{\ln f_0(t) - \ln f_{\text{lo}}}{\ln f_{\text{hi}} - \ln f_{\text{lo}}}$$
     `fLo → 1`、音域对数中点 `→ 3`、`fHi → 5`。内部保留超出 1–5 的连续值，图表扩展边距显示越界走势。
   - **个人中心归一化半音（Speaker-normalised Semitone, `f0_st`）**：
     $$ST_{\text{rel}}(t) = 12 \log_2\left(\frac{f_0(t)}{\sqrt{f_{\text{lo}} \cdot f_{\text{hi}}}}\right)$$
   - **绝对频率（Hz）**：平滑后的 $f_0(t)$。
   - 五度视图用于比较相对音域位置，半音视图用于比较实际音程，Hz 视图展示真实频率。后两种由 Hz 和各自音域按需派生。

2. **离散五度标调数字提取**：
   - 新增单轮廓函数，输入单音节处理后曲线、有效段掩码和固定 `fLo/fHi`，输出近似调值、调型与所取特征点。
   - 复用 `tone_py.chao` 的取点思路与 `classify_contour()`；单轮廓接口直接接受数组。
   - **端点与拐点判定**：
     - 起点取归一化时间 `[0, 0.10]` 内有效五度值的中位数；终点取 `[0.90, 1]` 内有效值的中位数。
     - 在内部区间 $t \in [0.15, 0.85]$ 搜索极大值 $D_{\max}$ 与极小值 $D_{\min}$。
     - 若 $\min(D_{\text{start}}, D_{\text{end}}) - D_{\min} \ge 0.5$，提取三位调值 `[D_start, D_min, D_end]`。
     - 若 $D_{\max} - \max(D_{\text{start}}, D_{\text{end}}) \ge 0.5$，提取三位调值 `[D_start, D_max, D_end]`。
     - 两类转折都满足时，选择相对两端突出程度较大的一个；其余情况提取两位调值。
     - 特征点使用 measured/corrected 的有效帧；端点窗口为空时返回 `chao = null`。内部 `[0.15, 0.85]` 有保留缺口时输出两位端点调值；内部完整时按上述规则提取转折点。
   - **取整规则**：`digit = clamp(floor(D + 0.5), 1, 5)`，统一使用半入取整。
   - 调用 `classify_contour(chao_str)` 得到调型分类，调值以“近似调值”展示。

### 3. 现象诊断与现有坐标迁移

- 现象规则以连续五度值计算起止高低、升降幅度和拐点位置，调值数字作为辅助展示。
- 根据每条规则所需的端点或转折区检查有效数据；缺失的特征跳过该条规则，其余规则继续计算。
- interpolated 帧用于显示与试听，诊断统计使用 measured/corrected 帧；置信度用于特征统计加权。
- 示范目标沿用具体语境下的标准录音和现有调号规则，覆盖孤立字与连读中的第三声、变调和轻声。
- 现有 T 值 0–5 坐标迁移到 degree 1–5：同步更新曲线字段、图表、实时引导带、现象阈值、示范曲线生成和测试样例。
- 对纯坐标阈值可使用 `D = 1 + 0.8 * T` 迁移；示范音频按新管线重新生成曲线。
- 使用新的 `algorithm_version` 和曲线 schema 版本，缓存键覆盖算法配置及音域快照。历史 0–5 数据通过显式版本转换读取。

## 五、 标准示范录音的同算法叠加与哼鸣合成（Sonification）

### 1. 标准示范曲线同管线生成与对齐叠加

- 对标准示范音频（默认发音人录音）运行与用户录音**一致**的 `extract_f0`、异常清洗、`trim_to_voiced`、Savitzky-Golay 平滑与 21 点比较序列生成流程。
- 标准发音人的五度归一化使用其自身的固定参考音域 $[f_{\text{lo}}^{\text{ref}}, f_{\text{hi}}^{\text{ref}}]$。
- 标准曲线保存发音人、音域快照、音节边界、分析区间、实际时长和算法版本。
- **叠加对齐方式**：
  - 在归一化音节时间轴（每个音节内部 $t \in [0,1]$）上，将**用户曲线**与**标准发音人实测曲线**同屏叠加渲染。
  - 每个音节额外显示双方实际时长及用户/示范时长比。
  - Hz 视图绘制各自真实频率，五度视图比较相对音域位置，相对半音视图比较实际起伏幅度。

### 2. 音高旋律声化试听（Sonification A/B 对比，接入 `tone_py/sonify.py`）

接入内置的 `tone_py.sonify.sonify_f0()`，为用户提供剥离咬字干扰的音高听觉对比：

- 输入：原生网格上的处理后 `f0_hz`、实际时间和对应的 `intensity_db` 包络。
- 参数：`fs = 16000`，`source = "vowel"`，使用内置三共振峰级联合成器合成统一的中性元音 `/a/` 哼鸣声，传入 `intensity` 表现起音与收尾包络。
- 将连续有效段分别合成，并按原始时间放入输出音频；缺口填静音，段边缘加短淡入淡出。输出时长由实际录音时间决定，内部缺口保持原时长。
- 通过音频端点返回 WAV，缓存使用音频 ID、算法配置、音域快照和合成参数。
- 产出：
  1. **标准示范音高哼鸣**；
  2. **用户实测音高哼鸣**；
  3. **按我的音域听标准**：保留标准的时间、缺口和合成音色，将标准五度曲线映射到用户标定音域：
     $$f_{\text{target}}(t) = \exp\left(\ln f_{\text{lo}}^{\text{user}} + \frac{D_{\text{ref}}(t)-1}{4}\left(\ln f_{\text{hi}}^{\text{user}}-\ln f_{\text{lo}}^{\text{user}}\right)\right)$$
- 播放使用实际秒数推进游标，通过对应音节分析区间映射到图表相对时间坐标。

## 六、 前端实时提取与图表视觉渲染实现

### 1. 前端实时提取升级（`src/utils/realtimeAcoustics.ts` & `src/components/RealtimeAcousticCanvas.vue`）

1. **固定步长环形缓冲（解耦渲染帧率与分析帧率）**：
   - 使用 `AudioWorkletNode` 采集 PCM，按采样计数写入环形缓冲，以 **10ms 步长**产生分析窗口；MPM 计算放在 Worker，画布按 rAF 渲染最新结果。
   - 帧时间戳由采样计数生成，记录窗口中心相对录音起点的秒数。窗口按采样率和最低频率计算，至少覆盖最低频率的 3 个周期，初始化时选择满足条件的窗口长度。
   - 降低最低频率时同步增加窗口长度。
2. **实时双门限与跳变观察缓冲**：
   - 主门限初始为 `clarity >= 0.82` 且 `rms >= 0.012`。
   - 前 3 帧稳定有声时，对 `rms >= 0.008`、`clarity >= 0.55` 且与邻近轨迹连续的弱周期帧延续显示，采用较弱样式。
   - 当前帧与上一帧的半音变化率超过 `2.0 ST/10ms` 时，暂挂入 3 帧观察缓冲。
   - 短暂偏离后回到原轨迹的点作为毛刺留空；连续 3 帧进入新平台时接纳新轨迹，待判定部分留白。
   - 半音域中值滤波和 EMA 仅在连续有效段内使用；进入缺口即清空状态。
   - 前后端置信度保留各自算法的原生含义，实时轨用于预览；录音完成后显示后端结果。
3. **实时纵轴绑定个人音域 `[fLo, fHi]`**：
   - 将本次固定的个人标定音域传入画布，替换 `AdaptivePitchWindow` 的动态均值缩放行为。
   - 1 度线锚定 $\text{hzToSemitone}(f_{\text{lo}})$，5 度线锚定 $\text{hzToSemitone}(f_{\text{hi}})$，画布范围为 $[ST(f_{\text{lo}})-2\text{ ST}, ST(f_{\text{hi}})+2\text{ ST}]$。
   - 目标引导带和实测点共用第四节五度映射。目标曲线按具体音节及语境选择。

### 2. 结果页图表展示升级（`src/renderers/ToneCurveChart.vue`）

*界面约束：不在音节上方显示对比卡片，不在断口处画浅红色气息中断背景条。*

1. **标准录音曲线与用户曲线同屏叠加**：
   - **标准示范曲线**：采用经过相同算法提取的真实曲线，以虚线绘制。
   - **用户实测曲线**：叠加在同一坐标系上。
   - 两条曲线使用原生网格的处理后数据，设置 `smooth: false`、`connectNulls: false`。
2. **按置信度展示分段样式**：
   - 可靠片段采用实线，弱周期或较低置信度片段采用同色系点线；共享图例“我的曲线”。
   - 通过相邻线段两端置信度的较小值决定线段样式，初始以 `0.50` 为实线/点线分界，分段边界共享端点。
   - 静音、清音及缺测帧使用带时间位置的 `null`，自然留白断开。
3. **三种坐标轴视图一键切换**：
   - 提供 `[五度值 (1–5)]`、`[相对半音 (ST)]`、`[频率 (Hz)]`。
   - **五度值视图（默认）**：显示 `1 (低)`、`2 (半低)`、`3 (中)`、`4 (半高)`、`5 (高)` 五条水平参考线；坐标范围覆盖有效数据，并至少留出 `0.5–5.5` 的显示空间。
   - **相对半音视图**：各自个人音域对数中心为 `0 ST`，按双方曲线共同确定显示范围。
   - **绝对频率视图**：Y 轴采用对数坐标，同时展示用户与标准发音人的真实 Hz。
   - 横轴标为“音节内相对时间”，音节依次拼接；实际时长在图表下方以简短文本显示。
4. **哼鸣旋律 A/B 试听控件**：
   - 提供“听标准音高”“听我的音高”“按我的音域听标准”按钮，播放第五节生成的音频，并同步推进时间游标。

## 七、 数据接口与模块接线

### 1. 帧与音节数据

后端绘图帧统一使用以下字段，JSON 空值输出为 `null`：

| 字段 | 类型 | 含义 |
|---|---|---|
| `t` | number | 原始录音中的秒数 |
| `hz` | number 或 null | 处理后频率 |
| `degree` | number 或 null | 连续五度值 |
| `confidence` | number | 0–1；测量或候选修正帧取选中候选强度，插值帧按第三节计算，空帧为 0 |
| `source` | measured / corrected / interpolated / null | 当前数值来源；原生有效帧经平滑后仍记 measured，空帧为 null |
| `intensityDb` | number 或 null | 对齐到当前帧的能量 |

每个音节返回：

- `syllable`、语境下的目标调号及现有音节标识。
- `user` 与 `reference`：各自包含绘图帧 `frames`、`rangeSnapshot`，以及下列时间、比较和质量字段。
- `t0/t1`：原始音节边界；`analysisStart/analysisEnd`：有声核心区间。
- `duration`：原始音节时长；`analysisDuration`：分析区间时长；均使用秒。
- `comparisonPoints`：21 点比较序列，包含归一化时间 `u` 和帧字段。
- `chao`、`shape`、`featurePoints`：近似调值、调型及其特征点。
- `quality`：有效帧数、覆盖率、剩余跳变密度、`canDiagnose`。

前端绘图位置由各自 `u = (t - analysisStart) / analysisDuration` 生成。秒数与归一化时间使用独立字段。全无有效帧的音节返回空绘图帧及空分析区间，保留原始音节边界。

原始 F0、候选集合和修正记录保存在后端分析产物中；API 返回图表、诊断和试听需要的数据。

### 2. 现有模块接线

- `backend/app/acoustics/analysis.py`：提取原始轨、候选、强度和处理轨。
- `backend/app/scoring/rules.py`：在 `_t_curve_in_segment()` 中保留完整帧网格和 null，使用一次核心区裁剪；接入统一五度映射和按音节质量判定。
- `curve_phenomena()`：适配空值、连续有效段、置信度及新的 1–5 阈值。
- 标准曲线生成任务：复用相同管线，保存标准发音人音域与版本。
- `src/api` 及后端 schema：同步帧、音节与版本字段。
- 实时画布、结果图和音高试听按同一份音域快照接线。
- 算法版本覆盖提取、纠偏、平滑与映射参数；缓存额外关联音域快照、音频内容和输出类型。

## 八、 Parselmouth filtered AC 调用示例

```python
import parselmouth
from parselmouth.praat import call

print("Parselmouth:", parselmouth.VERSION)
print("Praat:", parselmouth.PRAAT_VERSION)
print("Praat date:", parselmouth.PRAAT_VERSION_DATE)

sound = parselmouth.Sound("example.wav")

pitch = call(
    sound,
    "To Pitch (filtered ac)",
    0.010,  # time step，固定 10 ms
    50.0,   # pitch floor，Hz
    800.0,  # pitch top，Hz
    15,     # maximum number of candidates
    False,  # very accurate
    0.03,   # attenuation at top
    0.09,   # silence threshold
    0.50,   # voicing threshold
    0.055,  # octave cost
    0.35,   # octave-jump cost
    0.14,   # voiced/unvoiced cost
)

times = pitch.xs()
f0 = pitch.selected_array["frequency"]  # Hz；无声帧为 0
```

完整命令名 `"To Pitch (filtered autocorrelation)"` 也已在源码中注册。

**开发版的 `sound.to_pitch_ac()` 仍调用 raw autocorrelation。** Python 接口源码 中还留有适配 filtered/raw 的 TODO，所以应明确使用上面的 `praat.call()`。

## 九、 实施顺序与验收

### 1. 分阶段交付

| 阶段 | 主要交付物 |
|---|---|
| 第一阶段：坐标与数据链路 | 接入固定标定音域；统一 1–5 五度映射；帧网格与 null 全链路保留；修正横轴；同步 schema、示范数据和版本 |
| 第二阶段：后端基础管线 | filtered AC、完整候选与强度提取；有声核心定位；分段 SG；绘图序列与 21 点序列；按音节报告质量 |
| 第三阶段：纠偏与教学反馈 | 区间候选路径纠偏；弱周期片段恢复和样式；单音节调值；现象诊断规则适配 |
| 第四阶段：试听与实时优化 | 保留时长与缺口的音高试听、播放游标、Hz/半音视图；AudioWorklet 采集、Worker 分析和实时跳变缓冲 |

每阶段保持可运行状态，独立比较输出后继续下一阶段。候选纠偏、弱周期恢复和短毛刺插值分别配置开关，以便在同一批录音上比较。

### 2. 回归录音与检查项

选取 20–30 条真实录音，覆盖低/高音域、第三声低谷与嘎裂、第四声尾部、短音节、长清辅音、静音缺口、明显音高跳跃及背景噪声。对规则周期区间标注参考频率，对弱周期区间标注可分析范围和有效片段。

- **坐标一致**：固定音域下，相同 Hz 在实时图和结果图对应相同五度；练习期间音域快照固定。
- **缺口一致**：后端帧、图表和试听保留相同缺口及其时长；21 点比较序列之外仍保留原生缺口位置。
- **曲线准确**：比较八度错误率、清浊错误率、有效覆盖率、谷底深度与出现位置；同时查看原始轨和处理轨。
- **教学反馈有效**：明确升降、平调与降升样例得到对应近似调值；孤立字和连读使用相应示范目标。
- **局部结果可用**：个别异常片段保留断口，其他音节继续展示并生成适用的反馈。
- **试听同步**：音频时长、段落缺口、图表游标与当前播放对象一致。
- **版本接线完整**：用户曲线与示范曲线采用同一版本；新缓存命中正确音域快照；历史数据按版本读取。
- **实时性能**：在 44.1kHz、48kHz 和不同显示刷新率下，分析时间轴保持 10ms 步长，画布交互流畅。

为 null 传递、五度映射、候选纠偏、实际时长合成和关键规则增加针对性测试，运行相关后端测试与前端类型检查。各算法开关分别评测，使用结果确定集中配置中的最终参数。
