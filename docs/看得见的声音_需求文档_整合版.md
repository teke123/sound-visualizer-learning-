## 一、产品定位

### 1.1 一句话定位

"看得见的声音"是一款面向成人与大众的智能发音学习平台：针对传统语言学习中发音"看不见、摸不着"的痛点，把抽象的发音过程（口腔构形、音高变化、频谱特征等）转化为直观的 2D/3D 图像、动画和声学曲线，并以"学习—检测（实时声学反馈 + 多维声学对比）—反馈"闭环为用户提供个性化的发音诊断与针对性练习建议。

### 1.2 解决的核心痛点

1. **只给分数不给方案**：现有产品多数只做跟读打分，用户不知道"为什么错"和"怎么改"。本平台为每次检测结果给出声学可视化对比与可执行的四步改进方案。
2. **发音过程不可见**：传统学习依赖听觉模仿，看不到舌位、唇形、气流、送气差异和音高走向。本平台在录音时提供前端实时声学反馈（实时波形、音量与实时音高轨迹），并在提交后用 2D/3D 构形动画、基频曲线、元音空间共振峰图、送气段波形与语谱图等可视化手段让发音"看得见"。
3. **软件工具操作门槛高**：专业语音学分析工具（如 Praat）操作繁琐，学习者难以直接用于日常训练。本平台自动提取并渲染关键声学图像，配合清晰直观的语音学与发音器官说明，让成年学习者即开即用。
4. **内容固定不可扩展**：现有产品内容固化。本平台的学习内容经团队简单后台即可随时增改，新内容保存后自动融入全站，无需修改前端代码。

## 二、用户与使用场景

### 2.1 用户群体

| 群体 | 说明 | 定位 |
| --- | --- | --- |
| 普通话学习者（主攻） | 存在具体发音问题的成人学习者，典型如：方言区用户（易混声母、前后鼻音、平翘舌、声调调值等问题）、有普通话水平测试 / 课堂 / 职场表达需求的学习者 | **1.0 首要服务对象** |
| 外语学习者（中文学习者） | 以汉语声调和易混音为主要困难点的非母语成人学习者 | 1.0 共用同一套学习内容；专属路径与界面支持列入后续版本 |
| 语言康复需求者 | 可视化发音反馈对康复训练具有辅助价值，属于平台的应用前景与社会价值方向 | 应用前景人群 |
| 团队内容维护者 | 负责发音单元录入、媒体上传和反馈查看的团队成员 | 1.0 后台使用者 |

### 2.2 典型使用场景

- 一名方言区大学生发现自己平翘舌或送气音不分、第二声升不上去，希望找到自己的问题、从声学图和构形上看懂差距、练到改过来；
- 一名留学生分不清四个声调和元音舌位，希望看到自己的基频曲线、元音空间和标准参考差在哪里；
- 学习者走"找到问题 → 看懂构形与声学规律 → 关卡内跟读录音（实时看波形与音高） → 视觉对比与反馈 → 看到档案进步"的完整路径。

## 三、1.0 版本范围

### 3.1 交付概览

1. **核心发音关卡（L01–L30）**的学习与检测内容，涵盖单韵母、声母与「妈」字四声拼读；
2. **一条完整检测闭环**："看示范与构形 → 听辨与分步练 → 关卡内直接录音（含前端实时声学反馈） → 声学可视化对比（基频、共振峰、送气段波形/语谱图）+ 分数 + 四步反馈 + 录音质量提示 → 自动保存声音档案 → 再练"全流程；
3. 五大核心业务模块：**发音地图、关卡页（学习与录音一体，P05）、检测结果（声学分析与反馈，P09）、声音档案（P10）、团队自用后台**。

## 四、核心使用路径

### 4.1 主线：学习—检测—反馈闭环

1. 用户注册并登录进入平台首页（P01，可按需选填方言区/母语背景），看到发音地图 / 关卡入口与搜索框。
2. 进入一个关卡页（P05，例如"妈"字四声或声母关）：先看**一句话结论**、**发音构形**（2D 剖面、3D 模型与动图）及**声学与发音说明**，听**标准示范音频**（正常语速，鼓励提供慢速，男女声各一）。
3. 做**听辨练习**与**分步练习**：听一个音判断是哪一个（如"nán 还是 lán"），并完成 3–5 步练习。
4. 在**本关录音区（P05）**直接跟读录音：用户可选择完成**个人音域标定**（以获得更精确的个人音域与元音空间归一化对比），也可点击**跳过标定**直接录音；发声过程中前端实时展示**动态波形、音量包络与实时音高（F0）轨迹**，录完后提交。
5. 查看**检测结果（P09）**：展示**多维声学可视化对比**（基频 F0 曲线、元音空间共振峰 F1/F2、送气段波形/VOT 与语谱图）、评分结果、现象描述、**四步反馈**（现象—环节—提示—练习）以及**录音环境质量提示**（如音量偏小、底噪偏大提示，不阻断评分）。
6. 本次录音与结果自动存入**声音档案（P10）**；用户可按反馈中的"安全短练习"回到关卡再练或重录。
7. 多次练习后，在声音档案中并排回放同一关的多次录音，对比声学曲线与进步变化。

### 4.2 进步回看路径

用户进入声音档案（P10） → 按关卡查看历史记录 → 选择同一关的两次记录并排回放、对比声学曲线与分数 → 查看变化趋势 → 继续针对性训练。

### 4.3 内容维护路径（团队自用后台）

团队维护人员打开后台 → 按统一关卡字段录入或编辑关卡（文字、声道参数、构形媒体、示范音频、听辨题、反馈模板）或原理文章 → 保存并设为开放 → 前端立即从搜索、发音地图、发音库同步展示最新内容。

## 五、功能模块需求

### 5.1 发音地图（P03）与发音库（P06）

**模块目标**：让用户清晰了解单韵母、声母、拼读的层次结构与个人学习进度，并快速进入关卡或对比易混音。

| 编号 | 需求 |
| --- | --- |
| 地图-1 | 以闯关定位图展示单韵母、声母、拼读三层关卡结构及个人学习进度。 |
| 地图-2 | 图中每个已开放关卡可点击进入对应关卡页（P05）；尚未开放的关卡呈现"未开放"状态。 |
| 地图-3 | 提供易混音对的并排比较入口（如 n 与 l、b 与 p、z 与 zh 等），支持并排对比示范、构形与声学说明。 |
| 地图-4 | 发音库（P06）按层提供关卡卡片索引、示范试听与任意两关并排比较工具。 |

### 5.2 关卡页：学习与录音检测一体（P05）

**模块目标**：平台学习与跟读录音的统一载体。每个关卡呈现"这个音是什么、怎么发、声学特征是什么、和易混音差在哪"，并直接在页内完成录音与实时声学监控。

| 编号 | 需求 |
| --- | --- |
| 单元-1 | 所有关卡使用统一的页面结构（结论 → 构形与声学说明 → 示范 → 听辨与练习 → 本关录音区）。 |
| 单元-2 | 展示**一句话结论**：概括本关核心发音动作与要点。 |
| 单元-3 | 提供**发音构形多视图**展示：内容媒体（图/动图/视频）、2D 声道剖面图、3D 口腔模型视图并存切换，直观展示舌位高低前后、唇形圆展与成阻除阻运动。 |
| 单元-4 | 提供**标准示范音频**：至少正常语速一条，鼓励增加慢速版本，建议男女声各一；音频可完整播放，并配有对应文字。 |
| 单元-5 | 提供**分步练习**（3–5 步）与**听辨练习**（作答立即判对错并给出解释），记录完成情况以计算学习进度。 |
| 单元-6 | 提供**误区说明**与**声学/语音学说明**：清晰展示发音部位、发音方法、声学参考值（F0、F1/F2、VOT、时长等）及易混音差异原因。 |
| 单元-7 | 内嵌**本关录音检测区**：录音前展示朗读提示词、环境建议与示范播放；支持开始、停止、试听、重录与提交检测。 |
| 单元-8 | 提供**前端实时声学视觉反馈**：录音进行时通过 Web Audio API 实时绘制动态波形、音量包络与实时音高（F0）轨迹，帮助用户在发声当下即时调整。 |
| 单元-9 | 提供音域标定入口并**支持跳过标定**直接录音检测。 |
| 单元-10 | 展示相关关卡导航：上一关、易混关、下一关。 |

### 5.3 检测分析与结果反馈（P09）

**模块目标**：将用户语音转化为直观的声学图像并与标准对比，配合分数与四步反馈给出可执行的改进方案。

| 编号 | 需求 |
| --- | --- |
| 检测-1 | **多维声学可视化对比**：根据关卡特性展示（1）**基频（F0）曲线对比**（韵母/声调/拼读）；（2）**元音空间与共振峰（F1/F2）图像**（反映舌位高低与前后）；（3）**送气段波形（VOT）与语谱图（Spectrogram）**（反映塞音/塞擦音送气长短及擦音噪声频带分布）。不强制要求清辅音示范提取基频。 |
| 检测-2 | **个人音域换算（支持跳过）**：已完成标定的用户按个人音域与元音空间归一化对比；跳过标定的用户同样正常评分并展示声学图像，同时提供去标定的便捷入口。 |
| 检测-3 | **评分与现象描述**：展示本次录音评分（同规则可重复）及基于音节/声韵调检错与声学分析的直观现象描述。 |
| 检测-4 | **四步反馈**：现象 → 可能相关环节 → 可感知提示 → 安全短练习（可跳回 P05 练习步骤）。 |
| 检测-5 | **录音质量辅助提示**：检测音量、噪声、截幅与时长，作为改善录音环境的温和提示展示，不拦截或停止正常评分与声学可视化。 |
| 检测-6 | 结果页提供立即行动入口：重听示范、回放本次录音、返回关卡（P05）再练或重录。 |

### 5.4 声音档案（P10）与账号管理（P11）

**模块目标**：极简顺畅的账号流程，自动记录每次练习，支持前后对比与个人数据管理。

| 编号 | 需求 |
| --- | --- |
| 档案-1 | 用户注册并登录即默认同意服务条款，支持选填「方言区 / 母语背景」；学习进度与每次录音检测结果自动保存至个人账号。 |
| 档案-2 | 声音档案（P10）按关卡展示历史录音记录，支持同一关至少两次记录**并排回放与声学曲线对比**。 |
| 档案-3 | 支持用户随时删除单条录音记录、清空全部个人声音档案。 |
| 档案-4 | 账号页（P11）支持注册、登录、退出、设置/修改「方言区 / 母语背景」、音域标定、清空档案及验证密码后注销账号；远期支持通过绑定邮箱找回密码。 |

### 5.5 团队自用内容维护后台（CMS）

**模块目标**：提供简洁高效的内部维护工具，方便团队成员直接录入与更新关卡、文章和媒体。

| 编号 | 需求 |
| --- | --- |
| 后台-1 | 按统一关卡字段录入或编辑关卡内容、声道剖面参数、听辨题、练习步骤与四步反馈模板，保存后直接生效。 |
| 后台-2 | 支持上传图片、动画、3D 资源、示范音频与字幕文件并关联到关卡或文章。 |
| 后台-3 | 支持配置每关的朗读提示词、评测文本、参考示范及声学可视化指标，支持切换关卡开放状态。 |
| 后台-4 | 支持使用 Markdown 创建与编辑发音原理文章（P04）及其分类。 |
| 后台-5 | 支持查看用户提交的纠错反馈与"希望增加"记录，并标记处理状态。 |

## 六、内容字段框架

| 字段组 | 录入内容 |
| --- | --- |
| 身份 | 关卡编号（L01–L30）、类型（单韵母 / 声母 / 拼读）、目标音、代表汉字、标签、是否开放 |
| 大众结论 | 一句话结论、适用易混问题、学习目标 |
| 发音构形 | 口型 / 舌位 / 唇形描述、主图或动画、声道剖面关键帧参数、3D 模型资源 |
| 声学与专业说明 | 发音部位与方法、时长/基频 F0/共振峰 F1-F2/VOT 等声学参考值及说明、资料来源 |
| 示范媒体 | 正常与慢速示范音频、字幕或对应文字 |
| 练习 | 分步练习（3–5 步）、听辨题、跟读词、小测题（2.0） |
| 误区 | 可观察现象、改进方法说明 |
| 检测配置 | 朗读提示词、评测文本、参考示范、输出的声学指标（F0 / F1-F2 / 送气段波形 / 语谱图）、四步反馈模板 |

## 七、通用需求（跨功能约束）

1. **跨端兼容**：电脑浏览器与手机浏览器均可顺畅完成"登录 → 关卡学习与构形查看 → 关卡内录音（含实时声学反馈） → 查看声学可视化对比与四步反馈 → 声音档案前后比较"主路径。
2. **性能体验**：页面切换与示范播放响应及时；录音过程中前端实时声学画面流畅；录音提交后 30 秒内完成分析并展示结果，超出即时窗口时展示清晰的处理阶段并支持重试。
3. **清晰反馈**：核心页面状态明确；录音环境不佳时提供温和提示；清空档案与注销账号提供二次确认防误触。
