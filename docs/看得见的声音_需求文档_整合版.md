## 一、产品定位

### 1.1 一句话定位

"看得见的声音"是一款面向大众的智能发音学习平台：针对传统语言学习中发音"看不见、摸不着"的痛点，把抽象的发音过程（口腔构形、音高变化等）转化为直观的图像、动画和声学曲线，并以"学习—检测—反馈"闭环为用户提供个性化的发音诊断与针对性练习建议。

### 1.2 解决的核心痛点

1. **只给分数不给方案**：现有产品多数只做跟读打分，用户不知道"为什么错"和"怎么改"。本平台为每次检测结果给出可执行的改进方案。
2. **发音过程不可见**：传统学习依赖听觉模仿，看不到舌位、唇形、气流和音高走向。本平台用构形动画、曲线对比、发音地图等可视化手段让发音"看得见"。
3. **专业门槛过高**：语音学工具操作复杂，普通用户难以使用。本平台面向无语音学背景的普通人，界面与反馈使用大白话。
4. **内容固定不可扩展**：现有产品内容固化。本平台的学习内容经后台持续增改，新内容发布后自动融入全站，无需开发介入。

### 2.2 典型使用场景

- 一名方言区大学生发现自己前后鼻音不分、第二声升不上去，希望找到自己的问题、看懂差距、练到改过来；
- 一名留学生分不清四个声调，希望看到自己的音高曲线和标准曲线长什么样；
- 两人都希望跳过从头学拼音的过程，直接走"找到我的问题 → 看见差距 → 针对性练 → 看到进步"的路径。

## 三、1.0 版本范围

### 3.1 交付概览

1. **约 12 个核心发音单元**的学习内容，覆盖元音、辅音、声调三类关键发音要素，按"发音要素 / 常见问题"组织；
2. **一条完整检测闭环**："看示范 → 听辨 → 跟读录音 → 录音质量检查 → 音高曲线对比 → 四步反馈 → 保存记录 → 再练"全流程；
3. 六大功能模块：**发音地图、示范单元（学习）、检测中心（录音与质量检查）、检测结果（分析与反馈）、声音档案、内容管理后台**；

### 3.2 首版内容规模

1. 内容总量约 12 个发音单元：元音类覆盖单韵母，辅音类围绕常见易混声母组织，声调类以四声总览（"妈"字样板单元）与易混声调的区分为核心。具体单元清单由内容组按统一字段审定，保持三类要素覆盖与总量约 12 个，"妈"字四声样板单元为固定项。
2. 单元按"发音要素 / 常见问题"组织，用户可从任一单元进入，按需学习。

## 四、核心使用路径

以下路径是全产品要拼成的"主线"。每条路径可单独演示，也可连成一条线演示。

### 4.1 主线：学习—检测—反馈闭环

1. 用户打开平台首页，看到发音地图 / 单元入口与搜索框；（可选）选择自己的背景（母语 / 方言区），获得针对该背景的常见问题推荐【1.0·后期】。
2. 进入一个示范单元（例如"妈"字四声）：先看**一句话结论**，再看**发音构形**（口型、舌位示意动画），听**标准示范音频**（正常语速，鼓励提供慢速，男女声各一）。
3. 做**听辨练习**：听一个音、判断是哪一个（如"nán 还是 lán"），先确保"听得出区别"。
4. 做**跟读练习**：按提示录音，系统先做**录音质量检查**，通过后展示**自己的曲线与标准曲线的叠加对比**（声调类按个人音域换算到统一标度后对比）；质量存在问题时，系统明确告知原因并引导重录。
5. 查看**检测结果**：质量结论、可视化对比、明确的分析结论（如"第二声起点偏高、上升幅度不足"）、可靠性说明、四步反馈（现象—环节—提示—练习）。
6. 按反馈中的"安全短练习"回到单元再练，或重录对比；同意保存后，该次结果进入**声音档案**。
7. 多次练习后，在声音档案中查看同一问题的**前后变化与进步趋势**。

### 4.2 访客轻体验路径

用户可直接开始体验：完整学习任何已发布单元（看构形、听示范、做听辨与跟读练习）；对已开放检测的单元提交录音并查看**当次**结果；需要保存记录时再注册并授权保存。

### 4.3 进步回看路径

登录用户进入声音档案 → 按单元 / 问题查看历史记录 → 选择同一单元的两次记录并排回放、对比曲线 → 查看关键指标的变化趋势 → 决定继续练哪个单元。

### 4.4 快速诊断路径【1.0·后期】

选择背景 → 朗读一份覆盖主要常见问题的读词表（约 3–5 分钟） → 得到"我的问题清单"（每项附可靠程度说明） → 点选一个问题，直接进入对应专项单元开始 4.1 的闭环。在诊断能力齐备前，先以"用户自选背景 + 自选问题"方式过渡。

### 4.5 内容管理路径（后台）

内容管理者登录后台 → 按统一单元字段录入新单元（文字、构形图 / 动画、示范音频、听辨题、跟读词、反馈模板）→ 预览 → 提交审核 → 审核通过后发布 → 用户端立即可从搜索、发音地图、相关单元入口发现该内容；支持随时下架，下架后用户端即时更新。

## 五、功能模块需求

> 编号规则：每条需求按模块前缀编号（如"地图-1"）。未特别标注的均为【1.0】。

### 5.1 发音地图

**模块目标**：让用户一眼看懂声母、韵母、声调、音节、汉字之间的层级与关系，并快速进入想学的单元。

| 编号 | 需求 |
| --- | --- |
| 地图-1 | 以可视化关系图展示声母、韵母、声调、音节、汉字之间的层级关系，支持分类筛选（按声母 / 韵母 / 声调）。 |
| 地图-2 | 图中每个已发布单元可点击进入对应示范单元页；尚未发布的单元呈现"未开放"状态并配有说明。 |
| 地图-3 | 提供易混音对的并排入口（如 n 与 l 的并排比较），对比双方均已发布时呈现。 |
| 地图-4 | 专业性内容（国际音标、发音部位学术分类）默认收起，用户展开后查看。 |
| 地图-5 | 新单元发布后自动出现在地图中，地图结构保持稳定。 |

### 5.2 示范单元（学习页）

**模块目标**：平台学习内容的标准载体。每个单元用统一的结构呈现"这个音是什么、怎么发、和容易混的音差在哪"。

| 编号 | 需求 |
| --- | --- |
| 单元-1 | 所有单元使用同一套页面结构（结论 → 构形 → 示范 → 练习 → 误区 → 检测入口）；新增单元沿用同一结构。 |
| 单元-2 | 进入单元首先展示**一句话结论**：这个音最重要的一件事（如"这一关把嘴张大，发出 a"）。 |
| 单元-3 | 提供**发音构形**展示：口型、唇形、舌位高低前后等发音状态的图示或动画，让用户"看见"发音器官的动作。构形材料属于单元发布的前提条件。 |
| 单元-4 | 提供**标准示范音频**：至少正常语速一条，鼓励增加慢速版本，建议男女声各一；音频可完整播放，并配有对应文字。 |
| 单元-5 | 提供**分步练习**：3–5 步短练习，每步写清做几遍或停多久、练习中的身体感受，并注明"不舒服就停止"。 |
| 单元-6 | 提供**误区说明**：用可观察的大白话描述"可能听起来像什么、可以怎么改"，语气友善。 |
| 单元-7 | 提供**听辨练习**：听一个音、从选项中选出是哪个（如"nán 还是 lán"），系统记录对错，用于学习进度记录。 |
| 单元-8 | 单元说明解释易混音对"差在哪里、你为什么容易混"（例如方言背景中该区别的使用习惯），并配口型 / 部位示意图。 |
| 单元-9 | 提供**跟读录音入口**：检测入口随该单元检测开放而出现，与检测中心进入同一任务、同一套评价口径；检测开放前，单元提供完整的学习功能。 |
| 单元-10 | 提供**小测**：几道围绕本单元目标的题目，记录结果作为单元完成度参考。 |
| 单元-11 | 展示相关单元入口：上一单元、易混单元、下一已发布单元。 |
| 单元-12 | 专业术语、声学参数说明、资料来源默认折叠，感兴趣的用户展开查看。 |

### 5.3 录音与质量检查（检测中心）

**模块目标**：让用户在任何设备上顺利完成一次"可用于分析"的录音，保障进入分析的录音质量达标。

| 编号 | 需求 |
| --- | --- |
| 录音-1 | 录音前提供准备引导：安静环境提示、麦克风距离建议、录音用途说明（默认仅当次处理，保存需本人同意）。 |
| 录音-2 | 录音前可先听示范、看到要朗读的内容（提示词）。 |
| 录音-3 | 录音过程支持开始、停止、试听、重录、提交；录音中提供实时可视化反馈（如波形）。 |
| 录音-4 | 用户拒绝麦克风权限时，说明如何开启权限并提供下一步操作。 |
| 录音-5 | **质量五维检查**：从音量、噪声、截幅（爆音）、时长、静音比五个维度评估录音质量；五个维度全部通过后，录音才进入分析评分；存在问题时，系统用明确的话告知原因和重录方法。 |
| 录音-6 | 质量结论与评价结果分开显示，帮助用户区分"没录好"和"发音待改进"。 |
| 录音-7 | 提交失败或处理超时时，说明失败环节（没录上 / 太短 / 提交失败）并提供重试，已录内容在用户放弃前保留。 |
| 录音-8 | 任务列表呈现"已发布且检测已开放"的单元；从首页、单元页、检测中心进入同一单元任务时，提示词、示范与评价口径完全一致。 |

### 5.4 检测分析与结果反馈（检测结果）

**模块目标**：把分析结果变成用户看得懂、可执行的反馈，这是产品区别于"打分工具"的核心。

| 编号 | 需求 |
| --- | --- |
| 检测-1 | 结果页首先给出**录音质量结论**（能否评价及原因），质量通过后再展示分析内容。 |
| 检测-2 | **可视化曲线对比**：绘制用户的音高曲线并与标准参考曲线叠加展示，用户直观看到"我的曲线"和"标准曲线"的差距。 |
| 检测-3 | **按个人音域换算**：对比前将用户曲线按其本人音域换算到统一标度（类似五度标调），使男声、女声、音域偏高偏低的人都能和同一条标准线比较。首次使用通过自然朗读标定音域（如朗读"妈麻马骂"本身），之后随历史记录滚动更新。 |
| 检测-4 | **明确的分析结论**：用可理解的语言描述问题，如"第二声起点偏高、上升幅度不足：只升了约 1 度，标准约 2 度"；结论只陈述本次实际测得的现象。 |
| 检测-5 | **四步反馈**：现象 → 可能相关环节（"可能与……有关"的提示性表述）→ 可感知提示（短句、可执行，如"结尾再往上抬一点，像疑问的'啊？'"）→ 安全短练习（可直接跳回单元练习）。反馈文字来自人工审定的模板，同一分析结果每次输出一致，模板支持在后台修改。 |
| 检测-6 | **可靠性分级**：每类检测按验证程度归入三档并向用户如实标注——**可评判**（准确率已验证，给出结论）；**仅供参考**（给可视化和倾向性描述，并提示"建议对照示范再练"）；**只练不测**（提供听辨与跟读练习，检测入口待能力验证后开放）。档位由实测数据决定。 |
| 检测-7 | 评价（若给出）表示本次录音在本单元目标上的表现，可解释、同条件可重复（同一录音重复提交结论口径一致）；呈现方式为个人纵向比较，帮助用户关注自身进步。 |
| 检测-8 | 结果页固定显示边界声明："结果仅供学习参考，不作为普通话等级认定或医学诊断"；语言中性、可执行。 |
| 检测-9 | 结果页提供立即行动入口：重听示范、回单元练习、重录；已同意保存的可存入档案。 |
| 检测-10 | "妈"字四声样板单元的检测开放前提：音高走向、时长、稳定性等指标经测试数据验证可稳定给出。 |

### 5.5 声音档案与进步展示

**模块目标**：让用户的每次练习留下可回看的记录，看见自己的进步；这也是检验产品有效性的数据来源。

| 编号 | 需求 |
| --- | --- |
| 档案-1 | 用户同意保存后，每次检测记录按单元保存：日期、录音、质量结论、分析结果、反馈内容与结果版本。 |
| 档案-2 | 支持同一单元至少两次记录**并排回放与对比**（含曲线对比），并给出主要差异提示。 |
| 档案-3 | 按单元 / 问题展示关键指标随时间的变化趋势（进步曲线）。 |
| 档案-4 | 档案为空时展示"如何开启保存"的引导说明。 |
| 档案-5 | 录音与记录属于用户本人，呈现以个人纵向比较为主；不同单元的成绩分别呈现。 |
| 档案-6 | 支持删除单条记录和清空全部档案。 |

### 5.6 账号与录音数据控制

**模块目标**：低门槛进入 + 用户对自己的录音拥有完全控制权。

| 编号 | 需求 |
| --- | --- |
| 账号-1 | 用户可直接开始学习全部已发布单元；对已开放检测的单元可临时录音并查看当次结果。 |
| 账号-2 | 保存进度 / 录音前注册简单账号并**明确同意**；同意文案写清保存什么、用来做什么、可以随时删除。 |
| 账号-3 | 用户可选择仅查看当次结果，档案保存完全由本人授权开启。 |
| 账号-4 | 支持撤回同意：撤回后即时停止新增保存。 |
| 账号-5 | 普通练习录音仅用于当次学习；用于改进检测等新用途时，另行征得用户同意。 |
| 账号-6 | 账号体系保持轻量：以学习与档案功能为核心。 |

### 5.7 内容管理后台（CMS）

**模块目标**：支撑"内容可生长"——内容人员无需开发介入即可增改全站学习内容。

| 编号 | 需求 |
| --- | --- |
| 后台-1 | 按统一单元字段（见第六章）录入 / 编辑发音单元，支持保存草稿、预览、修改。 |
| 后台-2 | 支持上传图片、动画、音频等媒体并关联到单元；必需媒体与字段齐备是单元发布的前提。 |
| 后台-3 | 为每个单元配置检测任务：朗读提示词、是否开放检测、质检要求、允许输出的指标、反馈模板。 |
| 后台-4 | **发布与检测开放分离**：单元先发布学习内容、后开放检测；检测开放以学习内容已发布、该类检测已通过验证为前提。 |
| 后台-5 | 审核通过后发布；支持下架，下架后用户端即时更新。 |
| 后台-6 | 内容修改保留版本记录，必要时可回退到上一公开版本。 |
| 后台-7 | 反馈模板、说明文字等支持在后台修改，修改后前端即时生效。 |
| 后台-8 | 收集并处理用户反馈（见 5.8）；检测结论与已发布内容的修改均经由审核流程。 |
| 后台-9 | 后台关键操作（发布、下架、检测开关变更、审核）保留可查询的操作记录。 |

### 5.8 用户反馈

| 编号 | 需求 |
| --- | --- |
| 反馈-1 | 学习页提供"看懂了 / 还不明白"反馈入口，可注明哪里不清楚。 |
| 反馈-2 | 结果页提供"结果是否符合实际感受"的反馈入口。 |
| 反馈-3 | 提供"希望增加"入口：用户可提交希望学习的音或字（搜索无结果时同样出现该入口）。 |
| 反馈-4 | 支持报告内容错误（文字、声音、图片）。 |
| 反馈-5 | 后台可见全部反馈并按"待处理 / 已采纳 / 暂不采纳"处理。 |

| 编号 | 需求 | 优先级 |
| --- | --- | --- |

## 六、内容制作需求

### 6.1 统一发音单元字段

所有单元（含后续新增）按统一的字段框架录入，字段齐备是发布的前提：

| 字段组 | 录入内容 |
| --- | --- |
| 身份 | 单元编号、类型（元音 / 辅音 / 声调 / 易混音对）、拼音、声母 / 韵母 / 声调归属、代表汉字、标签 |
| 大众结论 | 一句话结论、适用问题、学习目标 |
| 发音构形 | 发音部位与方法说明、口型 / 舌位 / 唇形描述、主图或动画、替代文本 |
| 声音与声学 | 时长、音高、共振峰等语音学参考值及其适用说明（供专业折叠区与检测参考使用） |
| 媒体 | 主图 / 动画、正常与慢速示范音频、字幕或对应文字、来源与授权 |
| 练习 | 分步练习（3–5 步）、每步次数 / 时长、身体感受、安全停止条件、听辨题、跟读词、小测题 |
| 误区 | 可观察现象、可以怎么改、语气友善的表述 |
| 检测 | 朗读任务与提示词、参考示范、质检要求、允许输出的指标、反馈模板、可靠性档、审核人 |

### 6.2 内容质量与验证要求

1. 教学内容（结论、构形说明、练习、误区、反馈模板）由内容 / 语音学方向人员提供并审核后发布，保证教学口径的专业性。
2. 公开的示范音频、图片、动画具备授权记录，优先使用国家语音标准的公开授权资料。
3. 每个易混音类单元准备：说明文字、示意图、若干组对比词、标准示范录音（建议男女声各一）、听辨题、反馈模板。
4. 建立固定的**测试数据**（真人录音 + 人工逐条判断的结论）：每类检测上线前先在测试数据上评估准确率，达标后开放对应档位；检测逻辑每次调整后用同一测试数据复测。这既是分级开放的依据，也是项目可量化的成果。

## 七、通用需求（跨功能约束）

### 7.1 跨端与可达性

1. 电脑浏览器与手机浏览器均可完成"学习、播放、录音（开放检测的单元）、查看结果"主路径，即开即用。
2. 核心路径操作深度：从首页起，三次有效点击内进入某个单元的学习或录音。
3. 首页清晰呈现单元入口、搜索与当前进度；功能入口与实际可用能力一致。
4. 音频配有对应文字，关键图配有替代说明；结果呈现方式兼顾色觉差异用户。

### 7.2 性能与状态

1. 常规网络下页面切换与示范播放响应及时，数秒内可操作或给出明确加载状态。
2. 录音提交后在约定时限内给出结果或明确的失败原因；失败可重试。
3. 每个核心页面定义完整状态：加载中、无数据（含引导说明）、加载失败、无权限、检测未开放、录音中、提交中、成功、失败、质量待重录、结果已生成。
4. 错误提示告知用户下一步能做什么；重复点击、刷新、断网重连的结果保持一致，关键操作支持幂等。

## 八、1.0 完成判定（验收要点）

1. 手机与电脑浏览器上，从首页三次点击内进入任一已发布单元并开始学习。
2. 已发布单元内容完整：一句话结论、构形、可播放示范、分步练习、误区、听辨题齐备。
3. "妈"字四声样板闭环可完整演示：学习 → 听辨 → 跟读录音 → 质量检查 →（换算后）曲线对比 → 分析结论 → 四步反馈 → 保存记录 → 再录；样板单元按验证结果如实标注可靠性档。
4. 录音质量检查有效拦截问题录音（太小声、太吵、爆音、过短、没说话）并引导重录；评价仅在质量合格后给出。
5. 音高曲线按个人音域换算后与标准线对比：男声、女声用户均得到合理的对比与结论。
6. 可靠性三档（可评判 / 仅供参考 / 只练不测）真实生效，档位与测试数据的验证结果一致。
7. 访客可完成学习与一次当次检测；同意保存后，同一单元两次记录可并排比较；可删除、可撤回。
8. 后台可完成一个单元从录入、审核、发布到下架的全过程；发布后搜索与发音地图立即可达，下架后即时更新。
9. 同一分析结果的四步反馈每次输出一致；全站固定显示"学习参考"边界声明。
10. 每类已开放检测都有测试数据上的准确率记录作为开放依据。
