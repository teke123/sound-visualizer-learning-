# 功能需求 · 账号、检测与档案

## 账号、同意与访客学习

#### FR-101 访客可不登录学习（1.0，必做）

系统应允许使用者在不登录、清缓存条件下完成至少一关已发布关卡的学习。

业务规则：

- 无须先选择考试、职场、对外汉语或专业身份。

- 若当时存在已发布的关，访客还可提交一次录音并查看当次 P09。

- 未登录或未同意保存时，可查看当次结果，不自动写入档案；登录并同意后自动转存当前绑定会话全部未过期临时录音与结果。

#### FR-102 同意后的简单账号（1.0，必做）

系统应在保存进度或声音档案之前，要求使用简单账号，并在登录后、首次写入档案前获得本人同意。

业务规则：

- 同意文案写清保存什么、用来做什么、自动转存本会话全部未过期录音与结果、72 小时临时期限及删除范围。同意状态分未处理、已同意、已拒绝、已撤回；决定及 consentTextVersion 只追加留痕，不覆写旧记录。

- 登录入口写明「保存进度和录音需先同意」。

- 已登录且已同意时，录音与结果自动保存到本人档案，无须逐条点击保存。

- 访客取得结果后，登录并同意保存，自动将当前绑定会话全部未过期、未删除临时录音与结果转存本人档案；重复同意、登录和重试不产生重复条目。登录本身不构成同意；已有有效同意时登录也触发该转存。

#### FR-103 拒绝同意时仍可查看当次结果（1.0，必做）

系统应在用户拒绝同意时，仍允许查看当次 P09 结果；该结果在当前会话且未过期时可见，最长 72 小时；拒绝不提前删除当次结果，也不延长临时期。

#### FR-104 撤回同意与删除（1.0，必做）

系统应支持用户删除单条录音、删除全部档案，以及撤回同意。

业务规则：

- 撤回同意后立即停止新增保存，封锁已删除资源访问，并删除该账号全部录音（含临时）、声音档案、结果、音频文件、特征及评分缓存、学习事件与派生进度、个人音域和标定音频；再次同意不恢复已删数据。

- 撤回前须明确提示将删除全部旧档案、学习进度与音域，并要求确认；当前设备的相关本地进度与音域也清除。

- 删除后的条目及其独占 audioId 不可再读取；共用 audioId 仅在仍有本人有效录音引用时可读，不能据此恢复被删结果。单条删除、清空档案仅删除指定范围录音与派生资源；音域若依赖被删录音需重建或失效，独立学习事件保留。撤回与注销则连同全部进度和音域一起删除。

#### FR-105 录音用途（1.0，必做）

普通闯关录音仅用于当次学习；若将来用于改进检测，须另行取得同意。

#### FR-106 账号页（P11）（1.0，必做）

系统应提供账号页（P11）：未登录时提供注册与登录入口及说明；登录后提供退出、同意状态查看、撤回同意、删除单条录音与清空档案的入口。

#### FR-107 轻量账号（1.0，必做）

系统应提供满足保存与查询档案所需的简单账号：支持注册、登录、退出；账号信息收集以完成学习、档案和同意管理为限。

业务规则：

- 不收集邮箱或手机号，不提供密码找回；忘记密码只能重新注册，登录页须写明。
- 1.0 不做验证码等复杂注册防刷；注册、登录及付费评分等入口仍须基础频率限制。
- 用户名 3–32 字符（字母、数字、下划线或中文）全局唯一；密码不少于 8 位。

#### FR-108 账号注销（1.0，必做）

系统应支持注销账号：清空全部录音档案后删除账号的可识别信息，会话立即失效。

业务规则：

- 注销须再次确认并验证当前密码后执行。
- 注销后该账号不可再登录，用户名不再可用；审计所需的骨架记录匿名化保留。
- 注销按撤回同意的完整范围清理，含临时数据、进度和音域；所有登录会话立即失效。

## 检测中心与录音（P08）

#### FR-901 任务列表只含可测关（1.0，必做）

P08 任务列表仅出现「已发布」的关。

#### FR-902 进入前可听示范并看到朗读内容（1.0，必做）

系统应在进入录音前提供本关示范，并展示要朗读的内容。

#### FR-903 环境与用途说明（1.0，必做）

系统应提示找安静的地方、麦克风距离，以及录音用途：默认临时处理；要保存须本人同意。

#### FR-904 麦克风权限恢复指引（1.0，必做）

系统应在拒绝麦克风权限后说明如何开启。

#### FR-905 录音过程控制（1.0，必做）

系统应支持开始、停止、试听、重录、提交。

#### FR-906 处理失败可理解（1.0，必做）

系统应在处理失败时说明失败环节（例如没录上、太短、提交失败、评分服务异常）和下一步。

#### FR-907 多入口口径一致（1.0，必做）

系统应保证从首页、P05、P08 进入同一关任务时，提示词、示范、评分口径、结果页一致。提交须带展示时的 contentVersion；若公开版本已改变，返回 CONTENT_VERSION_CHANGED 并要求刷新任务，不能按新文本静默评分。

#### FR-908 访客可录（1.0，必做）

系统应允许不登录录音，可用于所有已发布关。

## 检测结果（P09）

#### FR-1001 录音质量先行（1.0，必做）

系统应先完成录音质量检查并返回结论：能评或不能评。检查包含两个维度：录音质量是否良好与是否按要求朗读（见 FR-1301）。不能评时写清原因和如何重录，并停止评分。

#### FR-1002 分数仅表示本关本次录音（1.0，必做）

系统应在质量合格时于 P09 展示分数。分数只表示本关当前录音的表现。

#### FR-1003 分数可解释、同规则可重复（1.0，必做）

系统应保证分数能用一句话对照本关评分维度解释；同一内容版本、规则版本与评分 Provider/模型版本下，对同一条合格录音重复提交，分数、现象与四步反馈一致。以音频内容哈希及上述版本缓存评分结论；缓存限于同一所有者及有效保留期，删除时一并清除。曲线另受音域和算法版本影响，历史快照不随个人音域变化重算。

#### FR-1004 现象（1.0，必做）

系统应用本关允许的可观察差异描述现象，仅使用已检测的维度。现象来自评分服务的音节与声韵调粒度检错信息（哪个音节、声母 / 韵母 / 声调哪一项不一致、漏读 / 增读等），用通俗话表述。

#### FR-1005 曲线对比可视化（1.0，必做）

系统应在 P09 将用户音高曲线与标准参考曲线分别展示，直观呈现「我的曲线」与「标准曲线」的差距。单韵母等关卡可同时展示共振峰（F1/F2）等声学特征对比，帮助学习者「看见」发音差异；声学特征数据由后端统一提取，前端只渲染不计算。

#### FR-1006 按个人音域换算（1.0，必做）

系统应在曲线对比前，将用户音高按本人音域换算到统一标度，使不同音高（如男声、女声）的学习者都能与同一条标准曲线比较。首次进入曲线对比前，系统应引导用户朗读一段由管理方设定的标定文本完成音域标定（提供专门的标定录音与音域计算接口）；已登录且已同意时，标定结果随档案中的有效历史滚动更新，可重新标定；访客或未同意时只作受 72 小时上限约束的临时会话标定，不存在长期档案。未标定不阻塞质量检查与评分，曲线状态为 needs_calibration，提供标定入口；无有效 F0 的录音标为 not_available，不伪造曲线。

#### FR-1007 规则引擎四步反馈（1.0，必做）

系统应输出规则引擎四步反馈：现象 → 可能相关环节 → 可感知提示 → 安全短练习。

业务规则：

- 只使用本关已定稿的现象标签。

- 相关环节用「可能」表述。

- 提示为短句、可执行。

- 短练习能跳回关卡练习。

- 四步模板齐全是关卡发布的前置条件。


#### FR-1008 立即行动与边界句（1.0，必做）

系统应提供播示范、回关卡练习、重录；已登录且已同意时自动保存到档案；访客登录并同意后自动转存当前绑定会话全部未过期临时录音与结果。固定显示边界句（见《07-非功能与UI约束》）。


## 声音档案（P10）

#### FR-1101 无档案说明（1.0，必做）

未登录或未同意保存时，录音仅当次可见。P10 显示「还没有保存的录音」，以及如何在同意后保存。

#### FR-1102 同意后的保存字段（1.0，必做）

系统应在已登录且已同意时，按关卡自动保存任务、日期、录音、质量、分数、现象、四步反馈和结果版本。

#### FR-1103 同关两次比较（1.0，必做）

系统应支持同一关至少两次记录并排播放、曲线对比和主要差异提示；比较仅在同一关内进行，双方均为本人已存档记录。不同内容或规则版本须提示不可直接比较分数，曲线的音域/算法基准差异也须标明，主要差异提示仅针对可比维度。

#### FR-1104 进步趋势（远期）

系统可支持按关卡展示已保存记录的关键指标随时间的变化趋势，帮助学习者看到前后进步。

## 录音质量检查

#### FR-1301 两维质量检查（1.0，必做）

系统应在计算分数之前完成录音质量检查，两个维度为：**录音质量是否良好**（音量、噪声、截幅、时长）与**是否按要求朗读**（对照本关朗读文本，识别漏读、增读、回读、替换与乱读）。

业务规则：

- 任一维度不合格即停止评分，仅说明如何重录。

- 必须用可执行的话说清怎么重录。

- 质量不合格时显示「本次不能评」。

- 检出乱读（胡乱朗读）时评分不可作为参考，按质量不合格处理。

- 质量结论与本关分数分开显示，避免把「没录好」理解成「发音很差」。

| 字段组 | 必须记录 | 说明 |
| ---- | ---- | ---- |
| 录音身份 | recordingId、audioId、levelId、contentVersion、ruleVersion、submissionId、提交时间 | 一次提交一条 |
| 录音文件 | 格式、时长、是否完整提交 | 未登录或未同意时不自动写入档案 |

## 临时录音与删除的生命周期

| 生命周期事项 | 规则 |
| ---- | ---- |
| 临时录音与结果的保留、失效及清理 | 用户上传（含未引用上传）、临时录音及结果、标定音频/状态和关联缓存从首次上传起最多 72 小时；到期立即不可读，最迟 24 小时内硬删。读取、提交和重试不续期；已存档录音保留至用户删除、撤回或注销。 |
| 删除完成时限、备份处理及第三方清理 | 逻辑封锁立即生效；本地文件、特征及评分缓存最迟 24 小时内硬删（架构默认上限，见 NFR-09）；清理失败重试并告警。备份默认不含私人音频/特征；若启用数据备份，保留不超过 7 天并在恢复前重放删除记录。第三方留存/删除能力须上线前核实，不能承诺本地删除即第三方已删除。 |

## 转存与删除的一致性

转存范围为当前绑定会话内尚未过期的已完成录音；正在处理的提交完成时重校验同意，未提交检测的孤儿上传不转为档案。质量不合格记录可存档但只含质量与重录建议。转存范围为当前绑定会话内尚未过期的已完成录音；正在处理的提交完成时重校验同意，未提交检测的孤儿上传不转为档案。质量不合格记录可存档但只含质量与重录建议。转存不增加逐条 archive API，由登录成功（已有同意）或授予同意自动触发；将所有符合范围的记录转为 archived，并登记有效 consentId。响应返回 transferredCount 和转存状态，失败可安全重试。完成评估前后都须重校验当前同意；撤回、删除或注销与评估并发时禁止后台处理完成后重新写回被删数据。

未登录/未同意进度只存本地，服务端 learning-events 拒绝写入。退出或切换账号清空当前设备账号相关状态并开始新的访客上下文；清空本地存储后的进度不可恢复，不能从临时录音反推访客进度。访客标定是处理临时音频所需数据，不属于学习事件进度。

本地删除边界：当前设备在撤回/注销时清除相关进度与音域；其他离线设备在下次联网重新校验账号与同意后清除，服务端不能远程立即擦除离线浏览器存储。自动转存不包括未提交检测的孤儿上传；处理中录音完成时重校验同意，质量不合格记录只保留质量结论与重录指引。
