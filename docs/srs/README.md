## 业务定案（D）

| 编号 | 定案事项 | 结论 |
| ---- | ---- | ---- |
| D-01 | 产品边界 | 只做普通话发音学习。 |
| D-02 | 用户分流 | 1.0 面向大众普通话学习者。普通话考试 / 职场用户进入 2.0，对外汉语路径进入 3.0。 |
| D-03 | 页面结构 | 保留 P01 起的页面结构，每页承载真实已发布内容；页面数量可随版本扩展，不在本规格中固定。2026-10-15 修订：P07 专业资料页退役（资料元数据并入 P04 文章参考资料与 P05 专业折叠），1.0 页面 = P01–P06、P08–P11 共 10 页；P07 编号空缺不复用，新增页面自 P12 起。 |
| D-04 | 1.0 关卡 | 6 个单韵母 + 23 个声母（21 + y + w）+「妈」拼读（m+a 及 mā/má/mǎ/mà），合计 30 关（L01–L30）。 |
| D-05 | 1.0 检测 | 所有已发布关均可录音打分，学习与检测随关卡一同发布。 |
| D-06 | 1.0 模型 | 评分调用外部普通话评分服务，结合规则引擎四步反馈跑通闭环。 |
| D-07 | 检测结果 | 结果 = 曲线对比 + 分数 + 现象 + 规则引擎四步反馈；分数在 P09 可见、可解释、同规则可重复。 |
| D-08 | 账号 | 可不登录先学；登录并同意后自动保存进度 / 录音；访客可在登录同意后保存刚才的录音与结果；撤回同意时删除全部旧录音与声音档案。 |
| D-09 | CMS | 1.0 必做录入、发布 / 下架与版本管理，由单一管理员操作。 |
| D-10 | 冻结日 | 1.0 = 2026-10-27；2.0 = 2027-01-15；3.0 = 2027-04-15。 |
| D-11 | 2.0 范围 | 大模型四步话术（须管理员确认）、个性化推荐、考试 / 职场问题标签分流（沿用同一套页面）、专属纠音模型与通用评分对比、复韵母与鼻韵母等关卡内容扩展。 |
| D-12 | 3.0 范围 | IPA、变调（含双字词与短句）、音位变体、对外汉语路径。 |
| D-13 | 1.0 小测 | 关卡小测移出 1.0、推迟 2.0（FR-607）；1.0 关卡完成度由听辨与练习事件派生。 |

## 核心业务闭环

用户的标准路径；任一已发布关均提供学习与录音检测。

```mermaid
flowchart TD
    A[打开首页] --> B[选择一关]
    B --> C[已发布关卡页]
    C --> D[看一句话结论和构形]
    D --> E[听示范]
    E --> F[完成听辨与 3–5 步跟着练]
    F --> I[按提示录音并提交]
    I --> J{录音质量与朗读要求是否合格}
    J -- 否 --> K[停止评分并说明如何重录]
    K --> I
    J -- 是 --> L[展示曲线对比、分数、现象、四步反馈]
    L --> N{是否已登录且已同意}
    N -- 否 --> O[当次结果可看，可登录同意后保存本条]
    N -- 是 --> P[自动保存到声音档案，比较前后变化]
    O --> M[重录或进入下一已发布关]
    P --> M
```
