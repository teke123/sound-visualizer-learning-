## 2.0 功能

#### FR-1601 大模型四步反馈话术（2.0，必做）

系统支持使用大模型结合本关目标、检错现象标签与声学特征参数，实时生成或优化四步反馈的表述文案，使反馈更贴合用户当次发音表现。分数与现象标签仍由评分与声学分析模块稳定给出；大模型服务不可用时自动回落至 1.0 规则模板。

#### FR-1603 个性化推荐（2.0，必做）

系统应根据用户的错题或薄弱关卡记录推荐下一关；无历史记录时默认从第一关开始。

#### FR-1604 专属纠音模型可对比（2.0，必做）

系统可允许用专属纠音模型替代或增强通用评分，并提供同任务、同录音的对比：至少覆盖一类拼读任务及一类易混声母任务。对比记录进入验收材料。

#### FR-1605 韵母层关卡扩展（2.0，必做）

系统应新增复韵母与鼻韵母关，重点覆盖前后鼻音易混对（an/ang、en/eng、in/ing）。新增关沿用同一套关卡结构（P05），开放后提供学习与检测，并可从搜索、发音地图的对应层进入。

#### FR-1606 易混声调关（2.0，必做）

系统应新增以易混声调区分为目标的关（如第二声 / 第三声），沿用基频曲线对比与音域换算口径，开放后提供检测。

#### FR-1607 考试 / 职场问题标签分流（2.0，必做）

系统应允许考试、职场学习者按问题标签进入同一套关卡与原理文章，沿用同一套页面与账号体系，通用路径保持直达。

## 3.0 功能

#### FR-1701 IPA / 变调 / 音位变体学习内容（3.0，必做）

系统应在关卡页（P05）、原理子站文章（P04）和学习说明中，提供 IPA、变调规则（含双字词与短句）、音位变体的教学内容与声学可视化对比，并提供对应朗读任务的检测。

#### FR-1702 对外汉语路径（3.0，必做）

系统应在同一套核心内容上增加对外汉语问题标签和学习提示（例如声调与送气音对非母语者的说明），沿用既有页面与关卡体系。
