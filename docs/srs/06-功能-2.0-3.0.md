## 2.0 功能

#### FR-109 考试 / 职场用户同意规则（2.0，必做）

考试 / 职场用户保存录音同样须经本人同意，与 1.0 同意规则同一强度。

#### FR-1601 大模型四步话术须确认（2.0，必做）

系统可允许用大模型生成或改写四步反馈的表述。质量结论、分数、现象标签由评分模块给出，模型仅改写表述文案。上线前须经管理员逐条确认；未确认或确认未通过时显示 1.0 规则模板。

#### FR-1602 话术可追溯检测结果版本（2.0，必做）

系统应保证大模型话术的确认记录能追溯到所依据的检测结果版本。

#### FR-1603 个性化推荐（2.0，必做）

系统应根据错关或未过关记录推荐下一关，推荐目标为已发布关；未登录时回落到下一已发布关或 L01。

#### FR-1604 专属纠音模型可对比（2.0，必做）

系统可允许用专属纠音模型替代或增强通用评分，并提供同任务、同录音的对比：至少覆盖一类拼读任务及一类易混声母任务。对比记录进入验收材料。

#### FR-1605 韵母层关卡扩展（2.0，必做）

系统应新增复韵母与鼻韵母关，重点覆盖前后鼻音易混对（an/ang、en/eng、in/ing）。新增关沿用同一套关卡结构，发布后提供检测，并可从搜索、发音地图的对应层进入。

#### FR-1606 易混声调关（2.0，必做）

系统应新增以易混声调区分为目标的关（如第二声 / 第三声），沿用曲线对比与音域换算口径，发布后提供检测。

## 3.0 功能

#### FR-1701 IPA / 变调 / 音位变体学习内容（3.0，必做）

系统应在关卡页专业折叠区、原理子站文章和必要的学习说明中，提供 IPA、变调规则（含双字词与短句）、音位变体的教学内容。内容发布后同步提供对应朗读任务的检测。通用主路径保持原样。

#### FR-1702 对外汉语路径（3.0，必做）

系统应在同一套核心内容上增加对外汉语问题标签和学习提示（例如声调对非母语者的说明），沿用既有页面与关卡体系。
