# 一、产品定位与目标

## 1.1 项目背景与问题陈述

**现状痛点**：

- 普通话发音学习主要依赖口耳相传。学习者难以看见口型、舌位和气流，也难以判断「哪里不像」以及下一步练什么。

- 现有学习材料多为静态课文或跟读音频，缺少「看示范 → 听辨 → 跟着练 → 录音 → 得到可执行反馈 → 再练」的闭环；多数产品只给分数，不给「为什么错、怎么改」。

**解决方案**：以浏览器为入口、以发音关卡学习与检测为主线的普通话发音学习系统。学习者看清口型、听清示范、完成听辨与短练习；对已发布的关，提交录音后得到录音质量结论、曲线对比、分数、可观察现象和规则引擎四步反馈。

**业务影响**：学习者能完成可重复的学习闭环；反馈中性、可执行，能带着再练；内容方可持续发布关卡而无需调整页面结构。

## 1.2 产品定位

「看得见的声音」是面向大众的智能发音学习平台，以普通话发音学习为核心，把抽象的发音过程（口腔构形、音高变化等）转化为直观的图像、动画和声学曲线。1.0 服务大众普通话学习者；2.0 在同一套页面上增加考试 / 职场问题标签；3.0 再增加对外汉语路径标签。系统以浏览器为入口，主路径在电脑和手机浏览器中完成。

系统应让使用者快速完成：

- 找到当前已发布的关卡并开始学习。

- 看懂本关口型、听清示范、完成听辨与 3–5 步练习。

- 在已发布关上录音，并得到能说明现象和下一步练习的学习参考结果。

- 在同意后保存进度和录音，比较同一关的前后变化，并随时删除。

CMS 负责关卡录入、媒体上传、发布、下架、版本管理和反馈处理；评分模块负责录音质量检查、曲线对比、分数、现象和规则四步匹配。

## 1.3 建设目标

1. **降低学习门槛**：无须先理解语音学或算法即可开始学习。

2. **保证学习可执行**：结果必须说明现象、可能相关环节、可感知提示和安全短练习，而不是只给空泛总分。

3. **保证检测可信**：已发布关均提供检测；质量不合格时停止评分。

4. **保证内容可治理**：关卡内容经 CMS 录入、发布。

5. **保证数据可控**：可不登录先学；保存须本人同意，可拒绝、可撤回、可删。

# 二、用户角色与画像

## 2.1 主要角色

> 口径说明：下表「角色」表达的是业务身份。系统权限按账号、同意状态和 CMS 管理员授权；业务身份不等于权限角色。

| 角色 | 主要职责 | 在系统中的关系 | 首次纳入 |
| ---- | ---- | ---- | ---- |
| 大众普通话学习者 | 看、听、辨、练、录音 | 1.0 面向的学习者 | 1.0 |
| 未登录访客 | 先学；有已发布关时可临时录音并查看当次 P09 | 当前会话可见，最长 72 小时，不构成长期档案 | 1.0 |
| 已同意的简单账号用户 | 保存进度、声音档案 | 须先完成保存同意 | 1.0 |
| 普通话考试学习者 | 通过问题标签进入同一套核心内容 | 同一套页面 | 2.0 |
| 职场发音学习者 | 通过问题标签进入同一套核心内容 | 同一套页面 | 2.0 |
| 对外汉语学习者 | 通过对外汉语标签进入同一套核心内容 | 同一套核心内容 | 3.0 |
| 管理员 | 录入关卡字段、上传媒体、保存草稿、发布 / 下架、版本回退、反馈处理 | CMS 操作者 | 1.0 |

## 2.2 核心用户画像：大众普通话学习者

- **目标**：按关卡学会看口型、听示范、分得清易混音；在可测关上录音后知道下一步做什么。

- **痛点**：不识专业术语；看不到舌位和音高走向；容易被无效按钮和吓人结论打断；担心录音被长期保存或用于不明用途。

- **使用要求**：需要即开即用、通俗短句、可播放示范、明确对错边界，以及随时可以停止和删除的出口。

## 2.3 其他角色画像

**管理员**

- 目标：按统一字段把关卡从草稿推进到已发布，发布后同步提供学习与检测。

- 痛点：缺示范、缺授权、缺四步模板时无法发布；需要预览大众端真实效果。

**2.0 / 3.0 新增学习者**

- 目标：用问题标签找到更贴合考试、职场或对外汉语的示例与推荐，仍使用同一套网站。

- 约束：通用主路径保持直达可用。

## 2.4 身份与数据权限

1. 人员可以不登录使用已发布学习内容。

2. 所有已发布关均提供学习与录音检测入口。

3. 未登录或未同意保存时，P10 显示「还没有保存的录音」的说明，以及如何在同意后保存。

4. 权限由服务端业务规则保证；客户端隐藏入口仅为体验处理。

5. 未发布正文、媒体与检测配置仅管理员可见。地图可展示预先公开的关卡身份骨架（ID、顺序、层、目标音和未开放状态），不泄露草稿。

## 2.5 会话与转存边界

访客临时录音由服务端匿名 sid 会话保护；未同意的已登录录音归该账号但仍为临时，账号归属与是否存档是两个独立状态。登录成功后绑定当前 sid 至该账号，保留已认证账号的当次结果访问能力；绑定后原访客资源归账号，sid 单独不再足以访问；注册本身不等于登录或授权。仅在登录且同意有效时自动转存符合 D-14 的全部记录。

同意界面须明确「会自动保存本会话全部未过期录音与结果」，共用设备用户可先删除临时录音或重新开始会话。退出、切换账号时断开旧绑定并轮换 sid，后续账号不可认领上一账号记录；丢失会话凭据的访客结果无法恢复。管理员权限不包含访问私人录音。
