# 一、产品定位与目标

## 1.1 项目背景与问题陈述

**现状痛点**：

- 普通话发音学习主要依赖口耳相传。学习者难以看见口型、舌位和气流，也难以判断「哪里不像」以及下一步练什么。

- 现有学习材料多为静态课文或跟读音频，缺少「看示范 → 听辨 → 跟着练 → 录音（含实时声学监控） → 得到可执行反馈 → 再练」的闭环；多数产品只给分数，不给「为什么错、怎么改」。

**解决方案**：以浏览器为入口、以发音关卡学习与检测为主线的普通话发音学习系统。学习者看清口型与声学规律、听清示范、完成听辨与短练习；在关卡内录音时即可获得前端实时声学视觉反馈（实时波形、音量包络与实时音高轨迹），提交后得到精细的多维声学图像对比（基频曲线、元音空间共振峰、送气段波形/语谱图等）、分数、可观察现象、规则引擎四步反馈以及录音质量提示。

**业务影响**：学习者能完成可重复的学习闭环；反馈直观、可执行，能带着再练；团队可通过简单后台持续维护关卡内容而无需调整页面结构。

## 1.2 产品定位

「看得见的声音」是面向成人与大众的智能发音学习平台，以普通话发音学习为核心，把抽象的发音过程（口腔构形、音高变化、频谱特征等）转化为直观的图像、动画和声学曲线。1.0 服务大众普通话学习者；2.0 在同一套页面上增加考试 / 职场问题标签；3.0 再增加对外汉语路径标签。系统以浏览器为入口，主路径在电脑和手机浏览器中完成。

系统应让使用者快速完成：

- 登录账号，找到当前开放的关卡并开始学习。

- 看懂本关口型与发音机制、听清示范、完成听辨与 3–5 步练习。

- 在关卡页（P05）上直接录音，边发声边查看前端实时声学反馈，提交后得到能说明声学现象和下一步练习的反馈结果。

- 自动保存学习进度和录音档案，比较同一关的前后变化，并可随时管理或删除自己的录音。

后台模块负责团队内部日常录入与维护关卡、媒体和原理文章；评分与分析模块负责声学特征提取、可视化对比、外部评分调用、现象与规则四步匹配以及录音质量提示。

## 1.3 建设目标

1. **直观可视化（实时 + 事后对比）**：录音过程中提供前端实时声学反馈（实时波形、音量包络与实时音高轨迹）；录音提交后通过 2D/3D 构形、基频曲线、共振峰元音空间、送气段波形与语谱图，让发音过程与声学结果清晰可见。

2. **保证学习可执行**：结果说明可观察现象、可能相关环节、可感知提示和安全短练习，而不是只给空泛总分。

3. **提供录音质量辅助提示**：检测录音音量、噪声等环境质量并给予友好提示，帮助用户了解录音环境是否理想，同时正常展示评分与声学反馈。

4. **保证内容易维护**：关卡与文章内容可通过团队自用简单后台方便地录入与更新。

5. **账号流程简洁清晰**：用户注册登录即默认同意服务条款，支持选填「方言区 / 母语背景」，学习进度与声音档案自动保存，支持删除个人录音与注销账号。

# 二、用户角色与画像

## 2.1 主要角色

| 角色 | 主要职责 | 在系统中的关系 | 首次纳入 |
| ---- | ---- | ---- | ---- |
| 大众普通话学习者 | 注册登录、看、听、辨、练、录音、查看声音档案 | 1.0 面向的核心学习者 | 1.0 |
| 普通话考试学习者 | 通过问题标签进入同一套核心内容 | 同一套页面 | 2.0 |
| 职场发音学习者 | 通过问题标签进入同一套核心内容 | 同一套页面 | 2.0 |
| 对外汉语学习者 | 通过对外汉语标签进入同一套核心内容 | 同一套核心内容 | 3.0 |
| 团队内容维护者 | 录入与修改关卡字段、上传媒体、维护原理文章、查看用户反馈 | 后台维护操作者 | 1.0 |

## 2.2 核心用户画像：大众普通话学习者（成人）

- **目标**：按关卡看懂口型与声学特征、听示范、分得清易混音；在关卡内录音时实时看到发声状态，提交后通过视觉对比和文字反馈知道自己的差距与下一步练法。

- **痛点**：光靠听觉模仿看不到舌位、送气差异和音高走向；普通打分软件只给冷冰冰的分数，不解释声学和发音器官层面的原因。

- **使用要求**：需要清晰直观的构形与声学图表、实时发声反馈、可播放示范、明确的改进提示，以及自动保存的个人练习档案以便对比前后进步。

## 2.3 其他角色画像

**团队内容维护者**

- 目标：通过简洁直观的后台表单录入或更新关卡文字、声道参数、示范音与原理文章，无需改动前端代码即可生效。

**2.0 / 3.0 新增学习者**

- 目标：用问题标签找到更贴合考试、职场或对外汉语的示例与推荐，仍使用同一套网站。

- 约束：通用主路径保持直达可用。

## 2.4 账号与数据使用规则

1. 用户注册并登录后使用系统的学习、录音检测与声音档案功能；注册/登录即默认同意服务条款。

2. 用户可在注册时或账号页（P11）选填个人的「方言区 / 母语背景」（如粤语、川渝西南官话、吴语、闽南语、英语、日语等），以便为后续针对性教学与统计分析提供依据。

3. 所有开放关卡均在关卡页（P05）同步提供学习内容与录音检测入口。

4. 用户的学习进度、音域标定结果和每次录音检测结果自动保存在个人账号下。

5. 用户可随时在声音档案（P10）或账号页（P11）删除单条录音、清空个人声音档案，或注销个人账号。

6. 密码找回：远期提供通过绑定邮箱找回密码的能力。
