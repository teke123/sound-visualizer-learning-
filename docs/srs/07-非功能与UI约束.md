## 外部接口（需求层）

系统通过浏览器提供学习与录音界面，通过 CMS 提供内容管理界面。录音评分调用外部普通话评分服务（科大讯飞语音评测接口）：检测任务必须指定朗读文本，评分针对该文本进行；系统使用服务返回的声韵、调型等维度分数与音节粒度检错信息生成现象与四步反馈。评分结果对象稳定包含：质量、分数、现象、四步、版本号。2.0 若启用大模型，仅作为话术生成接口，并带管理员确认位。

## 弱网

- 显示当前处理状态（检查中 / 分析中 / 失败）。

- 录音提交失败时保留可重试路径，保留已录内容直至用户放弃。

- 关键动作（发布、下架、写入档案、删除档案）在线完成。

# UI 与交互需求

## 页面状态

所有核心页面定义以下状态：初始、加载、空数据（含 P10 无档案说明、P03 未开放）、加载失败、无权限（含拒绝麦克风）、录音中、提交中、提交成功、提交失败、质量不合格、结果已生成。

## 防错和反馈

- 点击、录音、上传、处理中、成功和失败均有明确状态；提交后防止重复操作。

- 错误提示包含下一步能做什么。

- 「已提交」表示系统已受理；评分完成后更新为结果状态；结果未知时提供查询和重录入口。

- 界面使用正式图标与文字标注。

- 删除档案及撤回保存同意（将清空全部旧档案）须二次确认。

## 边界句

结果页和首页持续可见：「学习参考，不作为普通话等级认定或医学诊断」。FR-206、FR-506、FR-1008 的边界文案以本句为准。
