## 外部接口（需求层）

系统通过浏览器提供学习与录音界面，通过 CMS 提供内容管理界面。录音评分调用外部普通话评分服务（科大讯飞语音评测接口）：检测任务必须指定朗读文本，评分针对该文本进行；系统使用服务返回的声韵、调型等维度分数与音节粒度检错信息生成现象与四步反馈。评分结果对象稳定包含：质量、分数、现象、四步、版本号。2.0 若启用大模型，仅作为话术生成接口，并带管理员确认位。

## 弱网

- 显示当前处理状态（检查中 / 分析中 / 失败）；评分超出即时等待窗口时由后台继续处理，客户端断网或离开不取消，恢复后按 recordingId 查询（D-19）。

- 录音提交失败时保留可重试路径，保留已录内容直至用户放弃。

- 关键动作（发布、下架、写入档案、删除档案）在线完成。

## 审计与可观测性

| 编号 | 约束 | 说明 | 版本 | 优先级 |
| ---- | ---- | ---- | ---- | ---- |
| NFR-19 | 关键操作可追溯 | 提交检测、发布、下架、版本回退、同意、撤回、删除档案须留下可查询标识（requestId 或审计记录 ID），并能还原操作前后状态 | 1.0 | 必做 |

审计信息至少包括：操作者、对象、时间、操作前状态、操作后状态、原因、版本号及 requestId；撤回/注销后仅留匿名化状态骨架，不保留录音、特征、私人结果正文或可还原个人进度的数据。

# UI 与交互需求

## 页面状态

所有核心页面定义以下状态：初始、加载、空数据（含 P10 无档案说明、P03 未开放）、加载失败、无权限（含拒绝麦克风）、需要标定、录音中、提交中、提交成功、提交失败、质量不合格、结果已生成。

## 防错和反馈

- 点击、录音、上传、处理中、成功和失败均有明确状态；提交后防止重复操作。

- 错误提示包含下一步能做什么。

- 「已提交」表示系统已受理；评分完成后更新为结果状态；结果未知时提供查询和重录入口。

- 界面使用正式图标与文字标注。

- 删除档案及撤回保存同意须二次确认；撤回明确告知还会清空学习进度与音域；注销还须校验当前密码。

## 边界句

结果页和首页持续可见：「学习参考，不作为普通话等级认定或医学诊断」。FR-206、FR-506、FR-1008 的边界文案以本句为准。

## HTTP、媒体与资源保护

JSON 契约采用 camelCase，响应为 `{code, message, data, requestId, nextStep?}`，同一 requestId 写入 `X-Request-Id` 与审计。成功及质量不合格为 200（能解码但过短、静音等属于质量不合格）；首次提交超出同步等待窗口、处理中重复提交或查询为 202；未认证 401、无权限/未同意 403、不可见/已失效资源 404、幂等或内容版本冲突及未完成标定 409、上传过大 413、非法请求 400/422、限流 429、内部失败 500、Provider 异常 502/503、超时 504。不存在与非本人资源可统一 404，避免枚举。登录/注册适配层按同一 JSON 契约登记，不能把认证库默认行为视为业务端点契约。

文件/图片/音视频/字幕/模型直接返回对应媒体类型，不套 JSON 成功 envelope；支持音视频 Range（206、非法范围 416）、ETag 与 304，失败使用真实状态码。公开媒体的每次读取/再验证均须确认仍被已发布版本引用；缓存策略不得延长下架后的可访问性。私人结果与文件禁止共享缓存；预览及其媒体使用 no-store。

对上传、评分、特征计算、标定、反馈、注册、登录实施基础限流；访客按 sid 与 IP，登录按账号与 IP，并设全局计算并发上限。Cookie 使用 HttpOnly、HTTPS 下 Secure 与合适的 SameSite；写操作校验 Origin/CSRF，配置明确的跨域来源。管理员凭据与预览权限独立；用户本人录音的 F0、共振峰与共振峰图片按 audioId 对外提供，与音频文件使用同一归属与失效校验；质量诊断、ASR 与模型加载仅开发环境或管理员内部开放，1.0 不公开本地评分端点。

删除/转存/评分的并发流程须重校验同意和删除状态，保证撤回后没有新增存档或缓存复活；清理任务可重试并可观测。30 秒是结果或失败的用户时限，不代表外部调用天然可在该时限内成功，须验收超时恢复路径。无法撤回已下载的媒体，但下架后服务端及受控缓存不得继续授权读取。
