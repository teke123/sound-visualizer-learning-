## 外部接口（需求层）

系统通过浏览器提供学习与录音界面，通过简单后台提供团队内容维护界面。录音评分调用外部普通话评分服务（科大讯飞语音评测接口），并结合本地 Python 声学特征分析（提取基频 F0、共振峰 F1/F2、时域送气段波形/VOT 与语谱图）：系统结合评测维度分数、检错信息与声学参数生成现象与四步反馈，同时输出录音环境质量提示。

## 弱网与异常处理

- 显示当前处理状态（分析中 / 评分中 / 失败）；评分超出即时等待窗口时由后台继续处理，完成后可按 recordingId 查询（D-19）。

- 录音提交失败时保留可重试路径，保留已录内容直至用户放弃。

# UI 与交互需求

## 页面状态

核心页面定义以下状态：初始、加载、空数据（含 P10 空档案提示、P03 未开放状态）、加载失败、麦克风权限未开启、录音中、提交中、结果已生成（含录音质量提示）、提交失败。

## 防错和反馈

- 点击、录音、上传、处理中、成功和失败均有明确状态；提交后防止重复点击。

- 错误提示包含下一步能做什么。

- 清空档案及注销账号须二次确认；注销账号还须校验当前密码。

## HTTP 与媒体接口约定

JSON 契约采用 camelCase，响应为 `{code, message, data, requestId, nextStep?}`，同一 requestId 写入 `X-Request-Id`。成功响应为 200；首次提交超出同步等待窗口或处理中查询为 202；未登录 401、无权限 403、资源不存在 404、幂等冲突 409、上传过大 413、非法请求 400/422、限流 429、内部失败 500、Provider 异常 502/503、超时 504。

文件/图片/音视频/字幕/模型直接返回对应媒体类型，支持音视频 Range（206）与缓存响应。用户本人录音的 F0、共振峰、送气段波形、语谱图等数据与图片按 audioId 或 recordingId 对本人开放读取。
