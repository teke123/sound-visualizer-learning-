# 三、业务上下文与核心对象

## 3.1 统一学习上下文（LearningContext）

进入学习或检测类功能时，系统携带统一学习上下文，并定义获取、校验和切换规则：

- 登录状态。

- 保存同意状态。

- 关卡 ID（L01–L30 或后续已发布关）。

- 关卡发布状态（草稿 / 已发布 / 已下架）。

- 内容版本与规则版本。

- 问题标签（1.0 默认通用；2.0 起可切换）。

若某项业务无需其中某个对象，应明确标注「无需关联」。从搜索、地图、首页按钮或消息进入时，须重新校验关卡仍为已发布。

## 3.2 业务锚点规则

| 业务场景 | 主要锚点 | 辅助信息 |
| ---- | ---- | ---- |
| 学习、搜索、地图 | 关卡 ID + 发布状态 | 类型、目标音、代表汉字、学习标签 |
| 关卡内录音、检测中心 | 关卡 ID + 发布状态 + 规则版本 | 提示词、示范、质量两维 |
| 结果页 | 本次录音 ID + 关卡 ID + 内容版本 + 规则版本 | 质量、曲线对比、分数、现象、四步 |
| 声音档案 | 账号 + 同意记录 + 关卡 ID | 日期、录音、结果快照 |
| CMS 发布 | 关卡 ID + 授权记录 + 版本记录 | 状态机、版本 |

搜索词、汉字、拼音仅用于匹配已发布关；系统须展示匹配结果。

| 对象 | 必须具备的业务信息 |

# 四、信息架构与导航

## 4.1 页面清单与编号

页面编号从 P01 起顺序分配，页面数量可随版本扩展，新增页面沿用同一编号规则。下表为当前页面清单（2026-10-15 修订：P07 已退役，编号空缺不复用，新增页面自 P12 起，见 D-03）：

| 编号 | 页面 | 用户来这里做什么 | 1.0 必须呈现 |
| ---- | ---- | ---- | ---- |
| P01 | 首页 | 看懂这是普通话发音学习平台，立刻搜、学、练或录音 | 四个入口、搜索、已发布关入口、简短说明 |
| P02 | 搜索 | 用汉字、拼音或关卡名找到一关 | 结果列表、进入关卡、无结果时的相近关和「希望增加」 |
| P03 | 发音地图 | 看自己学到哪一层：单韵母、声母、还是拼读 | 三层闯关定位、已发布关可点进、易混关并排入口 |
| P04 | 发音原理（子站） | 用通俗的文章知道声音怎么发出来 | 文章目录 + 文章页（气 / 声 / 口型分类）；每篇配短练习、可播放示范与已发布关入口；文章参考资料（来源 / 许可 / 边界） |
| P05 | 示范单元 = 关卡页 | 围着这一关看、听、辨、练、录 | 一句话结论、构形（多视图切换）、示范音、听辨、3–5 步练、误区、本关录音（小测 2.0，见 FR-607） |
| P06 | 发音库 | 按层查看已发布关目录（工具页，不承载进度） | 只索引已发布关；可播放、可进关、可比较已发布相近关 |
| P08 | 检测中心 | 选一关按要求朗读并提交 | 与关卡内录音同一套任务、同一套评分口径 |
| P09 | 结果 | 看懂这一关录得怎么样、差距在哪、下一步练什么 | 录音质量、曲线对比、分数、现象、规则四步反馈、重录 |
| P10 | 声音档案 | 同意后看自己同一关的前后变化 | 至少两次可比较、可删、仅本人可见 |
| P11 | 账号 | 注册登录、管理同意与删除 | 注册、登录、退出、同意状态、撤回同意、删除档案入口 |
