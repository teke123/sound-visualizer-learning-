# 三、业务上下文与核心对象

## 3.1 统一学习上下文（LearningContext）

进入学习或检测类功能时，系统携带统一学习上下文：

- 当前登录用户账号信息（含可选的方言区 / 母语背景信息）。

- 关卡 ID（L01–L30 或后续新增关卡）。

- 问题标签（1.0 默认通用；2.0 起可切换）。

## 3.2 业务锚点规则

| 业务场景 | 主要锚点 | 辅助信息 |
| ---- | ---- | ---- |
| 学习、搜索、地图 | 关卡 ID | 类型、目标音、代表汉字、学习标签 |
| 关卡内录音（P05） | 关卡 ID | 提示词、示范音频、声学分析类型、前端实时声学反馈视图 |
| 结果页（P09） | 本次录音 ID + 关卡 ID | 声学可视化对比、分数、现象、四步反馈、录音质量提示 |
| 声音档案（P10） | 账号 ID + 关卡 ID | 日期、录音、结果记录 |
| 后台内容维护 | 关卡 ID / 文章 slug | 关卡字段、媒体文件 |

## 3.3 核心对象要求

| 对象 | 必须具备的业务信息 |
| ---- | ---- |
| 关卡 | 关卡 ID、顺序、类型、目标音、代表汉字、构形、声学说明与参考值、示范、练习、误区、是否开放 |
| 录音任务 | 提示词、评测文本与题型、示范、参考示范与参考发音人、输出的声学指标、四步模板 |

| 用户账号 | 账号 ID、用户名、密码哈希、方言区/母语背景（可选）、创建时间、个人音域状态（可选邮箱，用于远期密码找回） |

| 资料 | 内容 |
| 原理文章 | 标题、唯一 slug、分类、摘要、正文 |

# 四、信息架构与导航

## 4.1 页面清单与编号

1.0 页面为 P01–P06、P09–P11，共 9 页。页面数量可随版本扩展，新页面从 P12 起编号（D-03）：

| 编号 | 页面 | 用户来这里做什么 | 1.0 必须呈现 |
| ---- | ---- | ---- | ---- |
| P01 | 首页 | 看懂这是普通话发音学习平台，立刻搜、学、练或录音 | 搜索、关卡入口、简短说明 |
| P02 | 搜索 | 用汉字、拼音或关卡名找到一关 | 结果列表、进入关卡、无结果时的相近关和「希望增加」 |
| P03 | 发音地图 | 看自己学到哪一层：单韵母、声母、还是拼读 | 三层闯关定位、已开放关可点进、易混关并排入口 |
| P04 | 发音原理（子站） | 通过文章了解声音怎么发出来与声学机制 | 文章目录 + 文章页；每篇配文章参考资料 |
| P05 | 示范单元 = 关卡页 | 围着这一关看、听、辨、练、直接录音检测 | 构形（多视图切换）、示范音、听辨、3–5 步练、误区、专业与声学说明、本关录音（含实时声学反馈）与检测提交（小测 2.0，见 FR-607） |
| P06 | 发音库 | 按层查看关卡目录与并排比较（工具页，不承载进度） | 索引已开放关；可播放、可进关、可比较相近关 |
| P09 | 结果 | 看懂这一关录得怎么样、差距在哪、下一步练什么 | 声学可视化对比（基频、共振峰、送气段波形/语谱图等）、分数、现象、规则四步反馈、录音质量提示、重录 |
| P10 | 声音档案 | 看自己同一关的前后变化 | 历史记录列表、至少两次可比较、可删 |
| P11 | 账号 | 注册登录、维护个人背景与管理档案账号 | 注册、登录、退出、方言区/母语背景设置、音域标定入口、删除档案入口、注销账号入口 |

# 附录 A 关卡字段与结构定义

| 字段组 | 1.0 录入内容 | 用途 |
| ---- | ---- | ---- |
| 关卡身份 | 关卡 ID（L01–L30）、顺序、类型、目标音、代表汉字、学习标签、是否开放 | 搜索、地图、P06 目录 |
| 大众结论 | 本关要学会什么、适用的易混情况（若有） | 关卡页首屏、搜索摘要 |
| 看得见的构形 | 口型 / 舌位说明、主图或动画、替代文本；声道剖面参数（按发音器官位置的关键帧，单帧表示静态口型，多帧表示过程，如塞音成阻到除阻、拼读 m→a）；可选 3D 模型资源 | P05 构形（内容媒体视图、声道剖面视图、三维视图） |
| 示范媒体 | 正常语速音频；可选慢速；建议男女声各一条；字幕或对应文字；来源说明 | 播放示范 |
| 听辨与跟读 | 听辨题（题目 ID、题干音频、选项、正确项、解释）、跟读词（小测 2.0 起录入，见 FR-607） | P05 听辨与跟读 |
| 跟着练 | 3–5 步（步骤 ID）、每步次数或时长、身体感受 | P05 练习 |
| 误区 | 可观察现象、可以怎么改 | P05 误区 |
| 检测任务 | 朗读提示词、评测文本与题型、参考示范（用于声学对比的示范及其参考发音人）、本关输出的声学指标（如 F0、F1/F2、送气段波形/VOT、语谱图）、四步反馈模板 | P05 录音区 / P09 结果页 |
| 声学与专业说明 | 语音学与声学解释、声学参考值（时长、音高 F0、共振峰 F1/F2、VOT 等参考值及适用说明）、参考资料来源 | P05 展示 |

## 关卡学习与构形子结构约定

| 字段 | 结构说明 |
| ---- | ---- |
| `quiz[]` | `{id, stimulusMediaId, prompt, options: [{text, mediaId?}], answerIndex, explanation?}` |
| `practice[]` | `{id, title, instruction, repeat?, durationSec?, bodyCue, mediaId?}` |
| `articulation` | `{media: [{mediaId, kind: image / animation / video, altText}], description, sagittal: {keyframes[]}, model3dMediaId?}` |

2D 声道剖面参数 `sagittal.keyframes[]`（单帧表示静态口型，多帧表示动态过程，如塞音成阻→除阻、L30 的 m→a），按发音器官描述，元音与辅音共用：

| 字段 | 取值 | 说明 |
| ---- | ---- | ---- |
| `label` | 文本 | 帧说明，如「双唇闭合」「张口」 |
| `holdMs` | 整数 | 该帧停留时长，前端在帧间插值 |
| `jaw` | `0–1` | 下颌开合度 |
| `lips` | `{aperture: 0–1, rounding: 0–1, contact: none / bilabial / labiodental}` | 开口度、圆唇度、接触方式 |
| `tongueTip` | `{place: rest / dental / alveolar / postalveolar / retroflex, stricture: open / approximant / fricative / closure}` | 舌尖位置与阻碍程度 |
| `tongueBody` | `{height: 0–1, backness: 0–1, stricture: open / approximant / fricative / closure}` | 舌面高低前后；j/q/x 用高前位加阻碍，g/k/h 用高后位加阻碍 |
| `velum` | `raised / lowered` | 软腭升降（m、n 为 lowered） |
| `airflow` | `none / oral / nasal / burst / aspirated_burst / friction / affricate` | 气流示意 |
| `voicing` | 布尔 | 声带振动示意 |

## 数据与进度说明

- 关卡与文章内容由团队后台直接维护，保存后供前端读取展示。
- 用户的学习事件（听辨作答、练习步骤完成）和录音结果保存在服务端个人账号下，进度由服务端统一计算。
- 关卡详情提供 nav（上一关、下一关、易混关），方便用户在关卡间连续学习与对比。
