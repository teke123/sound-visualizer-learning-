# 功能需求 · 学习侧

## 首页与页面总则

#### FR-201 页面结构保留且承载真实内容（1.0，必做）

系统应保留《02-内容模型与信息架构》4.1 节定义的页面结构（P01–P06、P09–P11，共 9 页），页面数量可随版本扩展；每页按其定义承载内容，页面数据来自后台已开放的关卡。

#### FR-203 搜索框提示（1.0，必做）

系统应在首页搜索框提示可输入汉字、拼音或关卡名，例如「a」「妈」「翘舌」。

#### FR-204 关卡列表（1.0，必做）

系统应在首页展示已开放的关卡列表。

#### FR-205 推荐起始关（1.0，必做）

系统应默认从当前用户进度的下一关开始（完成判定见 D-24）。无任何进度时从 L01（a）或当前顺序中的第一关开始。

## 搜索（P02）

#### FR-301 可搜索汉字、拼音、关卡名（1.0，必做）

系统应支持搜索汉字、拼音、关卡名。

#### FR-302 结果字段（1.0，必做）

系统应在每条结果给出关卡名称、类型（单韵母 / 声母 / 拼读）、进入关卡按钮。

#### FR-303 结果范围（1.0，必做）

搜索结果包含当前已开放的关卡。

#### FR-304 无结果时的相近关推荐（1.0，必做）

系统应在无结果时给出相近关卡（例如搜「ai」时给出 a 或相关关卡），并提供「希望增加」提交口。

## 发音地图（P03）

#### FR-401 三层闯关定位图（1.0，必做）

系统应将发音地图实现为闯关定位图，固定三层：单韵母（L01–L06）→ 声母（L07–L29）→ 拼读（L30）。

#### FR-402 关卡开放状态（1.0，必做）

地图中已开放的关卡可点击进入 P05；尚未开放的关卡展示身份与「未开放」状态。

#### FR-403 易混关并排入口（1.0，必做）

系统应提供易混关并排入口：n 与 l、b 与 p、d 与 t、g 与 k、j 与 q、z 与 zh、c 与 ch、s 与 sh、f 与 h、u 与 ü。双方均开放时可点击进入比较。

#### FR-404 地图展示信息（1.0，必做）

发音地图清晰展示关卡身份、发音分类、层位、开放状态与个人学习进度。

## 发音原理（P04 · 博客式子站）

P04 为博客式原理子站——文章目录（`/principles`）+ 文章页（`/principles/:slug`）。文章讲普遍原理与声学知识；具体音的讲解与录音训练在关卡页（P05）。

#### FR-501 原理子站结构（1.0，必做）

系统应以文章列表与文章页的形式组织发音原理内容，并介绍相关的发音生理与声学原理。

#### FR-506 文章参考资料（1.0，必做）

系统应在文章页提供参考资料条目（标题、来源、许可）。

## 关卡页（P05 · 学习与录音检测一体）

关卡页（P05）整合学习与录音检测全流程，采用「构形与声学说明 → 示范 → 听辨与练习 → 本关录音检测（含前端实时声学反馈） → 结果（P09） → 下一步」的顺序。

#### FR-601 统一关卡页结构（1.0，必做）

系统应将 P05 作为关卡学习与录音检测的核心载体。每一关使用统一的结构。

#### FR-603 构形多视图（1.0，必做）

系统应以可来回切换的多视图呈现构形，让学习者直观看见嘴、舌、气流等与本关相关的发音运动：内容媒体（图 / 动图 / 视频）、2D 声道剖面图、3D 三维模型三种视图并存切换。

业务规则：

- 内容媒体与声道剖面图由后台录入的数据驱动展示；支持切换查看三维口腔模型视图。
- 任一视图缺席时其余视图仍可正常查看。

#### FR-604 示范音（1.0，必做）

系统应至少提供正常语速可播放示范，鼓励另提供慢速；建议男女声各一条；音频能完整播完并配对应文字。

#### FR-605 跟着练（1.0，必做）

系统应提供分步短练习。每步可播放、可暂停、可重做；用户可标记「完成这一步」，该标记记为一次练习完成事件，保存在用户账号下，用于计算 D-24 关卡完成度。

#### FR-606 听辨练习（1.0，必做）

系统应提供听辨练习：听一个音、从选项中选出是哪个（例如「nán 还是 lán」）。选择后立即判对错，答错展示解释并允许再答；每次作答记一次听辨事件并保存至用户账号，用作学习进度计算（D-24）。

#### FR-607 小测（2.0，必做）

系统应提供几道围绕本关目标的小测题目，记录结果作为本关完成度参考。

业务规则：1.0 不做小测（D-13）；2.0 提供小测，题型以单选起步；1.0 的关卡完成度由听辨与练习事件派生。

#### FR-608 误区（1.0，必做）

系统应说明常见发音误区：「可能听起来像什么、原因是什么、可以怎么改」。

#### FR-609 本关录音检测区（1.0，必做）

系统应在每个关卡页（P05）内直接提供录音与检测提交区域（详细录音与前端实时声学反馈要求见《04-功能-账号检测与档案》FR-902～FR-907）。用户无需跳转到其他独立录音页面即可在本关边看示范、边查看实时声学反馈完成录音并提交检测。

#### FR-610 声学与专业说明及关卡导航（1.0，必做）

系统应在关卡页展示发音部位、发音方法及声学说明（如时长、基频 F0、共振峰 F1/F2、VOT 等），并提供上一关、易混关、下一关的导航链接（如 L30 提供回到 L01 与 L09 的链接）。

## 发音库（P06）

P06 是关卡目录与对比工具页。

#### FR-701 按层索引关卡（1.0，必做）

系统应按单韵母 / 声母 / 拼读分层展示已开放的关卡卡片，支持试听与任选两关比较。

#### FR-702 卡片字段（1.0，必做）

系统应使卡片含名称、拼音、代表汉字（若有）、示范播放、进入关卡（P05）。

#### FR-703 关卡并排比较（1.0，必做）

系统应支持选择两个关卡并排比较示范音频、构形与声学说明。P03 的易混关入口与 P05 的易混关链接直接打开该比较；P06 可任选两个关卡比较，并以易混关作为快捷选项。三处使用同一比较界面。

## 反馈与内容扩展

#### FR-1501 希望增加（1.0，必做）

系统应在搜索无结果或页面提供「希望增加」的音或字提交口。

#### FR-1502 纠错（1.0，必做）

系统应支持报告文字、声音、图片、字幕错误。

#### FR-1503 新增关沿用既有结构（1.0，必做）

系统应保证新增关卡使用同一套关卡页（P05），并保留档案中的历史记录。
