# 功能需求 · 学习侧

## 首页与页面总则

#### FR-201 页面结构保留且承载真实内容（1.0，必做）

系统应保留《02-内容模型与信息架构》4.1 节定义的页面结构（P01–P06、P09–P11，共 9 页），页面数量可随版本扩展；每页按其定义承载内容，页面数据来自后台已开放的关卡。

#### FR-203 搜索框提示（1.0，必做）

系统应在首页搜索框提示可输入汉字、拼音或关卡名，例如「a」「妈」「翘舌」。

#### FR-204 关卡列表（1.0，必做）

系统应在首页展示已开放的关卡列表。

#### FR-205 推荐起始关（1.0，必做）

系统应默认从当前用户进度的下一关开始（完成判定见 D-24）。无任何进度时从 L01（a）或当前顺序中的第一关开始。

## 搜索（P02）

#### FR-301 可搜索汉字、拼音、关卡名（1.0，必做）

系统应支持搜索汉字、拼音、关卡名。

#### FR-302 结果字段（1.0，必做）

系统应在每条结果给出关卡名称、类型（单韵母 / 声母 / 拼读）、进入关卡按钮。

#### FR-303 结果范围（1.0，必做）

搜索结果包含当前已开放的关卡。

#### FR-304 无结果时的相近关推荐（1.0，必做）

系统应在无结果时给出相近关卡（例如搜「ai」时给出 a 或相关关卡），并提供「希望增加」提交口。

## 发音地图（P03）

#### FR-401 三层闯关定位图（1.0，必做）

系统应将发音地图实现为闯关定位图，固定三层：单韵母（L01–L06）→ 声母（L07–L29）→ 拼读。各层关卡数量随内容追加，地图按已开放关卡动态展示。

#### FR-402 关卡开放状态（1.0，必做）

地图中已开放的关卡可点击进入 P05；尚未开放的关卡展示身份与「未开放」状态。

#### FR-403 易混关并排入口（1.0，必做）

系统应提供易混关并排入口：n 与 l、b 与 p、d 与 t、g 与 k、j 与 q、z 与 zh、c 与 ch、s 与 sh、f 与 h、u 与 ü。双方均开放时可点击进入比较。

#### FR-404 地图展示信息（1.0，必做）

发音地图清晰展示关卡身份、发音分类、层位、开放状态与个人学习进度。

## 发音原理（P04 · 博客式子站）

P04 为博客式原理子站——文章目录（`/principles`）+ 文章页（`/principles/:slug`）。文章讲普遍原理与声学知识；具体音的讲解与录音训练在关卡页（P05）。

#### FR-501 原理子站结构（1.0，必做）

系统应以文章列表与文章页的形式组织发音原理内容，并介绍相关的发音生理与声学原理。

#### FR-506 文章参考资料（1.0，必做）

系统应在文章页提供参考资料条目（标题、来源、许可）。

## 关卡页（P05 · 学习与录音检测一体）

关卡页（P05）整合学习与录音检测全流程。桌面端（≥1024px）为双栏工作台：左栏常驻参照（构形、示范音，随滚动停留），右栏为训练与检测流（发音要领 → 本关录音检测（含前端实时声学反馈）→ 页内检测结果）。窄屏（<1024px）为单列认知顺序：构形 → 示范 → 发音要领 → 录音检测 → 页内结果；滚动至录音检测区时，页面顶部显示紧凑参照栏（关卡目标音与构形缩略、听示范入口）。

#### FR-601 统一关卡页结构（1.0，必做）

系统应将 P05 作为关卡学习与录音检测的核心载体。每一关使用统一的结构。关卡头部展示目标音的国际音标（IPA）与语音学特征标签（来自关卡语音学定位字段，未填写时按目标音与拼音自动匹配）。

#### FR-603 构形多视图（1.0，必做）

系统应以可来回切换的多视图呈现构形，让学习者直观看见嘴、舌、气流等与本关相关的发音运动：内容媒体（图 / 动图 / 视频）、2D 声道剖面图、3D 三维模型三种视图并存切换。

业务规则：

- 内容媒体与声道剖面图由后台录入的数据驱动展示；支持切换查看三维口腔模型视图。
- 任一视图缺席时其余视图仍可正常查看。

#### FR-604 示范音（1.0，必做）

系统应至少提供正常语速可播放示范，鼓励另提供慢速；建议男女声各一条；音频能完整播完并配对应文字。

#### FR-605 发音要领（1.0，必做）

系统应在关卡页以纯文本列表展示本关的发音步骤与方法，按步骤顺序列出，供学习者对照练习。

#### FR-607 小测（2.0，必做）

系统应提供几道围绕本关目标的小测题目，记录结果作为本关完成度参考。

业务规则：1.0 不做小测（D-13）；2.0 提供小测，题型以单选起步；1.0 的关卡完成度由本关的录音检测提交派生。

#### FR-609 本关录音检测区（1.0，必做）

系统应在每个关卡页（P05）内直接提供录音与检测提交区域（详细录音与前端实时声学反馈要求见《04-功能-账号检测与档案》FR-902～FR-907）。用户无需跳转到其他独立录音页面即可在本关边看示范、边查看实时声学反馈完成录音并提交检测。

#### FR-610 关卡导航与专业说明（1.0，必做）

系统应在关卡页（P05）底部提供上一关、下一关的导航链接；本关的发音部位、发音方法及声学说明（如时长、基频 F0、共振峰 F1/F2、VOT 等）应在完整检测结果页（P09）展示。

#### FR-611 页内检测结果闭环（1.0，必做）

系统应在关卡页（P05）提交录音成功后停留在当前页，在录音检测区下方原地展示本次检测结果：录音质量提示、分数与本次录音回放、声学可视化对比（基频曲线、共振峰、送气段波形 VOT、频谱图）、现象与规则四步反馈；处理中按 D-19 展示处理阶段并轮询。结果区底部提供「再录一次」（收起结果区并回到待录状态）与「查看完整报告」（进入 P09 查看完整报告与原始声学数据）。

## 发音库（P06）

P06 是音系参考与对比工具页：以音系表格组织普通话全部声母、韵母、声调与合法声韵拼合音节，已开放关卡在对应单元格点亮；不承载进度（进度呈现归 P03）。

#### FR-701 音系表格视图（1.0，必做）

系统应提供四张可切换的音系视图：

- 声母表：发音部位（列）× 发音方法（行）矩阵，21 个辅音声母，底部为零声母拼写行（y / w）。
- 韵母表：韵母结构（行）× 四呼（列），旁附单元音舌位四边形（圆唇 / 不圆唇标记），舌位点与韵母表选中联动。
- 声韵拼合总表：声母行（21 个 + 零声母 Ø）× 可拼合韵母列（按四呼分组）；合法音节按《汉语拼音方案》拼写展示（含省写规则，如 ju、diu、wei）与代表汉字。
- 声调表：四声调值、IPA 调号、调型示意与示例关卡。

业务规则：

- 单元格展示拼音、IPA（受「显示 IPA」开关控制）与代表汉字；已开放关卡覆盖的单元格点亮，覆盖口径为音节关优先，其次声母关、韵母关，零声母行经 y / w 拼写关归属。
- 关卡经关卡语音学定位字段（phonology，可选）或按 layer / targetSound / pinyin 自动匹配落位到对应单元格；新增关卡自动出现在表中。

#### FR-702 筛选与检索（1.0，必做）

系统应提供范围筛选（全部音系 / 仅已开放关卡）、隐藏空行/列开关、显示 IPA 开关、四呼切换（韵母表与拼合总表）、韵母结构筛选（韵母表）、易混组快捷过滤（送气对立、平翘舌、n/l、f/h、前后鼻、u/ü；激活时高亮对应行列并切换到相关视图）与搜索（拼音 / IPA / 代表汉字 / 关卡）。

#### FR-703 音详情与并排比较（1.0，必做）

系统应在选中单元格时提供详情侧栏：拼音、IPA、代表汉字与语音学分类标签；命中已开放关时提供示范试听、构形预览（多视图）、「进入关卡（P05）」与「加入比较」。

系统应支持任选两关并排比较示范音频、构形与声学说明，比较面板展示两侧语音学属性标签并高亮差异项；易混组提供一键比较（双方均开放时可用）。P03 的易混关入口与 P05 的易混关链接直接打开该比较；三处使用同一比较界面。

## 反馈与内容扩展

#### FR-1501 希望增加（1.0，必做）

系统应在搜索无结果或页面提供「希望增加」的音或字提交口。

#### FR-1502 纠错（1.0，必做）

系统应支持报告文字、声音、图片、字幕错误。

#### FR-1503 新增关沿用既有结构（1.0，必做）

系统应保证新增关卡使用同一套关卡页（P05），并保留档案中的历史记录。
