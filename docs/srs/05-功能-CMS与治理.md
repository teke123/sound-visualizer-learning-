# 功能需求 · 关卡治理与 CMS

## 关卡内容与发布治理

#### FR-1201 三十关身份与顺序（1.0，必做）

系统应按《02-内容模型与信息架构》3.4 节关卡清单实现 L01–L30 的身份、顺序和类型；顺序固定，允许少发布。

#### FR-1202 已发布关统一提供检测（1.0，必做）

系统应在关卡发布后同步提供学习与录音检测。检测 API 用于所有已发布关的朗读任务。

#### FR-1203 发布学习内容的前置条件（1.0，必做）

系统应仅允许满足以下全部条件的关进入「已发布」：

- 关卡 ID / 顺序 / 目标音完整；一句话结论、听辨题和 3–5 步练习完整。

- 示范音可完整播放且构形材料可用（内容媒体及其替代文本、声道剖面参数通过取值校验）。

- 指定的参考示范可提取有效音高，参考发音人音域已登记，可生成本关标准曲线。

- 来源、授权与版本记录齐全。

- 误区与专业折叠边界已写。

- 检测任务符合 FR-1204，发布后即可录音检测。

#### FR-1204 检测任务配置要求（1.0，必做）

每关须配置朗读文本，保证提示词与示范一致；质量两维检查可用，不合格时停止评分；评分字段与现象映射明确，四步模板齐全，关卡内入口与 P08 口径一致。这些要求与学习内容一同检查。

业务规则：评测文本须为评分服务可评测的形式（汉字或带调音节）。评分服务不能单独评测孤立声母，声母关以代表音节朗读（如 b 关读「波」），评分与现象只取声母相关维度；各关评测形式须在上线前逐关验证。

#### FR-1205 评分服务（1.0，必做）

系统应通过外部普通话评分服务完成每关录音评分，使用其返回的声韵、调型等维度分数与音节粒度检错信息，并结合规则引擎生成现象与四步反馈。评分服务不可用或返回异常时按处理失败处理（FR-906）。

#### FR-1206 教学内容来源（1.0，必做）

系统应保证教学内容（结论、构形说明、练习、误区、四步底稿、专业折叠文）由教学 / 语音学方提供；缺必需材料时该关暂不发布；仅可选媒体视图允许缺席，不得通过关闭必需模块绕过发布检查。

#### FR-1207 公开媒体授权（1.0，必做）

系统应保证公开示范音、图、动画、视频有授权记录，优先使用国家语音标准的公开授权资料。

#### FR-1208 结论可追溯版本（1.0，必做）

系统应保证所有对使用者可见的检测结论能追溯到规则版本与内容版本。

## CMS

#### FR-1401 按字段录入关卡（1.0，必做）

系统应支持管理员按关卡字段（附录 A）录入关卡，可保存草稿、预览、修改。

#### FR-1402 媒体上传（1.0，必做）

系统应支持上传图片、动画、音频、字幕和授权材料；关卡媒体齐全后方可发布。

#### FR-1403 配置检测任务（1.0，必做）

系统应为每一关配置检测任务：朗读提示词、质检要求、评分指标、四步模板。

#### FR-1404 发布与下架（1.0，必做）

系统应支持管理员在发布前置条件满足后发布一关，并支持下架；下架后大众端详情、搜索、导航和关联媒体即时转为不可见；地图仅保留预先公开的未开放身份骨架。历史私人录音结果按原版本保留。

#### FR-1405 大众端可见范围（1.0，必做）

大众端页面、搜索源与地图可学节点仅展示已发布内容。

#### FR-1406 新发布关可被发现且结构一致（1.0，必做）

系统应在新发布一关后，使其可从搜索、发音地图找到，且关卡页结构与既有关一致；P06 已发布索引同步更新。

#### FR-1407 反馈处理状态（1.0，必做）

系统应使用户反馈进入待处理 / 已采纳 / 暂不采纳；反馈须经处理后方可影响检测规则。

#### FR-1408 版本管理与回退（1.0，必做）

系统应在关卡内容与检测规则修改时保留版本与修改记录，支持查看历史版本并回退到上一公开版本；发布与回退由管理员操作。

#### FR-1409 原理文章管理（1.0，必做）

系统应支持管理员创建、编辑、保存草稿、预览、发布及下架 P04 原理文章。文章字段包括标题、唯一 slug、分类、摘要、Markdown 正文、示范媒体、短练习、参考资料（标题 / 来源 / 许可 / 适用边界）及关联关卡。发布前检查 FR-502、FR-504～FR-506 所需内容；草稿与下架文章不对大众端展示。

#### FR-1410 原理文章目录与关联（1.0，必做）

系统应支持单一管理员创建、重命名文章分类并调整文章归属，初始分类为「气 / 声 / 口型」。删除仍有关联文章的分类前，须先将文章迁移至其他分类。

管理员可选择关联关卡，使已发布文章出现在 P04 目录中，并按分类进入文章。面向用户的关联关卡入口仅指向已发布关；关联关卡下架后，不保留指向不可见页面的有效入口，并在 CMS 提示管理员检查受影响文章。

#### FR-1411 文章版本与权限（1.0，必做）

文章管理沿用单一管理员授权、媒体授权记录、版本记录与上一公开版本回退要求。预览可用于检查正文、示范播放、短练习、参考资料及关卡链接。

#### FR-1412 Markdown 编辑与预览（1.0，必做）

系统应提供文章 Markdown 正文编辑与渲染预览。预览应呈现大众端的正文、图片、示范音、短练习、参考资料及关联入口；未经发布的草稿预览仅管理员可访问。后台的预览一律打开大众端真实预览路由，与公开页面使用同一套渲染，不在后台另做一套渲染。

#### FR-1413 已发布内容的草稿修改与重新发布（1.0，必做）

修改已发布关卡、检测任务、规则模板或文章时，系统应将修改保存为草稿，大众端继续使用上一公开版本。管理员预览草稿并主动重新发布后，新版本才替换公开版本；重新发布须再次检查对应发布条件。发布失败时保留草稿与原公开版本。

新版本发布不改写已有录音的结果快照和版本记录。CMS 应区分公开版本与编辑草稿；分类重命名、文章归属及关联关卡的变更随相关内容重新发布生效。

## CMS 首版范围

1.0 由单一管理员管理文章、分类及关卡关联。媒体上传遵循 FR-1402，登记媒体归属、授权及发布引用，以保证访问控制与删除。管理范围包括标定文本配置（须覆盖六个单韵母并有足够音高起伏）、参考发音人音域登记、关卡骨架公开标记、预览和审计；独立统一媒体库及全站配置产品界面不属于 1.0。

# 附录 C CMS 状态机

关卡与文章发布状态（文章发布检查 FR-1409，关卡发布检查 FR-1203）：

    草稿 -> 已发布
    已发布 -> 已下架
    已下架 -> 已发布（须仍满足对应内容的发布前置条件）

已发布内容可同时存在编辑草稿；保存草稿不改变公开状态，重新发布成功后才更新公开版本（FR-1413）。

反馈单状态：

    待处理 -> 已采纳
    待处理 -> 暂不采纳

## 后台规划与发布一致性

- 管理界面优先 starlette-admin，sqladmin 备选；单管理员鉴权通过框架认证扩展自行配置，不假定安装后自动带可用管理员登录，不与学习账号权限混流。
- 稳定身份、编辑草稿、不可变公开版本分离；通用 CRUD 仅编辑草稿，公开版本不可直接增删改。发布、下架、回退经过用例层事务、前置检查与审计。回退生成新的公开版本记录，历史检测快照仍引用原版本。
- 发布检查逐项给出缺失字段；草稿与公开版本可对比。关卡发布须检测就绪；独立检测开关仅作 Provider 故障等应急熔断，可按单关或全局开启，须记录原因及恢复状态，不能把长期只学不测作为正常发布形态。冻结验收时全部已发布关检测开放。
- 管理员在后台签发短期预览令牌（默认 15 分钟，绑定管理员会话、内容对象、草稿修订及过期时间），打开前端真实预览路由。预览 JSON 与公开详情结构一致；草稿媒体也必须有预览权限，令牌不可授权私人录音。退出管理员会话或草稿修订变更即失效。
- 后台至少覆盖：内容/文章/分类/媒体与授权录入、检测任务与参考示范配置、标定文本与参考发音人配置、骨架公开标记、前置检查、草稿对比、发布/下架、应急熔断与恢复、版本回退、预览令牌签发、分类删除前迁移、受下架影响文章提示、反馈与希望增加处理、审计查看。常规表单不足时用自定义动作或页面。完整用例清单见后端决策图「后台治理用例」。
- 文章目录分类与文章归属按公开版本读取；分类更名须协调关联文章重新发布，禁止直接更改共享分类行而让草稿变更提前公开。关卡下架后若文章暂无已发布关联关，保留文章并显示关联入口暂不可用，后台提示补齐。
