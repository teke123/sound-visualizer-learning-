# 产品需求分析

> 业务需求以 [SRS](srs/README.md) 为准，API 契约见 [后端决策图](decision-map-backend.md)。

## 产品定位与用户

产品帮助大众普通话学习者理解发音、听出区别、完成练习并看到前后变化。1.0 面向大众学习者；2.0 提供普通话考试与职场问题标签分流；3.0 提供对外汉语路径。产品属于发音学习工具，检测结果不构成医疗、康复、声乐或普通话考试等级诊断。

## 学习闭环

选择已发布关 → 看结论和构形 → 听正式示范 → 听辨与跟着练 → 按要求录音 → 质量检查 → 曲线、分数、现象与四步反馈 → 重录或下一关。登录且同意后自动保存，并可在本人声音档案中比较同关两次结果。

质量检查包括音量、噪声、截幅、时长与是否按文本朗读。不合格时停止评分并提供重录指引。反馈只陈述测得的现象和可执行建议，不编造生理原因。音高曲线按个人音域换算；未标定仍可评分，曲线显示标定入口。

## 范围与内容

1.0 内容为 6 个单韵母、23 个声母和「妈」拼读，共 30 关；允许少发布，但所有已发布关须具备学习材料、授权示范与可用检测。原理文章按气、声、口型组织。页面为 P01–P06、P08–P11，共 10 页。关卡小测属于 2.0。

1.0 使用外部评分服务与规则四步反馈、单管理员 CMS、草稿与不可变公开版本、预览、发布/下架、回退及审计。2.0 包括大模型话术（管理员确认）、个性化推荐、专属纠音模型对比与复韵母/鼻韵母/易混声调内容。3.0 包括 IPA、变调、音位变体和对外汉语路径。具体冻结日和验收以 SRS 为准。

## 数据控制

可不登录先学，未登录或未同意的学习进度只在前端本地。同意后自动全部转存当前安全绑定会话中未过期、未删除的已完成录音与结果；同意后仅上传新的学习事件，不导入历史本地进度。临时数据首次上传起最多 72 小时，不因读取、提交或登录续期。

撤回同意或注销删除录音、结果、文件、特征、评分缓存、学习事件与进度、音域及标定数据；在途操作不可复活已删数据。私人音频不因反馈或管理员身份而公开。API 使用标准 HTTP 状态码与统一 JSON 响应体。

## 验证与协作

以端到端切片推进：先完成一关的学习、录音、质量、结果与档案闭环，再验证内容发布、各关检测及异常路径。前端、后端、内容共同依据关卡字段、结果快照和 OpenAPI 契约协作。

建设固定的真人录音测试集，配人工逐条判断；检测规则与评分服务变更时使用相同数据复测。验证维度包括结果准确性、同版本重复性、反馈可理解性、移动端主路径和权限/删除边界。未获得数据的能力不能声称可靠。

## 比赛与效果研究

### 一套产品，多种讲法

不为不同比赛做不同功能，而是同一套成果换不同侧重：

| 比赛                | 重点                | 需要的材料                   |
| ----------------- | ----------------- | ----------------------- |
| 大创（建议申报**创新训练**类） | 研究问题、创新点、可行性、前期基础 | 可运行原型 + 初步测试数据 + 清晰研究计划 |
| 计算机设计大赛（人工智能方向）   | 作品完整、能现场演示、技术含量   | 稳定的演示版本 + 准确率数据 + 作品视频  |
| 创新创业类比赛           | 用户、市场、商业模式        | 用户访谈、竞品分析、合作意向          |
| 挑战杯               | 学术价值              | 论文          |

### 建议的研究问题（大创与论文的主线）

> **“按个人音域换算的声调可视化反馈 + 针对性听辨训练”，能否在短期内提高方言区 / 外语学习者的声调与易混音发音准确度？**

配套一个小规模效果实验：

- 招募 20–30 名目标用户；
- 练习前做一次读词测试（人工评分），练习约 2 周，再做一次；
- 有条件可以分两组对比（例如“只听辨”与“听辨 + 可视化反馈”）。

这个实验同时产出：大创的前期基础、比赛里的“用户效果数据”、论文的核心结果。对学生项目来说，**一组真实的“前后对比数字”比十个功能更有说服力**。

### 创新点与证据

创新点需要实测证据支持：

1. **面向问题而非面向课本**：按方言 / 母语背景定位个人发音问题，针对性训练；
2. **按个人音域换算的声调可视化**：不同性别、音高的人都能和标准对比；
3. **可解释的可靠性反馈**：质量不合格不评分，开放维度以验证结果为依据，并用测试集数据证明；
4. **“听辨 + 跟读 + 可视化”三合一训练**；
5. **方言—发音问题对照知识**（领域资产）。
