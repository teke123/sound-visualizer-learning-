# 产品需求分析

> 业务需求以 [SRS](srs/README.md) 为准，API 契约见 [后端决策图](decision-map-backend.md)。产品面向普通话发音学习。

## 产品定位与用户

产品帮助大众普通话学习者（成人）理解发音机制、听出区别、完成跟读练习并通过声学可视化看到前后变化。支持用户选填个人「方言区 / 母语背景」。1.0 面向大众学习者；2.0 提供普通话考试与职场问题标签分流；3.0 提供对外汉语路径。

## 学习闭环

登录进入平台 → 选择开放关（P05） → 看构形与声学说明 → 听标准示范 → 听辨与跟着练 → 在本关直接录音（可选音域标定或跳过；发声时查看前端实时波形、音量与实时音高曲线） → 结果页（P09）查看声学可视化对比（基频 F0、共振峰元音空间 F1/F2、送气段波形/VOT 与语谱图）、分数、现象、四步反馈及录音环境质量提示 → 重录或下一关。每次练习与录音结果自动保存在个人声音档案（P10）中，支持同关多次记录并排比较。

录音质量检测（音量、噪声、截幅、时长）作为辅助提示帮助用户改善录音环境，不阻断评分与声学可视化。

## 范围与内容

1.0 内容为 6 个单韵母、23 个声母和「妈」拼读，共 30 关；按实际进度逐步开放。页面为 P01–P06、P09–P11，共 9 页（学习与录音检测统一在 P05 完成）。关卡小测属于 2.0。

1.0 使用外部评分服务结合本地 Python 声学特征分析、前端 Web Audio 实时声学反馈与规则四步反馈，后台为团队自用的简单内容维护工具。2.0 包括大模型四步反馈话术（结合用户方言/母语背景与声学特征）、个性化推荐、专属纠音模型对比与复韵母/鼻韵母/易混声调内容。3.0 包括 IPA、变调、音位变体和对外汉语路径。具体冻结日和验收以 SRS 为准。

## 账号与数据管理

用户注册并登录后使用系统，默认登录即同意服务条款，支持在注册或账号页（P11）选填「方言区 / 母语背景」。学习进度、音域标定与每次录音结果自动保存至个人账号。支持用户随时删除单条录音、清空个人声音档案以及注销账号；远期支持绑定邮箱找回密码。

## 验证与协作

以端到端切片推进：先完成典型关卡的学习、关卡内录音（含前端实时声学反馈）、声学可视化（基频、共振峰、送气段波形与语谱图）、结果反馈与档案对比闭环，再扩展全部关卡内容。前端、后端、内容共同依据关卡字段与 OpenAPI 契约协作。

## 比赛与效果研究

### 一套产品，多种讲法

不为不同比赛做不同功能，而是同一套成果换不同侧重：

| 比赛 | 重点 | 需要的材料 |
| --- | --- | --- |
| 大创（建议申报**创新训练**类） | 研究问题、创新点、可行性、前期基础 | 可运行原型 + 初步测试数据 + 清晰研究计划 |
| 计算机设计大赛（人工智能方向） | 作品完整、能现场演示、技术含量 | 稳定的演示版本 + 准确率数据 + 作品视频 |
| 创新创业类比赛 | 用户、市场、商业模式 | 用户访谈、竞品分析、合作意向 |
| 挑战杯 | 学术价值 | 论文 |

### 建议的研究问题（大创与论文的主线）

> **“多维声学可视化反馈（实时音高与波形监控 + 基频曲线、元音空间、语谱图对比）+ 针对性听辨训练”，能否在短期内提高方言区 / 外语学习者的声调与易混音发音准确度？**

配套一个小规模效果实验：

- 招募 20–30 名目标用户（记录其方言区/母语背景）；
- 练习前做一次读词测试（人工评分），练习约 2 周，再做一次；
- 有条件可以分两组对比（例如“只听辨”与“听辨 + 可视化反馈”）。

这个实验同时产出：大创的前期基础、比赛里的“用户效果数据”、论文的核心结果。对学生项目来说，**一组真实的“前后对比数字”比十个功能更有说服力**。

### 创新点与证据

1. **面向问题而非面向课本**：按方言 / 母语背景定位个人发音问题，针对性训练；
2. **实时 + 事后多维声学可视化对比**：发声时提供前端实时音高/波形反馈，提交后支持基频 F0（支持个人音域换算）、元音空间 F1/F2 与辅音送气段波形/语谱图直观对比；
3. **可解释的四步纠音反馈**：结合声学参数与评测检错给出“现象—环节—提示—练习”闭环；
4. **“构形 + 听辨 + 跟读 + 声学可视化”四合一训练**；
5. **方言—发音问题对照知识**（领域资产）。
