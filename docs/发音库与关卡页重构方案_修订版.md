# 发音库（P06）与关卡页（P05）重构执行计划

> 状态：可执行开发计划。依据当前分支源码（`LibraryPage.vue`、`LevelLearnSection.vue`、`LevelView.vue`、`ResultPage.vue`、`FormantChart.vue`、`backend/app/api/schemas.py`）制定。

## 1. 重构目标

1. **发音库（P06）音系表格化**：将现有的“三层关卡卡片网格”重构为按现代汉语语音学事实组织的**音系表格工具页**，包含**声母表（发音部位 × 发音方法）**、**韵母表（四呼 × 韵母结构）+ 元音舌位图**、**声韵拼合总表**、**声调表**，展示 **IPA（国际音标）**，并提供**筛选与行列隐藏功能**。
2. **面向全量音系扩展**：表格架构直接覆盖普通话全部声母、韵母、声调与合法声韵拼合音节；随着后续关卡和语料扩充，新内容通过统一的音系定位字段自动落位到对应单元格。
3. **关卡页（P05）双栏工作台与页内结果闭环**：将单列长滚动页面重构为桌面端“左栏常驻参照（构形 + 示范 + 说明）+ 右栏训练与录音检测”双栏布局；录音提交后**直接在关卡页内展示检测结果与声学对比图**，一键重录。
4. **共振峰坐标系对齐**：将 `FormantChart.vue` 的坐标轴调整为语音学标准元音空间方向（横轴 F2 从右往左增大对应舌位后→前，纵轴 F1 从上往下增大对应舌位高→低），与韵母表的元音舌位图保持一致。

### 2.2 筛选与隐藏功能

1. **范围筛选**：
   - `全部音系`：展示普通话完整声母、韵母、声调或合法拼合音节。
   - `仅已开放关卡`：仅保留/点亮当前已开放的专项关卡单元格。
2. **隐藏空行/空列开关**：开启后，在当前筛选或搜索条件下没有任何命中项的行（如某发音方法/声母）或列（如某发音部位/韵母）自动隐藏，保证表格紧凑易读。
3. **四呼与韵母结构过滤**（在“韵母表”和“声韵拼合总表”中显示）：
   - 四呼切换：`全部` / `开口呼` / `齐齿呼` / `合口呼` / `撮口呼`。
   - 结构切换：`全部` / `单韵母` / `复韵母` / `前鼻韵母` / `后鼻韵母`。
4. **IPA 显示开关**：控制单元格内是否渲染国际音标（如 `[ʈʂ]`）。
5. **易混组快捷过滤**：点击某个易混组标签（如“平翘舌”、“送气对立”、“n/l”），表格仅高亮/筛选出对应的声母或韵母行列，并支持一键打开并排比较。

## 5. 数据结构与接口设计

### 5.1 后端 Schema：新增可选 `phonology` 字段

数据库表结构（`LevelRow`）保持不变。在 `backend/app/api/schemas.py` 的 `LevelSummary` 与 `LevelDetail` 中增加 1 个可选字段 `phonology`，并在 `backend/app/content/usecases.py` 中透传：

```python
class LevelPhonology(BaseModel):
    ipa: Optional[str] = None                                    # 国际音标，如 "ʈʂ", "ᴀ", "ma˥"
    kind: Optional[Literal["initial", "final", "syllable", "tone"]] = None
    initial: Optional[str] = None                                # 声母键，如 "zh", "b", ""
    final: Optional[str] = None                                  # 韵母键，如 "a", "ang", "iou"
    tones: Optional[List[int]] = None                            # 覆盖声调，如 [1, 2, 3, 4]
    place: Optional[str] = None                                  # 发音部位（双唇/唇齿/舌尖前/舌尖中/舌尖后/舌面/舌根）
    manner: Optional[str] = None                                 # 发音方法（塞音/塞擦音/擦音/鼻音/边音）
    aspiration: Optional[Literal["aspirated", "unaspirated", "none"]] = None
    voicing: Optional[Literal["voiceless", "voiced"]] = None
    hu: Optional[Literal["kaikou", "qichi", "hekou", "cuokou"]] = None
    finalStructure: Optional[Literal["simple", "compound", "front_nasal", "back_nasal", "special"]] = None
```

- 当关卡数据中未填写 `phonology` 时，前端音系模块根据关卡的 `layer`、`targetSound`、`pinyin` 自动匹配到音系表对应单元格，保证现有 30 关与未来新增关卡平滑衔接。

### 5.2 前端汉语音系数据模块（`src/phonology/mandarin.ts`）

集中定义现代汉语语音学标准结构（供发音库四张表、筛选器与关卡头部共用）：
1. **声母矩阵定义**：7 个发音部位列 × 8 个发音方法行，21 个辅音声母 + `y`/`w` 的拼音、IPA、代表字、语音学特征。
2. **韵母矩阵与舌位定义**：四呼 × 韵母结构分类，39 个韵母的拼音、IPA、代表字，以及单元音在舌位四边形上的标准坐标 `(frontness, height, rounded)`。
3. **声韵拼合总表定义**：22 个声母行（21 辅音 + 零声母 `Ø`）× 韵母列的合法普通话音节拼写映射（如 `(j, ü) -> { pinyin: 'ju', char: '居' }`）。
4. **声调表与易混组定义**：四声调值、IPA 调号，以及平翘舌、送气对立、鼻边音、前后鼻音等易混过滤集合。
