**“看得见的声音”智能发音学习平台**
—— 基于多模态可视化的智能语音学习系统 ——


**项目申报书正文**

**■ 一、作品简介**

“看得见的声音”是一款面向大众与成人学习者的智能发音学习平台。针对传统语言学习中发音“看不见、摸不着”的核心痛点，本作品创新性地运用语音信号处理与多维可视化技术，将抽象的发音过程（如声带振动、舌位变化、气流与送气运动）转化为直观的 2D/3D 构形图像、动画和声学曲线。

平台采用“学习—检测—反馈”的闭环模式，为用户提供个性化的发音诊断与针对性练习建议。平台兼容电脑与手机端浏览器，无需安装即可使用。

**■ 二、立项背景与意义**

**▸ 2.1 现实需求**

（1）普通话推广的国家战略需求：我国仍有大量方言区人口存在不同程度的普通话发音障碍，尤其是声母混淆（n/l、z/zh、送气与不送气）、声调不稳等问题普遍存在。

（2）国际中文教育的广阔市场：超过3000万外国人正在学习中文。汉语声调系统与特殊辅音是外语学习者面临的最大挑战之一，市场对科学发音训练工具的需求极为旺盛。

（3）语言康复的社会需求：据统计，我国有超过2000万听障人士及大量嗓音障碍患者，可视化发音反馈对他们进行语言康复训练具有重要的辅助价值。

**▸ 2.2 现有产品痛点**

现有语音学习产品存在以下突出问题：

1. 只看分数不给方案：大多数App仅提供跟读打分功能，用户不知道“为什么错”和“怎么改”。
2. 缺乏科学可视化：传统学习方式依赖听觉模仿，无法直观看到舌位、气流等发音器官的运作状态以及基频、共振峰、语谱图等声学表现。
3. 专业软件门槛高：语音学分析软件（如Praat）操作复杂，普通学习者难以直接用于训练。
4. 内容固定不可扩展：现有产品内容固化，无法根据新的研究成果或用户需求灵活扩展。

**▸ 2.3 理论支撑**

本项目有扎实的跨学科理论支撑：语音学（IPA国际音标体系）、声学（基频F0、共振峰F1/F2、嗓音起始时间VOT、语谱图等声学参数）、发声生理学（声带振动、共鸣腔调节）、语音信号处理（短时傅里叶变换、基频与共振峰提取算法）以及教育心理学（刻意练习理论、反馈驱动学习）。

**■ 三、项目内容与技术路线**

**▸ 3.1 系统总体架构**

平台采用B/S架构（浏览器/服务器模式），分为前端展示层、业务逻辑层和数据存储层三个层次：

| **层次** | **核心组件** | **功能说明** |
|:--:|:---|:---|
| **前端展示层** | 9个核心页面 | 用户交互、关卡内音频录制、构形与声学可视化渲染 |
| **业务逻辑层** | 语音声学分析、评分与反馈引擎、内容管理 | 声学特征提取、评分调用、四步反馈生成、内容维护 |
| **数据存储层** | 数据库 + 文件存储 | 发音关卡、录音样本、用户声音档案 |

**▸ 3.2 核心功能模块**

| **模块名称** | **核心功能** | **技术实现** |
|:---:|:---|:---|
| **发音地图** | 声母/韵母/拼读闯关定位与易混音对比 | SVG交互式图表 + 分类导航 |
| **关卡页（学习与录音）** | 2D/3D构形动画 + 标准音频 + 分步练习 + 页内录音 | Canvas/3D渲染 + Web Audio API + MediaRecorder |

| **内容维护后台** | 关卡录入 + 媒体上传 + 反馈查看 | 轻量级内部维护后台 |

**▸ 3.3 语音分析技术路线**

录音采集：利用Web Audio API和MediaRecorder实现浏览器端关卡内直接录音，支持PC和手机端，采样率不低于16kHz。

特征提取：后端采用Python生态（Librosa、Praat/Parselmouth）进行多维声学特征提取，包括基频F0、共振峰F1/F2、送气段时域波形（VOT）、宽带/窄带语谱图（Spectrogram）、时长等。

质量提示：从音量（RMS）、噪声（SNR估计）、截幅（峰值检测）、有效时长等维度检测录音环境质量，为用户提供改善录音效果的辅助提示。

结果生成：结合语音评测与声学特征分析，通过规则引擎匹配检测现象与反馈模板，生成“现象—环节—提示—练习”四步反馈。

**▸ 3.4 可视化方案**

发音构形可视化：通过2D声道剖面、动图与3D模型展示口腔剖面、舌位高低前后、唇形圆展、成阻与除阻等发音器官状态。

多维声学可视化：绘制基频（F0）曲线、元音空间与共振峰（F1/F2）分布图、送气段波形（VOT）及语谱图（Spectrogram），并与标准参考示范对比展示。

发音地图可视化：展示单韵母、声母、拼读音节与易混音对之间的体系关系。

**■ 四、创新点与特色**

**创新点一：首创“多模态可视化发音学习”理念**

将听觉信息转化为视觉信息，通过2D/3D构形动画、基频曲线、元音空间共振峰图、送气波形与语谱图等多种可视化手段，让抽象的发音过程变得直观可见。这是认知科学中“多重表征学习”理论的直接应用。

**创新点二：构建“现象—环节—提示—练习”四步反馈机制**

从“给分数”升级为“给解决方案”。系统不仅呈现声学差距，还进一步说明相关的发音器官配合环节，并提供可感知的练习提示和一键直达的短练习。

**创新点三：“内容可生长”的模块化架构**

采用统一的发音关卡字段，新关卡录入后自动融入搜索、发音地图、发音库和比较视图，无需重新设计前端页面结构。

**■ 六、应用前景与社会价值**

**▸ 6.1 教育领域**

1. 普通话推广与教学辅助：帮助方言区学习者纠正普通话发音，提升表达自信。
2. 高校语音学课程教辅：为语言学及相关专业学生提供直观的发音与声学可视化实验工具。
3. 对外汉语教学：为全球中文学习者提供科学、直观的发音训练平台。

**▸ 6.2 语言康复领域**

1. 听障与言语康复辅助：可视化反馈帮助听障者在听觉受限的情况下，通过视觉监控自己的发音状态。
