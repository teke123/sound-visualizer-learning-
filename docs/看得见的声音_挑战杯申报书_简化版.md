**“看得见的声音”智能发音学习平台**
—— 基于多模态可视化的智能语音学习系统 ——


**项目申报书正文**

**■ 一、作品简介**

“看得见的声音”是一款面向大众的智能发音学习平台。针对传统语言学习中发音“看不见、摸不着”的核心痛点，本作品创新性地运用语音信号处理与可视化技术，将抽象的发音过程（如声带振动、舌位变化、气流运动）转化为直观的图像、动画和声学曲线。

平台采用“学习-检测-反馈”的闭环模式，为用户提供个性化的发音诊断与针对性练习建议。首版将完成12个核心发音单元（涵盖元音、辅音、声调等关键发音要素），实现从“妈”字四声检测到个性化练习的完整闭环。平台兼容电脑与手机端，无需安装即可使用。

**■ 二、立项背景与意义**

**▸ 2.1 现实需求**

（1）普通话推广的国家战略需求：我国仍有大量方言区人口存在不同程度的普通话发音障碍，尤其是声母混淆（n/l、z/zh）、声调不稳等问题普遍存在。

（2）国际中文教育的广阔市场：超过3000万外国人正在学习中文。汉语声调系统是外语学习者面临的最大挑战之一，市场对科学发音训练工具的需求极为旺盛。

（3）语言康复的社会需求：据统计，我国有超过2000万听障人士及大量嗓音障碍患者，可视化发音反馈对他们进行语言康复训练具有不可替代的辅助价值。

**▸ 2.2 现有产品痛点**

现有语音学习产品存在以下突出问题：

1. 只看分数不给方案：大多数App仅提供跟读打分功能，用户不知道“为什么错”和“怎么改”。
2. 缺乏科学可视化：传统学习方式依赖听觉模仿，无法直观看到舌位、气流等发音器官的运作状态。
3. 专业门槛过高：语音学教材和软件（如Praat）操作复杂，普通用户难以使用。
4. 内容固定不可扩展：现有产品内容固化，无法根据新的研究成果或用户需求灵活扩展。

**▸ 2.3 理论支撑**

本项目有扎实的跨学科理论支撑：语音学（IPA国际音标体系）、声学（基频F0、共振峰F1/F2、VOT等声学参数）、发声生理学（声带振动、共鸣腔调节）、语音信号处理（短时傅里叶变换、基频提取算法）以及教育心理学（刻意练习理论、反馈驱动学习）。

**■ 三、项目内容与技术路线**

**▸ 3.1 系统总体架构**

平台采用B/S架构（浏览器/服务器模式），分为前端展示层、业务逻辑层和数据存储层三个层次：

| **层次** | **核心组件** | **功能说明** |
|:--:|:---|:---|
| **前端展示层** | 10个核心页面 | 用户交互、音频录制、可视化渲染 |
| **业务逻辑层** | 内容管理、语音分析、用户管理 | 检测规则匹配、反馈生成、版本控制 |
| **数据存储层** | 数据库 + 文件存储 | 发音单元、录音样本、用户档案 |

**▸ 3.2 核心功能模块**

| **模块名称** | **核心功能** | **技术实现** |
|:---:|:---|:---|
| **发音地图** | 声母/韵母/声调关系可视化 | SVG交互式图表 + 分类筛选 |
| **示范单元** | 构形动画 + 标准音频 + 分步练习 | Canvas动画 + Web Audio API |
| **检测中心** | 录音质量检测 + 四声分析 | MediaRecorder + 后端Python分析 |
| **检测结果** | 可视化曲线 + 四步反馈 | Chart.js/Canvas + 规则引擎 |
| **声音档案** | 多次录音比较 + 趋势分析 | IndexedDB + 后端数据库 |
| **后台管理** | 内容录入 + 审核 + 版本管理 | CMS + 工作流引擎 |

**▸ 3.3 语音分析技术路线**

录音采集：利用Web Audio API和MediaRecorder实现浏览器端录音，支持PC和手机端，采样率不低于16kHz。

特征提取：后端采用Python生态（Librosa、Praat/Parselmouth）进行声学特征提取，包括基频F0、共振峰F1/F2、VOT、时长等。

质量检测：从音量（RMS）、噪声（SNR估计）、截幅（峰值检测）、时长（有效语音段）、静音比（silence ratio）五个维度评估录音质量。

结果生成：基于规则引擎匹配检测现象与预设反馈模板，生成“现象-环节-提示-练习”四步反馈。

**▸ 3.4 可视化方案**

发音构形可视化：展示口腔剖面、舌位高低前后、唇形圆展等发音器官状态。

声学曲线可视化：绘制基频曲线、语谱图（Spectrogram），并与标准参考曲线叠加对比。

发音地图可视化：采用展示声母、韵母、声调、音节、汉字之间的层级关系。

**■ 四、创新点与特色**

**创新点一：首创“多模态可视化发音学习”理念**

将听觉信息转化为视觉信息，通过构形动画、声学曲线、发音地图等多种可视化手段，让抽象的发音过程变得直观可见。这是认知科学中“多重表征学习”理论的直接应用，可显著降低学习门槛。

**创新点二：构建“现象-环节-提示-练习”四步反馈机制**

从“给分数”升级为“给解决方案”。系统不仅告诉用户“你的四声不稳定”，还进一步说明“可能与声带张力调节不足有关”，并提供“感知提示”和“安全短练习”。这一设计理念在国内外同类产品中未见先例。

**创新点三：“内容可生长”的CMS架构**

采用统一的发音单元录入字段，新内容发布后自动关联搜索、发音地图、发音库和相关单元，无需重新设计页面结构。这种“乐高式”架构使平台具备自我进化的生命力。

**创新点四：严格的分级开放策略**

知识页可以先发布供学习，但检测功能必须等样本积累、规则验证后才开放。这种“先学后测”“验证后开放”的策略，确保了平台的科学性和可信度，避免了对用户的误导。

**■ 六、应用前景与社会价值**

**▸ 6.1 教育领域**

1. 中小学语文教学辅助：帮助方言区学生纠正普通话发音，提升语文教学质量。
2. 高校语音学课程教辅：为语言学专业学生提供直观的发音可视化实验工具。
3. 对外汉语教学：为全球中文学习者提供科学、系统的发音训练平台。

**▸ 6.2 语言康复领域**

1. 听障人士康复：可视化反馈帮助听障者在看不到/听不清的情况下，通过视觉监控自己的发音。
