# 强制对齐（Forced Alignment）调研报告

> 调研人：Z3 周安来 · 第 10 周
> 目标：测试讯飞语音评测 API 与 Qwen3-ASR 对「不标准普通话发音」的处理能力，判断其能否用于音素级强制对齐。

## 一、任务背景

为分析说话者的录音，需要精确到音素级别的起止时间（Forced Alignment）。讯飞 API 声称有相关能力，但可能拒绝处理发音过于不标准的录音。本调研用两类不标准发音（外国口音 + 方言口音）实测。

## 二、素材准备

| 素材 | 类型 | 来源 | 说明 |
|------|------|------|------|
| `00200213.wav` | 外国口音（法语母语者说中文） | OMPAL 语料库（Interspeech 2025 开源） | 5.5 秒「我的小狗叫黑黑」，16k 单声道 |
| `SPK002.wav` | 方言口音（浓重普通话口音，男） | MagicData「中文浓重普通话口音会话语音语料库」 | 2 秒「那是的嘛，大的小的都有嘛」 |
| `SPK003.wav` | 方言口音（浓重普通话口音，男） | 同上 | 3.7 秒「最近这几年电影国产电影也有长进」 |

所有素材均为**专业录制、单人、成人、音频文本严格对应**，符合强制对齐的输入要求。

## 三、讯飞语音评测（ISE）结果

调用方式：WebSocket `wss://ise-api.xfyun.cn/v2/open-ise`，HMAC-SHA256 鉴权，返回 Base64 XML，音素起止时间在 `<phone>` 节点（每帧 10ms）。

### 3.1 外国口音（OMPAL 法语母语者「我的小狗叫黑黑」）

**结论：正常评判，未拒绝。** 14 个有效音素，均有起止时间，错误定位精准：`叫` 整个漏读（dp=16）、`的/小/黑` 的韵母 e/iao/ei 发音错误。

### 3.2 方言口音一（浓重口音男声「那是的嘛，大的小的都有嘛」）

**结论：正常评判，未拒绝。** 22 个有效音素，错误定位：

| 音素 | 起止时间 | 错误标注 |
|------|---------|---------|
| `n`（那） | 10-40ms | 声母错（err=1） |
| `a`（那） | 40-220ms | 调型错（err=2） |
| `x`（小） | 1200-1280ms | 声母错（err=1） |
| `iou`（有） | 1640-1740ms | 调型错（err=2） |
| `a`（嘛） | 1780-1830ms | 韵母错（err=1） |

### 3.3 方言口音二（浓重口音男声「最近这几年电影国产电影也有长进」）

**结论：正常评判，未拒绝。** 30 个有效音素，错误定位：

| 音素 | 起止时间 | 错误标注 |
|------|---------|---------|
| `z`/`uei`（最） | 10-250ms | 声母错 + 韵母错 |
| `j`（近） | 250-280ms | 声母错（err=1） |
| `zh`（这） | 680-780ms | 声母错（err=1） |
| `d`/`ian`（电） | 1260-1440ms | 声母错 + 韵母错 |
| `ian`（电） | 2290-2360ms | 韵母错（err=1） |
| `ing`（影） | 2400-2460ms | 调型错（err=2） |

### 3.4 讯飞结论

**讯飞对不标准发音（外国口音、浓重方言口音）都不会拒绝评测，而是正常给出音素级起止时间 + 精准发音错误标注**（漏读、声母错、韵母错、调型错）。这意味着讯飞可作为强制对齐的后备方案，且能顺带给出「发音错误定位」——这对项目更有价值。

## 四、Qwen3-ASR 结果

调用方式：HuggingFace 空间 `Qwen/Qwen3-ASR` 的 `/transcribe` 接口（gradio_client）。

**结论：空间后端异常，无法通过 API 返回结果。** 多次尝试（不同格式/时长/语言参数）均返回 `AppError`，属空间后端问题。

## 六、结论与建议

1. **讯飞语音评测不拒绝不标准发音**，且返回音素级起止时间 + 精准发音错误定位，可直接作为强制对齐工具（需指定标准文本）。
2. **Qwen3-ASR 空间当前后端异常**，暂不可用，建议后续手动复测或关注空间更新。
3. 后续可基于讯飞的音素时间戳，直接生成 TextGrid 或与本地 TIFA 工具对比。
